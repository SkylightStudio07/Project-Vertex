# 아카이브(기록관) 입구 화면 · 레이아웃 요청서

로비 좌하단 **아카이브** 버튼을 누르면 열리는 입구 화면. 가운데 기록관 담당 캐릭터가 소파에 앉아 있고, 오른쪽에 기록 메뉴 4개가 세로로 늘어선다. 메뉴를 고르면 각 기록 화면(지금의 마테리얼 등)으로 들어간다.

- 참고·재료
  - `Reference_Baekyagwan.png`: 「영원한 7일의 도시」 백야관. **구성 참고:** 가운데 앉은 캐릭터 + 오른쪽 세로 메뉴(큰 첫 글자 + 나머지 작은 글자, 마름모 장식), 왼쪽 위 화면 이름, 오른쪽 위 닫기. 장식 모양·글꼴은 따르지 않는다.
  - `Source_BG.png` (1920×1088): 배경. **그대로 쓴다.**
  - `Source_Chara.png` (1536×1024, 투명): 기록관 담당. **그대로 쓴다. 다시 그리지 않는다.**
  - `Reference_Shop_Facility.png`: 다른 로비 시설 화면(상점). 제목 판·`← 로비` 버튼 모양을 이것과 맞춘다.
- 화면 1920×1080.

## 1. 배치

| 요소 | 자리 | 내용 |
|---|---|---|
| 배경 | 전체 | `Source_BG` |
| 캐릭터 | 가운데~왼쪽 가운데, 화면 높이의 80% 정도 | `Source_Chara`. 발끝·여우까지 보이게 |
| 제목 | 왼쪽 위 | `03` · `아카이브` · `ARCHIVES` (상점 제목 판과 같은 모양) |
| 닫기 | 오른쪽 위 | `← 로비` (상점과 같은 버튼) |
| 기록 메뉴 4개 | 오른쪽, 세로 | 아래 2절 |
| 담당 대사 | 왼쪽 아래 작게 | 이름 띠 + 한 줄 (상점 대사창과 같은 판) |

## 2. 기록 메뉴 (위에서부터)

| # | 이름 | 영문 | 상태 |
|---|---|---|---|
| 01 | **적** 기록 | ENEMY RECORDS | 열림. 오른쪽 아래 작게 `수집 12 / 40` |
| 02 | **동**료 기록 | COMPANION RECORDS | 열림. `수집 3 / 15` |
| 03 | **아**이템 도감 | ITEM CODEX | 열림. `수집 8 / 30` |
| 04 | **플**레이 기록 | PLAY RECORDS | 열림. `런 14회` |

- 백야관처럼 **첫 글자를 크게**(나머지의 약 2배), 나머지는 작게 붙인다. 영문은 이름 아래 아주 작게.
- 각 메뉴는 가로로 긴 판(약 420×110). 왼쪽에 마름모 장식 칸 + 아이콘(적 = 과녁, 동료 = 두 사람, 아이템 = 상자, 플레이 = 시계/깃발). 백야관처럼 판이 살짝 겹치거나 계단식으로 엇갈려도 좋다.
- 상태: 보통 / 마우스 올림(판이 밝아지고 왼쪽 장식이 강조색) / 잠김(흐림 + 자물쇠, 지금은 쓰지 않지만 조각은 필요).

## 3. 색 — 시안 두 개

이 화면은 어두운 보라 서재라 로비의 회백 판이 뜬다. 판은 **어두운 반투명 먹색(#16181B, 80~85%) + 회백 글자**로 간다.

| 시안 | 강조색 |
|---|---|
| A | 청록 #0DB8F2 (로비 공통) |
| B | 진홍 #B3263A — 캐릭터의 붉은 나비에 맞춘 이 화면 전용 색 |

- 강조색은 마름모 장식, 큰 첫 글자, 마우스 올림 테두리에만 쓴다.
- 장식으로 작은 나비·종잇조각이 메뉴 근처에 두세 개 떠 있어도 좋다(조각은 따로).
