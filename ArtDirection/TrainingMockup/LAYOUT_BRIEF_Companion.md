# 훈련장 · 동료 편성 페이지 · 레이아웃 요청서

훈련장에 데려갈 동료(최대 3명)를 고르는 **별도 페이지**다.

동료는 막마다 3명씩 늘어난다(3막까지 9명). 여기에 이벤트 동료까지 더하면 **12~20명**이 된다. 메인 화면의 가로 줄로는 감당이 안 되므로 페이지를 따로 둔다.

- 같은 틀: `Training_Main_Mockup.png`(훈련장 메인), `Training_Deck_Mockup.png`(덱 편집), `Reference_CardCatalog.png`(무기고 카드 목록)
- 지금 화면(임시 조립): `Reference_Current_Companion.png`(편성 페이지), `Reference_Current_Main_v2.png`(메인 — 동행 3칸 + 빈 칸)
- 기획: `Docs/기획/훈련장.md`

## 1. 공통 스타일

- 덱 편집과 같은 틀이다.
  - 1672×941 판, 왼쪽 위 "06 │ 훈련장 · 동료 편성 / TRAINING GROUND / COMPANION", 오른쪽 위 "← 돌아가기"
  - 주 버튼은 먹색 + 아래 청록 선
- 오프화이트 종이 #EEF0F2, 흑연 선, 청록 #0DB8F2는 선·점·작은 배지에만 쓴다.
- 잠긴 동료는 회색 칸 + 실루엣 + 자물쇠 + 조건 한 줄("호감도 Lv.2 필요").
- 반투명 판·글로우·빨강·노랑은 쓰지 않는다.

## 3. 메인 화면 동행 칸 (수정)

메인(`Training_Main_Mockup`)의 동료 구역은 가로 목록 대신 **동행 3칸 고정**이다.
- 채운 칸: 지금의 동료 카드(동행 태그)를 쓴다.
- 빈 칸: 점선 테두리 + "+ 동료 편성". 새 조각이 필요하다.
- 구역 오른쪽 위에 "편성 →" 작은 글자 버튼을 둔다(눌러도 편성 페이지로).
