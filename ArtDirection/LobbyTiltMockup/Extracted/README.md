# 로비 2.5D 틀 — 2배 분절

틀 PNG 5개와 원본 배경 보정본 1장이다. 메뉴·그림자·호버·캐릭터·말풍선·글자·진행 막대·톱니는 포함하지 않는다. 확정 미리보기의 기하를 정리해 2배 캔버스에 새로 그렸으며, 목업을 잘라 확대하지 않았다.

## 조각과 배치

모든 화면 rect는 1920×1080, 좌상단 원점, `[x,y,width,height]`다.

| 조각 | 화면 rect | PNG |
|---|---|---|
| Frame_TopLeft | 0,0,400,180 | 800×360 |
| Frame_TopBar | 1180,0,740,100 | 1480×200 |
| Frame_BottomLeft | 0,920,320,160 | 640×320 |
| Frame_BottomCenter | 740,840,260,240 | 520×480 |
| Frame_BottomRight | 1780,930,140,150 | 280×300 |

틀은 모두 scale=2, 알파0/255, PNG 헤어라인2px다. 종이색 #EEF0F2에 고정 시드의 미세 잡음과 저주파 얼룩을 새로 합성했다. 원본 종이의 색감을 참고한 재생성 질감이며 원본을 확대하지 않았다. 9-slice는 쓰지 않는다.

상단 왼쪽은 미리보기의 긴 종이 모서리를 살려 높이를180으로 잡았다. 상단 오른쪽은 메뉴 예약 영역의 y100 경계 위에 맞춰 높이100으로 정리했다. 오른쪽 아래 삼각형은 투명 캔버스 상단54px을 비워 실제 시작 높이를 y984로 낮췄다. y1010 이전에는 x1880 오른쪽에만 보인다. 작은 글귀도 이 축소된 모서리 안으로 이동했다.

예약 영역 `[960,100,920,910]`은 모든 틀 조각의 알파를 합쳐 검사했다. 요청에서 허용한 Frame_BottomCenter의 x960~1000 부분만 예외다. 이 조각은 메뉴 뒤에 둔다. 메뉴를 감싸던 구멍·테두리·격자는 없다.

## 배경 보정

`Background_RightDim.png`는 **Reference_Background_Current.png의 원본 픽셀에만 보정**한1672×941 RGBA 파일이다. 알파는 전부255다. 생성 모델을 사용하지 않았고 천막·산·다리 위치를 이동하거나 재구성하지 않았다. 2배 출력 규칙은 틀에만 적용된다.

보정은 sRGB 채널값에서 다음 순서로 적용한다.

1. 원본에 Gaussian blur 반경 **1.15 원본 픽셀** 적용.
2. 휘도 `Y=0.2126R+0.7152G+0.0722B`, 채도 **0.78**: `Y+(RGB-Y)×0.78`.
3. 밝기 **0.78배**.
4. 푸른 회색 **RGB(47,64,79)**을 **10%** 혼합.
5. 원본 X **640부터1300까지** 부드럽게 보정본으로 전환. `t=clamp((x-640)/660,0,1)`, 가중치 `w=t²(3-2t)`, 결과 `원본×(1-w)+보정본×w`.
6. 반올림하여8비트로 저장. x≤640은 원본과 완전히 동일하며 x≥1300은 위 보정이100% 적용된다.

화면 기준 전환 구간은 약 x735~1493이다. 밝기0.78은 최종 밝기의 단순비가 아니라 틴트 혼합 전 곱셈값이다. 색·흐림은 이미지에 구워져 있고 런타임 반투명 판은 필요 없다. 스크립트와 layout.json에 보정값을 함께 보관했다.

## 글자와 게임 요소

`layout.json`에 VERTEX, EXPEDITION 3줄, SHELTER 3줄, OBSERVE 3줄, SOMEWHERE 3줄, 50/100의 박스·정렬·대략 글자 크기·색을 기록했다. 진행 막대와 설정 톱니 자리도 `runtime_element_slots`에 있다. 글자 크기는 실제 TMP 폰트에 맞춰 조정한다. 오른쪽 아래 글귀는 축소된 모서리에 맞춰 작게 배치한다.

## Unity 인계

틀은 Sprite / Single, PPU200, Full Rect, Mip Maps Off, Compression None, Bilinear, Clamp를 권장한다. Canvas Reference Pixels Per Unit100 기준으로 RectTransform은 JSON의1배 화면 크기를 쓴다. 좌상단 피벗이면 anchoredPosition은 `(x,-y)`다. 배경은 원본 크기를 유지했으므로 틀과 같은 SetNativeSize 규칙을 쓰지 말고 화면1920×1080에 맞춰 표시한다.

그리기 순서는 배경 보정본 → 틀 → 기존 기울인 메뉴다. 캐릭터와 TMP는 기존 게임 구성을 사용한다. 이 작업에서는 Unity 임포터·씬·프리팹·메뉴 셰이더를 변경하지 않았다.

## 검증과 재생성

Contact_Sheet.jpg와 Assembly_Lobby.jpg는 폭1120이며 후자는 배경과 틀만 조립한 화면이다. 원본 PNG는 스크립트에서만 읽었다. validation.json에는 알파·출력 크기·메뉴 영역 비침범·배경 왼쪽 원본 보존 검사 결과와 틀 파일 해시가 있다. 배경 원본 해시는 layout.json에 있다.

저장소 루트에서 `python ArtDirection/LobbyTiltMockup/Split_Handoff/build_split.py` 실행(Pillow·NumPy 필요). 같은 입력과 라이브러리 버전에서 재현 가능하며 PNG6장·JSON·확인용 JPG를 다시 쓴다. README는 유지된다.
