# 로비 2.5D 메뉴 · 틀 다시 그리기 요청서

로비 오른쪽 메뉴 6칸(탐색 개시 · 베이스캠프 · 무기고 · 의뢰 · 마테리얼 · 훈련장)을 명일방주 로비처럼 **원근으로 기울인 판**으로 바꿨다(`Reference_Current_Tilted.png`).

그런데 지금 로비 틀 그림 `UI_Static`(`Reference_UI_Static_Current.png`)은 버튼 6개 자리마다 **버튼 모양대로 구멍이 뚫려 있고 구멍 테두리에 선**까지 그려져 있다. 버튼이 기울면 구멍과 어긋나서 틈마다 배경 장면과 테두리 선이 비친다(`Reference_Problem_Gaps.png`).

이번 작업은 다음 두 가지다.
- 틀 그림을 **메뉴 자리를 비운 조각들**로 다시 그린다.
- 기울어진 메뉴가 **배경 장면 위에 떠 있는** 구성으로 목업을 그린다.

버튼 6개 그림은 그대로 쓴다. 새로 그리지 않는다.

## 0. 공통

- 화면 1920×1080. 로비 키트 원본 크기는 1672×941이고 게임에서 1.15배로 띄운다. **좌표는 1920×1080 화면 기준**으로 적는다.
- 색은 지금 로비와 같다.
  - 종이 #EEF0F2
  - 먹색 #16181B
  - 청록 #0DB8F2 (선·점에만)
- 빨강·노랑·금색, 반투명 판, 글로우는 쓰지 않는다. 그림자는 **불투명 색으로 굽는다.** 알파 그림자를 쓰면 Linear 색공간에서 회색으로 뜬다.
- 글자는 그리지 않는다.
  - 글귀(EXPEDITION / PEOPLE …, OBSERVE / PREPARE / DEPART, SOMEWHERE / FURTHER / TOGETHER, VERTEX, 50 / 100)는 이미 게임 글자(TMP)로 얹혀 있다.
  - 목업에는 넣어도 되지만 조각에서는 뺀다.

## 1. 기울인 메뉴 (그대로 둠)

- 메뉴 6칸은 한 판으로 세로축 −14°, 가로축 2° 기울어 있다.
  - 오른쪽이 안쪽으로 물러난다.
  - 마우스를 따라 ±2.5° 흔들린다.
- 차지하는 범위는 대략 화면 **x 960~1880, y 100~1010**이다. 흔들림 여유를 두고 이 범위 안에는 틀 장식을 두지 않는다.
- 각도는 확정이 아니다. 목업에서 −10°~−16° 사이로 보기 좋은 값을 제안해도 된다.

## 2. 틀 조각 (메뉴 자리는 비움)

지금 `UI_Static` 한 장을 아래 조각으로 나눠 다시 그린다. **메뉴 자리에는 아무것도 없고 배경 장면이 보인다.**

| 조각 | 내용 | 대략 위치 (1920×1080) |
|---|---|---|
| `Frame_LeftBand` | 왼쪽 위 종이 모서리(VERTEX 로고 자리), 왼쪽 아래 종이 모서리(SHELTER 글귀 자리), 화면 가운데를 비스듬히 지나는 큰 종이 사선 띠. 지금 그림의 왼쪽 부분을 그대로 살린다 | 왼쪽 ~ 가운데 |
| `Frame_TopBar` | 오른쪽 위 띠: 진행 막대·설정 버튼 자리 바탕, 오른쪽 끝 세로 헤어라인·십자, "OBSERVE…" 글귀 자리 | 위쪽 y 0~100 |
| `Frame_CornerBR` | 오른쪽 아래 먹색 삼각형 + 흰 사선 + 십자 ("SOMEWHERE…" 글귀 자리). **메뉴 오른쪽 아래 모서리와 겹치지 않게** 지금보다 작게 또는 오른쪽으로 밀어서 | 오른쪽 아래 |
| `Frame_EdgeMarks` (선택) | 화면 가장자리 헤어라인·십자·작은 마름모 같은 자잘한 장식 | 가장자리 |

- 그리는 순서는 배경 장면 → 틀 조각 → 기울인 메뉴다. 틀 조각은 모두 메뉴 **뒤**에 깔린다.
- 지금 그림에서 메뉴를 감싸던 **구멍 테두리 선은 모두 없앤다.**

## 3. 메뉴를 장면에서 띄우기

배경 장면(산·다리·천막)이 밝고 복잡해서 칸이 묻힐 수 있다. 아래 두 방법을 목업에 같이 보여 준다. 둘 다 써도 된다.

| 방법 | 내용 |
|---|---|
| 칸 그림자·두께 | 칸마다 아래·오른쪽으로 짧게 떨어진 **불투명 먹색 그림자**(오프셋 6~10px), 또는 명일방주처럼 칸 옆면 두께(4~6px 띠). 칸 크기별 조각으로 뽑는다: `Shadow_Large`(탐색 개시), `Shadow_Wide`(베이스캠프), `Shadow_Small`(시설 칸) |
| 배경 오른쪽 처리 | 배경 장면의 메뉴 쪽(오른쪽 절반)을 살짝 어둡고 흐리게. **배경 그림 자체에 굽는다** (`Background_RightDim` 변형 한 장, 1672×941 원본 크기) |

## 4. 결과물

목업 2장 (1920×1080):

1. `LobbyTilt_Mockup.png`: 로비 전체. 배경 장면 + 새 틀 조각 + 기울인 메뉴 6칸 + 캐릭터 + 글귀. `Reference_Current_Tilted.png`의 메뉴 모습을 그대로 얹는다.
2. `LobbyTilt_Mockup_Hover.png`: 같은 화면에서 "훈련장" 칸 호버. 칸이 앞으로 살짝 튀어나오고 그림자가 길어진다.

그림 규칙:
- 캐릭터·배경 장면을 새로 그리지 않는다. 배경 오른쪽 처리만 예외다.
- 분절은 목업 확정 뒤 따로 요청한다. 틀 조각은 **2배 해상도**로 다시 그릴 예정이니 선 굵기를 1px 이상으로 잡는다.
