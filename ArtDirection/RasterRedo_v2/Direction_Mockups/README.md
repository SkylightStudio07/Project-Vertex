# Lobby-aligned battle UI concepts

내장 이미지 모델로 전체 화면을 각각 생성한 방향 확인용 목업 3장. 생성 원본을 그대로 저장했다. 기존 PNG 조각이나 게임 에셋은 수정하지 않았다.

- Victory.png: 로비 탐색 패널의 대형 나침반 문양, 옅은 기하학 면, 큰 제목을 가져온 승리 배너.
- Result_Clear.png: 같은 흰 판 디자인에 전장 기록 이미지와 통계 열을 조합한 결과 화면.
- Skill_Banners.png: 카드 일러스트, 먹색 면 분할, 저대비 무기·조준 문양을 겹친 스킬 배너.

PROMPTS.txt에 실제 생성 프롬프트 저장. 사용 참조는 전투 HUD/기존 컷인 목업 및 사용자가 첨부한 로비·무기고 이미지. 목업 배경/HUD/글자는 생성 과정에서 달라질 수 있으며 실제 게임 적용본이나 정확한 분절 규격이 아니다.
