# 재화 표시 바 · 레이아웃 요청서 (드래프트)

로비에 영구 재화 세 가지가 생겼다. 로비 화면 오른쪽 위에 이 재화들을 늘 보여 주는 **재화 표시 바**를 그린다. 이번은 방향을 잡는 **드래프트**다. 시안 몇 개를 비교해 보고 하나를 고른 뒤 다듬는다.

| 재화 | 성격 | 쓰는 곳 |
|---|---|---|
| **탈린** | 흔한 화폐. 런이 끝나면 남은 크레딧 1/10이 들어온다 | 로비 상점 |
| **파츠** | 중간 재화. 전투·의뢰에서 얻는다 | 무기 강화, 시설 강화 |
| **아티팩트** | 희귀 재화. 막 보스 첫 격파, 스토리 의뢰에서만 | 새 무기, 최종 강화 |

이미 있는 **거점 개발도 게이지**("Lv.3  0 / 30" + 청록 막대)도 같은 자리에 있다. 재화 바와 한 묶음으로 정리한다.

- 참고 이미지
  - `Reference_Lobby_Current.png`: 지금 로비. 오른쪽 위에 개발도 게이지와 설정 버튼이 있다. 재화 바는 이 줄에 들어간다.
  - `Reference_Arknights_ResourceBar.png`: 명일방주 상단 재화 바. **구성만** 참고한다. 아이콘 + 큰 숫자 + 일부 재화 옆 [+] 버튼이 한 줄로 늘어선다. 색과 아이콘 모양은 따르지 않는다.
  - `Reference_Armory.png`: 로비 시설 화면(무기고). 재화 바는 시설 화면 오른쪽 위에도 같은 모양으로 들어간다.
- 화면 크기는 1920×1080이다.

## 0. 공통 스타일

- 색:
  - 회백색 #EEF0F2: 판, 칸
  - 먹색 #16181B: 아이콘 칸, 숫자, 선
  - 청록 #0DB8F2: 강조(개발도 막대, [+] 버튼, 늘어난 숫자). 이 셋에만 쓴다.
- **빨강·노랑·금색 금지.** 탈린도 금색 동전이 아니다. 아이콘은 모두 먹색 칸 위 흰 선화(또는 회백색 칸 위 먹색 선화)다.
- 반투명 판과 글로우는 쓰지 않는다. 판은 불투명하다.
- 모서리 절단, 헤어라인, 작은 마름모, `+` 좌표 표식은 로비 키트와 같은 굵기와 각도로 쓴다.
- 숫자는 게임에서 TMP로 얹는다. 목업에는 넣되 평평한 단색 면 위에 둔다.

## 1. 들어갈 요소

| 요소 | 내용 |
|---|---|
| 개발도 | 작은 라벨 "BASE DEV" 또는 "거점 개발도" + "Lv.3" + 얇은 진행 막대(청록) + "0 / 30" |
| 탈린 | 아이콘 + 숫자(예: 1,240) + **[+] 버튼**(로비 상점으로 감) |
| 파츠 | 아이콘 + 숫자(예: 36) |
| 아티팩트 | 아이콘 + 숫자(예: 2). 희귀하다는 느낌이 나게 칸이나 테두리를 한 단계 구분한다(이중선 등). 색은 늘리지 않는다 |
| 설정 버튼 | 지금 있는 톱니 버튼. 바의 오른쪽 끝에 그대로 둔다 |

### 아이콘 방향 (흰 선화, 정사각 칸 안)

| 재화 | 아이콘 아이디어 |
|---|---|
| 탈린 | 각인이 있는 얇은 판/칩 (동전처럼 둥글지 않게, 각진 증서·토큰 느낌) |
| 파츠 | 볼트·톱니가 겹친 부품 |
| 아티팩트 | 각진 결정·코어. 4방향 별(Vertex Mark) 모티프를 살짝 섞는다 |

## 2. 시안 (3가지를 한 장씩)

같은 요소를 배치만 다르게 해서 비교한다.

| 시안 | 배치 |
|---|---|
| **A. 한 줄 바** | 명일방주처럼 오른쪽 위 한 줄: [개발도 Lv·막대] · [탈린] · [파츠] · [아티팩트] · [설정]. 칸마다 얇은 사선 구분선 |
| **B. 두 줄 묶음** | 윗줄: 개발도(라벨 + Lv + 넓은 막대) / 아랫줄: 탈린 · 파츠 · 아티팩트 작은 칩 3개. 오른쪽 위 모서리에 사선 절단된 종이 판 하나로 묶음 |
| **C. 칩 분리** | 개발도는 지금 자리 그대로, 재화 3개는 각각 떨어진 작은 먹색 칩(아이콘 칸 + 회백색 숫자 칸) |

- 세 시안 모두 오른쪽 위, 화면 상단 약 y 20~110 안에 들어가게 한다. 왼쪽의 "VERTEX" 로고, 오른쪽 끝 장식과 겹치지 않는다.
- 숫자 자리는 다섯 자리(99,999)까지 들어갈 폭으로 잡는다.

## 5. 추가 요청: 시안 D (명일방주식 무테 배치) — 2026-10-21

A·B·C를 검토한 결과, 칸·테두리·이름표·구분선이 많아 복잡하다. **명일방주 로비 오른쪽 위처럼 판 없이 띄우는 방식**으로 시안 D를 하나 더 그린다.

- 참고: `Reference_Arknights_Lobby.png` (명일방주 로비 오른쪽 위). 재화가 **판·칸 없이** "아이콘 + 큰 숫자 + 작은 (+)"로만 떠 있고, 그 위에 배터리·시간이 아주 작은 한 줄로 붙어 있다.

```
                 BASE DEV  Lv.3  ━━━━━━──────  0 / 30          ← 위 작은 한 줄 (명방의 배터리·시간 자리)
   [탈린] 1,240 (+)     [파츠] 36     [아티팩트] 2        ⚙      ← 큰 숫자 줄
```

| 요소 | 그리는 법 |
|---|---|
| 판·칸 | **없음.** 테두리, 아이콘 칸, 구분 사선, 이름표("탈린" 등) 모두 빼고 로비 배경(종이색) 위에 바로 놓는다 |
| 아이콘 | 칸 없이 아이콘만. 크기는 숫자 높이 정도. 먹색 선화 또는 먹색 면 + 회백색 선. 탈린 = 각진 칩, 파츠 = 톱니, 아티팩트 = 별 결정(지금 시안과 같은 모양) |
| 숫자 | **크고 굵게**(화면 약 30px), 먹색. 명방처럼 숫자가 주인공 |
| (+) | 탈린 숫자 바로 옆 작은 원형 (+). 청록 면 + 흰 십자 |
| 아티팩트 구분 | 아이콘 둘레에 얇은 이중 마름모 테두리 하나만. 색은 늘리지 않는다 |
| 개발도 | 큰 숫자 줄 **위**에 작게 한 줄: "BASE DEV  Lv.3" + 가는 청록 막대(2px) + "0 / 30". 명방의 배터리·시간처럼 작고 가볍게 |
| 설정 | 톱니 아이콘만, 판 없이 줄 오른쪽 끝 |

- 위치: 지금 로비 오른쪽 위, 메뉴("탐색 개시" 판) 위 빈 띠 안. 메뉴를 옮기거나 다시 그리지 않는다.
- 결과물: `CurrencyBar_D_Mockup.png` (1920×1080, 지금 로비 위). 오른쪽 아래에 2배 확대본 하나.

## 6. 확정 방향: 시안 D 다듬기 → 기본 틀 + 목업 — 2026-10-21

시안 D(판 없는 배치)로 간다. 로비 오른쪽 위 종이 띠는 그대로 둔다. 명일방주처럼 **아이콘과 숫자를 굵고 크게** 해서 띠 위에서도 또렷하게 만든다. 그림자 효과는 우리 쪽에서 포토샵으로 따로 넣으므로, **이번 결과물에는 그림자를 넣지 않는다.**

```
              BASE DEV  Lv.3  ━━━━━━──────  0 / 30
   ◆ 1,240 (+)      ⚙ 36      ✦ 2                ⚙(설정)
```

| 요소 | D 대비 바꿀 점 |
|---|---|
| 숫자 | 더 크고 굵게. 화면 약 34px, 가장 굵은 굵기. 먹색 |
| 아이콘 | 숫자 높이보다 살짝 크게(약 38px). **선 굵기를 두 배**로, 면을 채운 실루엣 쪽으로. 작게 봐도 모양이 구분되게 |
| 아이콘 간격 | 재화 묶음 사이를 D보다 넓게(약 48px). 구분선은 넣지 않는다 |
| (+) | 원형 청록 면 + 흰 십자, 숫자 오른쪽에 바짝 |
| 아티팩트 | 이중 마름모 테두리는 유지 |
| 개발도 줄 | D와 같은 가는 한 줄. 막대 2px, 글자 작게 |
| 그림자 | **넣지 않는다** (포토샵에서 따로) |

## 7. E 수정 지시 — 2026-10-21

E의 숫자 크기·굵기, (+), 개발도 줄은 좋다. 아래만 고친다.

| # | 문제 | 고칠 것 |
|---|---|---|
| 1 | 기본 틀 조각(`Extracted_Draft/`, `layout.json`)이 없다 | 6절 결과물 2번을 **반드시** 만든다 |
| 2 | 탈린이 입체 금괴(골드바)다 | **평면** 각진 칩: 모서리 하나가 잘린 납작한 사각 토큰 + 가운데 작은 각인(마름모 또는 "T"). 입체감·금괴 모양 금지 |
| 3 | 파츠가 설정 버튼과 같은 톱니다 | **톱니 금지.** 육각 너트 + 볼트가 겹친 실루엣(또는 렌치). 바로 옆 설정 톱니와 한눈에 달라야 한다 |
| 4 | 아티팩트 이중 마름모가 빠졌다 | 4방향 별 결정 둘레에 얇은 **이중 마름모 테두리**를 다시 넣는다 |
| 5 | 로비 배경을 다시 그렸다 | 목업은 `Reference_Lobby_Current.png`를 **그대로** 깔고 그 위에만 그린다. 메뉴·캐릭터를 새로 그리지 않는다 |

- **아이콘·막대·(+) 조각은 이미지 생성이 아니라 벡터(SVG)로 그린 뒤 PNG로 내보낸다.** 단순 도형이라 벡터가 정확하고 굵기도 맞추기 쉽다.
- 결과물: `CurrencyBar_F_Mockup.png` + `Extracted_Draft/` (6절 목록 그대로) + 아이콘 3종을 한 장에 모은 `Icons_Sheet.png`.
