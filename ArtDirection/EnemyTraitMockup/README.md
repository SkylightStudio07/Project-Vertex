# 적 속성 표시 방향 목업

내장 image_gen으로 완성 화면3장 생성. SVG·도형 조립 미사용. 분절과 게임 적용은 하지 않았다. 실제 프롬프트는 PROMPTS.txt.

- Battle_Traits.png: 창고 전투에 적3명. 왼쪽 미상?, 가운데 기계, 오른쪽 인간/중장갑. 오른쪽 이름표는 이름과 속성 두 줄. 상태 아이콘은 HP왼쪽의 숫자 있는 정사각형, 속성은 오른쪽의 숫자 없는 잘린 칩으로 분리했다.
- Battle_Traits_Targeting.png: 같은 장면에서 철갑 사격을 오른쪽 적에게 겨냥. 중장갑 칩만 청록 활성, 인간은 먹색 유지. 카드 설명에도 방패와 중장갑 특효/피해×1.2 표시.
- Archive_Traits.png: 적 기록에 속성 줄, 기록2편 공개 전후 비교, 12종 범례를 부록으로 추가. 황금시대도 뼈흰색 단색이다.

반환된1672×941 원본을1920×1080 PNG로 리샘플링했다. 이미지 모델 편집이므로 참조 장면의 인물·HUD·글자·칩 외곽이 픽셀 단위로 동일하지는 않다. 세 적 구성을 위해 적과 HP/인텐트를 추가했고, 큰 인텐트 설명 팝업은 비웠다. 칩 공통 규격은 약32×28px, 글리프18~20px 의도로 제작했으며 최종 공통 외곽과 소형 아이콘 판독성은 승인 후 분절 단계에서 고정/검수한다. 기록 화면은 범례 확인을 위해 여유 있게 표시했다. 경장갑/중장갑 글리프는 기록 상단과 범례에 세부 차이가 있어 최종 아이콘은 범례를 기준으로 통일할 필요가 있다.

검토: 미상 단일칩, 공개1/2개, 중장갑만 활성, 이름표2줄, 기록2편 공개 안내,12종 이름 모두 포함. HP는 회백색으로 수정했다. Reference와 게임 Assets는 변경하지 않았다.
