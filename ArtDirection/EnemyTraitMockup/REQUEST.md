# 적 속성 표시 · 방향 목업 요청

전투 중 적에게 **속성**(인간 · 기계 · 중장갑 등 12종)을 보여 주는 UI를 새로 디자인한다.
지금은 임시 글자 태그만 붙어 있다(`Reference/`). 이번에는 **방향 목업만** 받고, 분절은 목업이 확정된 뒤 따로 요청한다.
작업 방식은 `../UI_Mockup_Split_Workflow.md`를 따른다.

## 게임 규칙 (그림이 이걸 보여 줘야 한다)

- 적 하나가 속성을 **0~3개** 가진다. 카드 중에는 특정 속성에 **특효**(피해 ×1.2)인 카드가 있다.
- 속성은 그 적을 충분히 잡아 본 뒤에 공개된다(적 기록 2편). **공개 전에는 `?`** 하나만 보이고, 마우스를 올리면 "속성 미상 — 추가 탐색 필요"가 나온다.
- 공개 뒤에는 속성마다 **아이콘 칩**이 하나씩 뜬다. 이름 글자는 마우스를 올렸을 때 나오는 이름표에서 보여 준다.
- 특효 카드를 들고 그 속성을 가진 적을 겨냥하면, 맞는 속성 칩이 **청록으로 켜진다**.

## 속성 12종 · 아이콘 방향

흰(또는 뼈흰색) 단색 글리프로, 화면에서 **18~20px**로 보여도 실루엣만으로 구분되어야 한다. 굵은 선, 디테일 최소.

| 속성 | 아이콘 방향 (제안 — 더 나은 안이 있으면 바꿔도 됨) |
|---|---|
| 인간 | 사람 머리 · 어깨 실루엣 |
| 기계 | 톱니바퀴 |
| 경장갑 | 얇은 판 한 장 (방탄판) |
| 중장갑 | 두껍게 겹친 판 / 육중한 방패 |
| 신비 | 눈 하나 |
| 차원 | 어긋나게 겹친 사각 틀 (틈) |
| 파도 | 물결 세 줄 |
| 사이킥 | 머리 옆 동심 파동 |
| 호문클루스 | 플라스크 속 작은 형체 |
| 별 | 네 갈래 별 |
| 근원 | 동심원 가운데 점 (핵) |
| 황금시대 | 월계 / 해 원반 — **금색은 쓰지 않는다**, 모양으로만 |
| (미상) | `?` |

## 목업 3장

### 1. `Battle_Traits.png` — 전투 화면 (`Current_Trait_Known.png` 장면)

적 셋을 세우고 각각 다른 상태로:

| 적 | 상태 |
|---|---|
| 왼쪽 | 속성 미상 — `?` 칩 하나 |
| 가운데 | 속성 하나 공개 (기계) |
| 오른쪽 | 속성 둘 공개 (인간 · 중장갑), **마우스 올린 상태** — 이름표 두 줄: 이름 / "속성 · 인간 · 중장갑" |

HP바 · 상태 줄 · 인텐트 · 손패는 지금 게임 그대로 두고, 속성 칩과 이름표만 새로 그린다.

### 2. `Battle_Traits_Targeting.png` — 같은 장면, 특효 카드 겨냥

- 손에서 "중장갑 특효" 카드를 끌어 오른쪽 적을 겨냥 중.
- 오른쪽 적의 **중장갑 칩만 청록으로 켜지고**, 인간 칩은 그대로.
- 카드 설명 앞의 "중장갑 특효." 문구 옆에 같은 아이콘을 작게 붙인 안도 보여 준다(카드 쪽 표시 제안 — 선택).

### 3. `Archive_Traits.png` — 적 기록 상세 (`Material_Dark_Enemy.png` 화면)

- 적 머리 정보 줄(이름 · 등급 · 격퇴 수 · 기록 n/5) 아래에 **속성 줄**: 칩 + 이름.
- 공개 전이면 `?` 칩 + "속성 미상 — 기록 2편에서 공개". 한 장 안에 공개 전 / 공개 후를 작은 비교 칸으로 같이.
- 화면 한쪽에 **12종 범례**(아이콘 + 이름)를 기록 서류의 부록처럼 넣는다. 아이콘 12개 디자인을 한 번에 확인하려는 용도.
