# 적 속성 분절

PNG17장: 공용 칩3장, 흰 글리프13장, 기록 이름 판1장. SVG 미사용. 칩 표면은 내장 image_gen으로 생성한 무광 먹색 원화를 사용하고, Active는 그 표면의 미세 톤을 청록으로 매핑했다. 외곽과 얇은 테두리만 래스터 마스크로 처리했다. 실제 생성 프롬프트는 PROMPTS.txt, 원화는 Generated/Chip_Material.png.

글리프는 확정 Archive_Traits.png의 범례에서 밝기 기반 알파로 직접 추출했다. ?는 같은 이미지 해금 비교 칸에서 추출했다. 도형이나 폰트로 다시 그리지 않았다. 경장갑은 범례의 휜 판 한 장, 중장갑은 두꺼운 방패를 사용한다. 모든 유효 글리프 픽셀 RGB는 순백색이며 가장자리만 soft alpha다.

## 크기와 배치

정본1920×1080에서 오른쪽 중장갑 칩의 외곽은 약46×38px로 측정했다(래스터 가장자리 약1px 오차). 요청의 약36×32보다 크므로 실측을 우선했다. 칩·그림자·글리프 모두92×76 PNG, 같은 원점. 글리프 유효 영역은 최대40×40 PNG = 화면20×20px, 비율 유지 및 가운데 정렬. 18px 확인 행은 실제 유효 글리프를18px 이내로 줄인 결과다.

HP바 기준 오른쪽 위 모서리에서 오른쪽 끝 칩 원점(-36,-46), 다음 칩은 왼쪽49px(칩46+간격3)씩 이동한다. 이 값은 목업 오른쪽 칩이 HP바 오른쪽보다10px 나오는 모습까지 반영한다. 그림자는 동일 캔버스를 화면(+2,+2) 이동하고 불투명도0.5로 표시한다. 글리프는 공개#FFFFFF, 미상#E2E5E6, 켜짐#101A20. 대응되는 칩만 Chip_Active로 바꾼다. 미상은? 하나, 공개 후 속성0개는 표시하지 않는다.

기록 이름 판은144×46px 기준, 안쪽 칩 원점(4,4), 묶음 간격13px. 이름은(64,11)부터19px로 그린다. 가로9-slice 경계는 PNG 기준 L108/B12/R20/T12. 가운데는 글자 없는 생성 먹색 표면이다. 별104px와 호문클루스184px 너비 샘플 포함.

## 검증 및 범위

17PNG 크기·판 이진 알파0/255·칩3종 동일 알파·글리프 순백RGB·공통 캔버스 검사 통과. Contact_Sheet.jpg에 먹색/청록 조립,18px13종, 이름 판 늘림, 정본 좌표 재조립 비교를 담았다. 범례의 황금시대 월계 등 세부는18px에서 작아지므로 확대 원화와 축소 행을 함께 확인할 수 있다.

재조립은 정본 배경 위에 새 칩/기록 머리 줄만 교체한 검토 화면이다. HP·인텐트·인물·카드·범례는 비교 배경일 뿐 납품 조각에 없다. 기록 해금 비교 및 범례 패널, 카드 설명 앞 방패는 분절하지 않았다. 게임의 빨간 HP바는 그대로 사용한다. 게임 Assets는 수정하지 않았다. 원화 재생성 때문에 칩 표면의 미세 톤은 정본과 차이가 있다.
