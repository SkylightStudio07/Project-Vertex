# 동료 탭 · 레이아웃 요청서

로비 좌하단 **동료(04)** 버튼으로 여는 화면. 합류한 동료를 모아 보고, 동료마다 **전력 정보**(지시 스킬 · 동료 카드 · 호감도 단계별 해금)를 확인하는 곳이다. 대화·선물·랭크업 이벤트는 베이스캠프 몫이라 여기에는 없다.

화면은 두 장: **① 목록** → 칸을 누르면 **② 상세**.

- 참고
  - `Reference_Arknights_List.png`: 명일방주 오퍼레이터 목록. **① 목록의 구성만** 참고: 세로로 긴 초상 카드 격자, 카드 아래 이름 띠·작은 정보, 위쪽 정렬 탭.
  - `Reference_AstraeOratio_Poster.png`: 아스트래 오라티오 캐릭터 소개. **② 상세의 분위기** 기준: 화면을 사선으로 나눈 먹색/회백 두 면, 전신이 가운데 경계 위에 서고, 먹색 쪽에 대사 한 줄(「」), 회백 쪽 아래에 소속·이름·영문.
  - `Reference_Arknights_Detail.png`: 명일방주 상세. **정보 항목만** 참고(레벨·신뢰도 막대·스킬 칸). 명방처럼 칸을 빽빽하게 늘어놓지 **않는다** — 정보는 오른쪽 한 열에 여백 넉넉히.
  - `Reference_Shop_Facility.png`: 로비 시설 화면 공통 문법(제목 판 `04 동료 / COMPANIONS`, `← 로비` 버튼).
- 색: 회백 #EEF0F2 · 먹색 #16181B · 강조 청록 #0DB8F2 (로비 공통, 빨강·금색 금지). 화면 1920×1080.
- 캐릭터 그림은 **새로 그리지 않는다**. 목업에는 견본 실루엣이나 기존 동료 그림 자리만 둔다(게임에서 `sanctuaryFullArt`·얼굴 크롭을 넣는다).

## ① 목록

- 제목 판(왼쪽 위) · `← 로비`(오른쪽 위) · 정렬 탭 3개 `합류순 / 호감도 / 막` (오른쪽 위, 로비 버튼 왼쪽).
- **초상 카드** 약 200×330, 한 줄 6장 · 2줄. 카드 = 위쪽 얼굴~상반신 크롭, 아래 먹색 띠에 이름 + 소속 한 줄, 오른쪽 위 호감도 Lv 숫자, 아래 가장자리에 호감도 단계 칸 5개(청록 채움).
- 상태: 보통 / 마우스 올림(청록 테두리, 살짝 위로) / **미합류**(먹색 실루엣 + `???` + 합류 조건 한 줄, 예 "2막 구출 의뢰").
- 칸이 비면 그 자리는 옅은 빈 틀.

## ② 상세 (아스오라 포스터 구도)

```
┌─────────────── 사선 경계 ───────────────┐
│ 먹색 면                    ╱  회백 면              │
│  「대사 한 줄」            ╱   ┌ 호감도 Lv.3 ■■■□□ ┐ │
│                          ╱    │ 지시(스킬) 카드     │ │
│        [ 전신 ]          ╱     │ 동료 카드 목록      │ │
│                        ╱      │ 단계별 해금 Lv1~5   │ │
│                      ╱  소속 · 이름 · 영문           │
└────────────────────────────────────────┘
```
- 화면을 **왼쪽 위 → 오른쪽 아래로 가는 사선**으로 나눈다. 왼쪽(넓게) 먹색, 오른쪽 회백. 경계선 위에 아주 가는 청록 선.
- **전신**: 경계선 위 가운데~왼쪽. 그림 주변에 작은 반짝임(✦)·마름모 몇 개.
- **대사**: 먹색 면 왼쪽 위, 「」로 감싼 한두 줄 (게임에서 `campLines` 중 하나).
- **이름 블록**: 회백 면 아래 — 소속 작게(+ ✦), 이름 크게, 영문 작게. (아스오라 오른쪽 아래와 같은 자리·비율)
- **정보 열**(회백 면 오른쪽 위~가운데, 폭 약 520):
  1. 호감도 `Lv.3 / 5` + 진행 막대(청록) + 다음 단계까지 포인트
  2. **지시(스킬)**: 아이콘 칸 + 이름 + 설명 2~3줄 + `최대 호감도 시 강화` 표시
  3. **동료 카드**: 작은 카드 썸네일 가로 한 줄(4~6장), 잠긴 것은 자물쇠
  4. **단계별 해금**: Lv1~Lv5 세로 목록 — 각 줄에 무엇이 열리는지(기록 1편 / 카드 / 스킬 강화), 열린 줄은 먹색 글자, 잠긴 줄은 회색 + 자물쇠
- 하단 작은 버튼 2개: `기록 보기`(아카이브 동료 기록으로), `베이스캠프에서 만나기`.
- 좌우 화살표(`‹ ›`)로 이전/다음 동료.
