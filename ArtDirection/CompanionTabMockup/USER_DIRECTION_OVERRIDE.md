## 분절 납품 (2026-10-22)

SPLIT_REQUEST.md에 따라 목록/상세 v2 확정본을 SVG로 재구성했다. 결과는 Extracted_Draft/, 묶음은 Companion_v2_Package.zip. 픽셀 단위 원본 크롭이 아닌 편집 가능한 벡터 재구성이므로 배경/그림자의 세부 표현은 목업과 차이가 있다.

- 37 PNG(1920×1080 배경 2장, 2배 UI 34장, 원본 캐릭터 1장)와 SVG 36개.
- 목록 페이지 표시 삭제. 넘치는 동료는 세로 스크롤.
- 상세 음성 표시는 삭제하고 대사 넘기기 `‹ LINE 01 / 03 ›` 적용.
- Lv.1~5 모두 대응하는 동료 기록 I~V를 표기하고 추가 해금을 함께 표시.
- 이름/설명/레벨 등 글자는 layout.json에 별도 보관. PNG/SVG에 글자 없음.
- 프레임은 9-slice, 가운데 +/잠금 기호와 그림자는 별도 레이어. 정보 판 머리 띠는 48 논리 픽셀 고정.
- Chara_ChiharaSho_Full.png는 프로젝트의 기존 투명 원본을 바이트 단위로 동일하게 복사했다. 생성 목업 속 재해석된 전신을 추출한 것이 아니다.
- Companion_List_Assembly_v2.png / Companion_Detail_Assembly_v2.png는 조각으로 재조립한 검토본. 목록 잠김 실루엣과 상세 카드 그림은 배치 확인용 자리표시이며 실제 동료/카드 아트로 교체한다.
- validation.json에 크기, 글자 분리, 9-slice 범위, 필수 수정사항 검사 결과 기록. ZIP 무결성도 확인했다.

## 이전 방향 변경 이력

사용자 최신 지시가 기존 LAYOUT_BRIEF.md의 아스오라 포스터 구도보다 우선한다.

- 기존 상세의 큰 흑백 사선 분할은 아스오라와 너무 유사하므로 변경한다.
- 명일방주처럼 깔끔한 기하학 도형 배경에 캐릭터를 배치한다.
- 도형, 캐릭터, 정보 패널에 그림자를 적극적으로 사용한다. 기존 통합 지침의 그림자 절제 원칙보다 이 화면에 대한 사용자 지시가 우선한다.
- 참고: Reference_Arknights_Geometry_Shadow.png.

## 현재 목업

- Companion_List_Mockup.png: 6열×2줄 동료 목록 초안.
- Companion_List_Mockup_v2.png: 사용자가 상세 v2 방향을 수락하고 목록에도 적용하도록 요청한 후 제작한 최신 목록 검토안. 6열×2줄 구성과 초상/잠김/빈 칸은 유지하고, 회백·먹색 도형 배경과 카드/제목 판 그림자로 상세 v2와 통일했다. 내장 image_gen 사용, 프롬프트는 GENERATION_PROMPT_List_v2.txt. 분절 전 목업이다.
- Companion_Detail_Mockup_v1.png: 이전 아스오라 구도, 비교용 보존.
- Companion_Detail_Mockup_v2.png: 사용자가 수락한 스타일 기준. 회백·먹색 도형을 겹치고 캐릭터/패널 그림자를 추가했다. 이름은 좌하단, 정보는 오른쪽 세로 패널에 배치했다.

내장 image_gen으로 생성했다. 생성 프롬프트는 GENERATION_PROMPT_List_v1.txt, GENERATION_PROMPT_Detail_v1.txt, GENERATION_PROMPT_Detail_v2.txt에 있다. 목록 생성 후 호감도 표시를 5칸으로 수정했고, 상세 v1은 전신이 화면 안에 들어오도록 보정했다. PNG는 생성 도구의 원본 해상도(1672×941)를 보존했으며 요청서의 1920×1080 제작 좌표 확정/분절은 아직 진행하지 않았다.

캐릭터는 기존 아트를 참조한 생성 목업이므로 원본 픽셀 보존 합성본이 아니다. 단계별 해금·호감도·카드 내용 일부는 배치 검토용 예시다. 실제 제작 시 원본 캐릭터 레이어와 게임 데이터를 사용한다.
