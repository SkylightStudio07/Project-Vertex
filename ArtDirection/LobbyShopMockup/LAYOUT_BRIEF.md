# 로비 상점 · 레이아웃 요청서

로비 메뉴 05 **상점** 화면. 탈린으로 파츠·선물·무색 카드 해금을 산다. 기획: `Docs/기획/로비_상점.md`

- 참고 이미지
  - `Reference_Shop_Draft.png`: **이 시안이 기준이다.** 왼쪽 캐릭터(보급 담당, 우리 캐릭터 — 그대로 쓴다), 오른쪽 탭 + 3×2 상품 칸, 아래 구매 바, 왼쪽 아래 대사창. 구성·색·판 모양은 유지하고 아래 1절만 고친다.
  - `Reference_Armory.png`: 같은 로비 시설 화면(무기고). 제목(번호 + 한글 + 영문 캡션), 오른쪽 위 `← 로비` 버튼, 탭, 잠긴 카드 `???` 칸을 **이것과 똑같은 모양·자리**로 맞춘다.
  - `Currency_Icons/`: 로비 재화 바에서 쓰는 재화 아이콘(먹색판 + 흰색판). **새로 그리지 않고 이것을 그대로 쓴다.**
  - `References/`: 다른 게임 상점(Wildfrost, Darkest Dungeon). 구성 참고용이다. 색·질감은 따르지 않는다.
- 화면 크기 1920×1080.

## 1. 시안에서 고칠 것

| # | 고칠 것 | 내용 |
|---|---|---|
| 1 | 재화 아이콘 | 위쪽 재화 줄과 가격 앞 아이콘을 `Currency_Icons/`의 탈린·파츠·아티팩트로 바꾼다. 시안의 화살촉·육각 너트·별 아이콘은 쓰지 않는다 |
| 2 | 구매 바 | `보유 1,240 → 구매 후 1,120`처럼 **바뀐 뒤 잔액**을 보여 준다. 그 옆에 **수량 선택** `− 1 +`, 합계 가격(청록, 크게), `구매하기` 버튼 |
| 3 | 재고 | 파츠 상품 칸 오른쪽 위에 `재고 2/3`. 다 팔리면 칸 전체를 흐리게 + 가운데 `품절` 띠 |
| 4 | 무색 카드 | 상품 그림 자리에 **카드 앞면**(무기고 카드 칸과 같은 모양). 해금 전: 그대로 + 가격. 해금 후: `해금 완료` 띠, 가격 자리 비움. 무기고처럼 아직 안 열린 카드는 `???` + 실루엣 |
| 5 | 탈린 부족 | 살 수 없는 칸은 가격 숫자를 회색으로. 구매 바 버튼은 비활성(회색 판) |
| 6 | `← 로비` | 무기고와 같은 크기·자리·판 |

- 대사창: 시안 그대로(이름 띠 `보급 담당` + 대사 1~2줄). 구매·부족·품절 때 대사가 바뀐다.
- 캐릭터: 시안의 캐릭터와 자리를 **그대로** 쓴다. 다시 그리지 않는다.

## 2. 상품 칸

- 3열. 칸 = 번호(`01`) · 상품 그림 · 이름 · 작은 설명(`파츠 ×10` / `선물 · 1개` / `카드 · 해금`) · 가격(탈린 아이콘 + 숫자).
- 고른 칸은 청록 테두리(시안 그대로).
- 상품 그림은 회백 배경 위 사물 일러스트(시안 톤). 지금 필요한 것:
  - 파츠 묶음, 보급 패키지(파츠 큰 묶음), 따뜻한 커피, 기록 노트
- 칸이 6개를 넘으면 세로 스크롤.
