# 카드 목록 분절 키트

승인된 Armory_CardCatalog_Mockup_v1.png의 실제 픽셀을 기준으로 추출. 글자 영역만 내장 이미지 모델의 제거 결과로 교체했다. 빈 패널과 강화 불가 상태는 모델 복원/편집 결과다.

## 강화 버튼 교체

- 정상: Upgrade_Normal.png / 호버: Upgrade_Normal_Hover.png
- 비활성: Upgrade_Disabled.png — 호버 없음, 상호작용 비활성 권장.
- 세 상태 공통: 좌상단 (1157, 808), 크기 428×90. 외곽 투명 마스크와 피벗을 공유.
- 비활성 문구는 별도 UI 텍스트로 **강화 불가**. 설명이 필요하면 **무기고 강화 대상이 아닙니다**. 이미지에는 번역용 텍스트를 구워 넣지 않았다.
- 강화 불가 카드는 무기고 강화 단계 텍스트도 숨기거나 대체한다. 비용 부족/최대 강화/미해금과는 별도의 상태로 취급한다. 이 동작은 아직 구현하지 않았다.

## 구성과 배치

`layout.json`에 모든 PNG의 좌표·크기·호버 관계·상태 매핑이 있다. 기준 캔버스 1672×941, 좌상단 원점.

- UI_Base_WithControlHoles + controlLayers를 조립하면 Reassembled_Textless를 재현한다.
- Reassembled_AllHover는 호버 확인용으로 여러 요소가 동시에 강조된 미리보기다.
- Preview_Disabled_Textless는 오른쪽 아래만 강화 불가 패널로 바뀐 글자 없는 미리보기다.
- Backing_*은 카드/필터 콘텐츠를 바꿔 넣기 위한 빈 패널. 원본의 숨겨진 레이어가 아니라 모델 복원본이다.
- *_Composite는 검토용 묶음. 하위 조각과 중복 배치하지 않는다.
- Card_*은 목업 카드 전체, Art_*은 삽화 크롭이다. 실제 카드 프리팹 교체 전 디자인 참고용이며 잠금 아이콘과 기호가 합쳐진 삽화가 있다.
- 체크박스 및 작은 기호는 사각 크롭으로 종이 바탕이 남아 있다. 모든 이미지가 독립 누끼는 아니다.
- Source_*는 텍스트 포함 원본 보존 조각이다.

조립 검사는 텍스트 없는 마스터와 베이스+컨트롤의 픽셀 일치만 확인한다. 모델 복원본의 정확성이나 Unity 연결 검증은 아니다. 이번 작업에는 Unity 임포트/프리팹 배선이 포함되지 않는다.
