# 전투 보상 화면 · 레이아웃 요청서

전투에서 이기면 "작전 종료" 띠(`Reference_Victory.png`)가 지나간 뒤 이 보상 화면이 뜬다.

지금 화면(`Reference_Current_Reward.png`)은 v1 이전의 아이보리 판이다. 육각 아이콘, 금색 동전, 영어 제목 Reward를 쓰고 있어서 나머지 화면과 결이 다르다. 이번에는 **로비, 상점, 결과 화면과 같은 가족**으로 다시 그린다.

- 스타일 기준:
  - `Reference_LobbyMain.png`: 로비. 종이 판, 먹색 띠, 헤어라인, 번호.
  - `Reference_Shop.png`: 상점 v2. 같은 전투 노드 화면의 최신 판이다.
  - `Reference_ResultClear.png`: 결과 화면. "작전 보고서" 문법.
  - `Reference_BattleHUD_v3.png`: 뒤에 깔리는 전투 화면.
- 화면 크기는 1920×1080이다.

## 0. 공통 스타일

- 색:
  - 종이 #EEF0F2: 판과 줄
  - 먹색 #16181B: 띠, 글자, 아이콘 칸
  - 청록 #0DB8F2: 가는 선, 작은 칸, 강조. 이 셋에만 쓴다.
- **빨강, 노랑, 금색 금지.** 골드 아이콘도 금색 동전이 아니라 먹색 칸 위 흰 선화로 그린다.
- 반투명 판, 글로우, 별·꽃잎은 쓰지 않는다. 판은 불투명하다.
- 글자(제목, 보상 이름, 버튼 글자)는 게임에서 TMP로 얹는다. 목업에는 넣되, 나중에 분절할 때 지울 수 있게 평평한 단색 면 위에 둔다.

## 1. 화면 구성

```
┌──────────────────────────────────────────────────────────────────┐
│ (전투 화면 — 먹색 #16181B로 덮은 불투명 0.85 정도. 그림에 굽지 말고 뒤 화면 위에 덮은 모습으로) │
│                                                                    │
│        ┌─ 보상 판 (종이, 약 1000 × 720, 화면 가운데) ───────────┐   │
│        │ REWARD / OPERATION SPOILS            No.03 · FLOOR 03  │ ← 머리띠 (먹색 또는 종이+헤어라인)
│        │ 전리품                                                  │ ← 큰 제목
│        │ ─────────────────────────────────────────────────────  │
│        │ [01][■ 아이콘] 18 골드                          →  │   │ ← 보상 줄 (최대 5줄)
│        │ [02][■ 아이콘] 카드 보상    1장 선택             →  │   │
│        │ [03][■ 아이콘] 군용 구급키트  아이템             →  │   │
│        │                                                        │
│        │ ─────────────────────────────────────────────────────  │
│        │  남은 보상 2                          [ 계속 → ]       │ ← 바닥: 상태 글자 + 주 버튼
│        └────────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────┘
```

| 부분 | 내용 |
|---|---|
| 보상 판 | 종이 판. 로비처럼 모서리 하나를 사선으로 자른다. 가장자리 헤어라인, 십자 표식, 나침반 워터마크 1개(명도 차 4% 이내) |
| 머리 | 작은 영문 라벨 "REWARD / OPERATION SPOILS" + 큰 한글 "전리품" + 오른쪽 작은 번호 칸(층 번호 자리) |
| 보상 줄 | 가로로 긴 종이 줄. 왼쪽부터 번호(01) → **먹색 정사각 아이콘 칸**(흰 선화 아이콘) → 보상 이름(굵게) → 작은 회색 설명(“1장 선택”, “아이템”) → 오른쪽 화살표. 상점 v2의 상품 줄과 같은 문법 |
| 줄 호버 | 왼쪽에 청록 세로 띠 + 테두리 청록 + 아이콘 칸 그대로. 목업에서 두 번째 줄을 호버 상태로 그린다 |
| 받은 줄 | 줄은 연출로 사라지므로 따로 그리지 않는다 |
| 바닥 | 왼쪽 작은 상태 글자("남은 보상 2"), 오른쪽 주 버튼 "계속 →". 먹색 버튼 + 청록 짧은 선(턴 종료 버튼, 로비 버튼과 같은 문법) |

### 아이콘 (흰 선화, 먹색 칸 위)

| 보상 | 아이콘 |
|---|---|
| 골드 | 동전 더미 또는 크레딧 칩 선화 (금색 금지) |
| 카드 | 카드 두세 장 겹친 선화 |
| 아이템 | 게임 아이템 그림이 들어간다(컬러). 목업에서는 구급키트 그림을 칸 안에 넣어 컬러 그림이 들어가도 어울리는지 보여 준다 |

## 2. 카드 보상 화면 (같은 판 안에서 전환)

"카드 보상"을 누르면 같은 화면에서 보상 줄이 사라지고 카드 3장이 뜬다. 하나를 고르거나 건너뛴다.

```
        ┌─ 판 (같은 위치, 넓어져도 됨: 약 1400 × 760) ───────────────┐
        │ CARD REWARD / SELECT ONE                                     │
        │ 카드 선택                                                    │
        │                                                              │
        │     [카드 1]          [카드 2]          [카드 3]             │ ← 카드는 게임 카드(그리지 않아도 됨, 자리만)
        │                                                              │
        │ ──────────────────────────────────────────────────────────── │
        │  덱에 1장을 추가합니다                   [ 건너뛰기 ]         │ ← 보조 버튼 (종이 + 먹색 테두리)
        └──────────────────────────────────────────────────────────────┘
```

- 카드 자리는 게임 카드 크기(약 300 × 420)로 회색 틀만 둔다. 프로젝트 카드 그림을 넣어도 된다.
- 카드 아래 받침(얇은 먹색 선 + 번호 01·02·03)이 있으면 좋다.
- 건너뛰기는 **보조 버튼**이다. 종이 바탕에 먹색 테두리를 쓰고, 주 버튼보다 약하게 그린다.
