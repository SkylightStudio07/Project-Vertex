## 이미지 규칙 (413 방지)

- 모델이 직접 보는 이미지는 **미리보기 JPG뿐**이다(한 번에 2장까지).
- 원본 PNG는 스크립트로 디스크에서만 읽는다.
- 결과 확인은 확인용 시트(1200폭 이하)로 한다.

## ★ 핵심: 2배 해상도로 새로 그린다

- **출력:** 화면 크기의 2배 PNG. 예: 화면에서 460×70인 줄은 920×140.
- **새로 그릴 것:** 판, 줄, 칸, 선, 아이콘, 버튼은 목업을 참고해 2배 캔버스에 **벡터처럼 깨끗하게 다시 그린다.** 목업을 잘라 확대하지 않는다.
  - 헤어라인: 2배에서 2px (화면 1px)
  - 테두리·굵은 선: 2배에서 4px 이상
- **종이 질감:** 2배에서 새로 입힌다. 바탕색은 #EEF0F2, 로비 종이처럼 아주 옅게.
- **좌표:** `layout.json`의 좌표는 **1920×1080 화면 기준(1배)** 으로 적는다. 조각마다 `"scale": 2`와 실제 PNG 크기를 함께 적는다.
- **9-slice:** **2배 PNG 기준 픽셀**로 적는다. Unity에서는 PPU 200으로 임포트한다.
- **알파:** 판과 칸은 0 또는 255만 쓴다.

## ★ 판 하나로 두 화면을 쓴다

보상 목록 판(약 1000×828)과 카드 선택 판(약 1110×800)은 크기만 다르고 생김새는 같다. 그래서 **판은 9-slice 한 장**으로 뽑고 게임에서 크기를 바꾼다.
- 오른쪽 위 사선 모서리, 네 모서리 십자 표식, 가장자리 헤어라인이 늘어나도 깨지지 않게 9-slice 테두리 안에 넣는다.
- 나침반 워터마크는 판에서 빼서 따로 뽑는다(판이 늘어나도 찌그러지지 않게).

## 3. layout.json에 적을 것

두 장면(`reward`, `card`)에 대해 각각 적는다. 좌표는 모두 1배 화면 rect다.

- **판 rect:** 보상 목록, 카드 선택 각각
- **워터마크 위치:** 판 오른쪽 위 기준
- **머리:** 영문 라벨, 큰 제목, 번호 글자 자리 (박스, 정렬, 대략 글자 크기, 색 hex)
- **줄:**
  - 첫 줄 rect, 줄 간격
  - 줄 안 요소 오프셋: 번호, 번호 밑줄, 아이콘 칸, 아이콘, 이름, 설명, 화살표
  - 설명이 없는 줄(골드)은 이름을 세로 가운데에 둔다. 이름의 위치를 두 경우(설명 있음 / 없음) 모두 적는다
- **바닥:** 가로선 y, 상태 글자 자리, 버튼 rect와 버튼 글자 자리
- **카드 선택:** 카드 3장 자리 rect, 받침 rect, 번호 글자 자리
- **9-slice 값**
