# Cut-in category mockup

이미지 모델로 생성한 카테고리 비교 목업. 세 줄은 비교용이며 실제 동시 표시 요구가 아니다. SVG 제작·재합성 없이 모델 원출력을 저장했다.

공용 프레임 + 왼쪽 카드 일러스트 + 중앙 카드명 + 오른쪽 카테고리 문양 구조. 우측 이미지는 개별 카드마다 만들지 않고 POWER / SKILL / ATTACK 세 종류를 재사용한다. 파워는 에너지 코어, 스킬은 연결된 모듈, 공격은 타격 문양. 등급(Unique 등)은 카테고리와 별도 데이터로 취급한다.

이번 산출물은 방향 확인용 목업이다. 우측 문양 PNG 분절 및 게임 적용은 아직 수행하지 않았다. 배경·카드 그림·HUD는 모델 생성 과정에서 변형될 수 있다. 실제 생성 프롬프트는 PROMPT.txt.
