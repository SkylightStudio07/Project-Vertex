# 적 행동 이펙트 방향 목업

`REQUEST.md`와 `../../UI_Mockup_Split_Workflow.md`를 기준으로 제작한 검토용 낱장 그림이다. 모든 최종 PNG는 **1920×1080, RGB, 불투명 배경**이다.

| 파일 | 내용 |
|---|---|
| `Streaks.png` | 216px 높이의 5행. 탄도선 A/B, 포탄 꼬리 A/B, 보라·남색 저주 구체. 왼쪽 꼬리 → 오른쪽 머리. 순흑 배경. |
| `Blasts.png` | 480px 너비의 4열. 화구 폭발 A/B, 가운데가 빈 붉은 주황·금빛 버프, 보라·병든 연두 저주 터짐. 순흑 배경. |
| `Smokes.png` | 서로 다른 검은 갈색 폭연 3종. 불빛 없는 일반 합성용 방향. 정확한 `#808080` 배경. |
| `Battle_EnemyAction.png` | 제공된 게임 캡처 위에 실제 크기로 합성한 화구 A, 폭연, 대각선 포탄 꼬리, 적 뒤의 버프. |
| `PROMPTS.txt` | 실제 사용한 imagegen 프롬프트 전체와 생성 결과 식별 경로. 버프 수정 프롬프트 포함. |

## 배치와 합성

- 줄기 중심 y: 108 / 324 / 540 / 756 / 972. 배치 폭은 각각 1400 / 1000 / 900 / 900 / 600px이다. 빛 번짐까지 각 행 안에 들어간다.
- 화구 A/B는 약 380×600px, 바닥 기준점은 각 열 아래 가운데 `(240,940)` 및 `(720,940)` 부근이다. 버프는 약 400×800px, 바닥 중심 `(1200,940)` 부근이며 몸 자리의 폭 160px을 비웠다. 저주 터짐은 약 380px, 중심 `(1680,540)`이다.
- 게임 목업: 화구 약 190×300px, 바닥 `(382,705)` 부근. 폭연 약 230×300px. 포탄 꼬리는 `(620,340)`에서 `(382,705)` 방향으로 떨어진다. 버프 약 210×420px, 발밑 중심 `(1462,705)` 부근이다.
- 불꽃과 기운은 밝기를 더하는 가산 방식, 폭연은 일반 알파 합성으로 얹었다. 캐릭터와 UI가 앞에 보이도록 원본 영역을 보호했다.

## 제작 방식

모든 불꽃·빛·저주·폭연 표면은 **내장 `image_gen.imagegen` 도구로 그린 래스터 작화**다. SVG, 벡터 도형, 코드로 새로 그린 이펙트 표면은 사용하지 않았다. 후처리는 크기·배치 정리, 검정/회색 배경 수치 정리, 원본 캡처 위의 래스터 합성에 한정했다.

최초 생성한 게임 화면 편집본은 구도 검토에만 사용했다. 최종 게임 목업은 최종 시트의 그림을 원본 캡처에 합성하여 배경·캐릭터·HUD의 재생성 변형을 피했다. 버프는 몸 자리를 더 넓게 비우도록 이미지 도구로 다시 그린 최종안을 사용했다.

참조 네 장과 기존 `../GroundImpact/Sources/`를 확인했다. 기존 크레이터·파편·충격 고리·흙먼지는 새로 그리거나 추가하지 않았다.

## 검수

- 최종 PNG 4장의 크기 1920×1080 확인, 시각 검토 완료.
- `Streaks.png` 행 경계 및 바깥 여백: 순흑 이외 픽셀 0개.
- `Blasts.png` 열 경계 및 바깥 여백: 순흑 이외 픽셀 0개.
- 버프 몸 자리 `x=1120..1279, y=400..939`의 160×540px 영역: 순흑 이외 픽셀 0개.
- `Smokes.png` 열 사이와 바깥 검수 여백: `#808080` 이외 픽셀 0개.
- 게임 목업의 보호한 캐릭터·HUD 영역: 원본 대비 변경 픽셀 0개. 지정한 이펙트 합성 영역 밖: 원본 대비 변경 픽셀 0개.
- 글자·캐릭터·기계 묘사는 효과 시트에 추가하지 않았다. 게임 목업의 글자와 캐릭터는 제공 캡처 원본이다.

## 범위와 해상도

요청된 방향 목업 4장과 프롬프트 기록을 납품했다. 그림 선택 후 진행할 투명 조각 분절, 약 2배 해상도 재생성, Unity 임포트·적용은 이번 납품에 포함하지 않았다. 이미지 도구가 반환한 원본은 시트 1717×916 / 1672×941, 버프 수정안 1221×1288이었으며 최종 목업 규격으로 재배치·리샘플링했다. 따라서 이번 파일을 네이티브 2배 해상도 게임용 원본으로 간주하면 안 된다.

저장한 작업 결과는 이 `EnemyActionFx/` 폴더 안에만 있다. `Assets/`, `Packages/`, `ProjectSettings/` 수정 및 git 사용은 하지 않았다.
