# Crystal Guardian · 근접 휘두르기 시트

납품: `Swing_CrystalGuardian.png` — 1920×1080 RGB PNG, 4열×3행, 각 칸 480×360. 좌상단부터 행 순서. 검정 바탕의 가산 합성용이며 알파는 런타임에서 `max(R,G,B)`로 추출한다.

Built-in imagegen으로 원화와 위치 수정본을 그렸다. 실제 두 생성 프롬프트는 `PROMPTS.txt`에 기록했다. SVG나 코드로 궤적·파편을 그리지 않았다.

## 크기·검정 여백·위치

생성본은 1672×941이었다. 4×3 격자를 유지하여 전체를 1920×1080으로 bicubic 리사이즈했다. 이후 모든 칸에 동일하게 75% 등비 축소와 로컬 오프셋 (+32, 0)을 적용했다: `(x,y) → (0.75x+32, 0.75y)`. 칸별 내용의 바운딩 박스를 기준으로 재정렬하지 않았다. 이는 과하게 아래로 뻗던 생성 궤적을 가이드의 발톱 높이에 맞추는 공통 좌표 보정이다.

그림을 다시 그리지 않는 픽셀 정리만 수행했다: RGB의 최댓값을 세 채널에 동일하게 적용하여 완전한 무채색으로 만들고, 원래 밝기 2/255 이하의 배경 노이즈를 0으로 정리했다. 마지막 잔상이 밝은 점으로 남지 않도록 10·11·12칸에 각각 0.5·0.15·0.05 밝기 배율을 적용했다. 1~9칸 배율은 1이다.

12칸 모두 네 가장자리 안쪽 12px 띠의 모든 RGB 값이 **정확히 0**이다. 검정이 아닌 픽셀의 최소 가장자리 거리는 전체에서 37px로, 요구된 12px보다 넓다. 모든 픽셀은 R=G=B이다. 11칸은 최댓값 30/255, 비검정 픽셀 784개; 12칸은 9/255, 84개로 마지막 두 칸이 비어 있지 않다. 9→12칸의 총 밝기는 305731→30087→2392→192로 감소한다.

가이드와 가산 오버레이를 만들어 육안 확인했다. 초반 반짝임은 들어 올린 발톱 부근, 5~6칸은 머리 왼쪽, 7칸은 왼쪽 여유 공간, 8칸 섬광은 로컬 약 (125, 176)의 뻗은 발톱 끝 부근이다. 파편과 잔상은 공통 좌표에서 이어진다. 가이드의 캐릭터·숫자·붉은 선·배경·격자는 최종 PNG에 포함하지 않았다.

Unity 임포트와 실제 게임 재생 검수는 수행하지 않았다. 요청한 폴더 안에서만 납품 파일과 임시 검수 파일을 작성했고, 임시 검수 파일은 삭제했다. Assets/, Packages/, ProjectSettings/ 수정 및 git 사용 없음.
