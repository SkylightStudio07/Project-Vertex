# 적 탄착 이펙트 방향 목업

`REQUEST.md`와 `../../UI_Mockup_Split_Workflow.md`를 기준으로 만든 방향 검토용 목업입니다. 모든 PNG는 **1920×1080**, 불투명 RGB입니다.

| 파일 | 내용 |
|---|---|
| `Impact_Additive.png` | 순흑 `#000000` 바탕, 384×540 칸의 5열×2행. 왼쪽부터 기계 / 중장갑 / 차원 / 신비 / 방어도에 막힘. 위아래는 같은 종류의 서로 다른 낱장입니다. |
| `Impact_Flesh.png` | 중간 회색 `#808080` 바탕, 짙은 붉은 핏방울과 옅은 먼지 3종. 오른쪽으로 조금 더 튀는 일반 합성용 방향입니다. |
| `Battle_Impact.png` | 원본 전투 캡처의 오른쪽 적 가슴 `(1464, 487)`에 첫 번째 기계 이펙트를 가산 합성한 크기 검토용 화면입니다. 이펙트의 실제 비검정 영역은 약 **180×169px**입니다. |
| `PROMPTS.txt` | 기본 imagegen 도구에 전달한 실제 생성·수정 프롬프트 4개. 처음의 미채택 시안도 기록했습니다. |

탄착 중심은 가산 시트 각 칸의 중앙, 즉 x=`192 / 576 / 960 / 1344 / 1728`, y=`270 / 810`입니다. 생체 시트의 탄착 기준점은 `(320,540)`, `(960,540)`, `(1600,540)`입니다. 연속 애니메이션 프레임으로 그리지 않았습니다.

그림은 전부 **내장 imagegen**으로 생성했습니다. 불꽃·연기 붓질은 `../MuzzleFlash/Flash_Variants.png`, `../MuzzleFlash/Smoke_Variants.png`를 참조했습니다. 첫 가산 시안의 총구처럼 한쪽에서 시작하는 형태를 수정했고, 막힘은 청록빛의 얇고 끊어진 표면 파문으로 별도 보완했습니다. 최종 1~4열은 두 번째 생성본, 5열은 네 번째 생성본을 사용했습니다.

이미지 도구가 요청한 정확한 해상도와 단색 배경을 그대로 반환하지 않아, 생성 후 래스터 배치·리샘플링과 배경 잔차 정리를 수행했습니다. 가산 원본 RGB는 채널별 5단계 이하의 미세 배경 잔차를 제거했습니다. 생체 원본은 기준 회색 `(127,126,126)` 주변의 ±4단계 잔차를 정리해 `#808080`에 맞췄습니다. 효과의 붓질과 색은 생성 그림에서 가져왔고, 코드로 형상을 새로 그리지 않았습니다. SVG는 사용하지 않았습니다.

전투 목업은 `Reference/Current_InGame_Enemy.png`에 이미 생성한 기계 낱장을 축소하여 `min(255, 원본 RGB + 이펙트 RGB)`로 합성했습니다. 원본 장면을 재생성하지 않았습니다. 배경·캐릭터·HUD의 원래 픽셀은 이펙트가 덮인 곳 이외에 그대로 보존됩니다. 기계 이펙트는 크기와 색 대비를 확인하기 위한 예시이며, 캡처 속 적의 속성을 바꾸는 작업은 포함하지 않습니다.

검수 결과:

- PNG 3장 모두 1920×1080이며 육안 검토를 마쳤습니다.
- 가산 시트의 모든 이펙트는 빛 번짐과 불똥까지 각 칸 안에서 완전히 검정으로 떨어집니다. 비검정 픽셀은 좌우 경계에서 최소 47px 이상 떨어집니다.
- 생체 시트의 바깥 여백과 각 그림 사이에는 정확한 `#808080`을 유지했습니다. 회색 바탕을 남겼으며 알파를 추출하지 않았습니다.
- 전투 화면의 변경 영역은 원본 좌표 `[1376,396,180,169]` 안에 한정됩니다. 그 밖의 픽셀과 모든 HUD 영역은 원본과 같습니다.
- 글자·테두리·총·손·몸·상처를 새 이펙트에 그리지 않았습니다.

이번 납품은 방향 목업 단계입니다. 게임용 분절 PNG, 알파 추출, 임포트, 코드 적용은 요청 범위에 따라 진행하지 않았습니다. `Assets/`, `Packages/`, `ProjectSettings/`는 변경하지 않았고 git은 사용하지 않았습니다. 별도의 미완료 납품 항목은 없습니다.
