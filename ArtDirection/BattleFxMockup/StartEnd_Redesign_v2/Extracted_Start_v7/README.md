# 작전 개시 v7 분절

띠 전용 투명 PNG 12개, layout.json, Contact_Sheet.jpg, 일반·정예 재조립 화면. 전장·캐릭터·카드·HUD·의뢰 추적 패널은 조각에 포함하지 않는다. 게임 Assets는 수정하지 않았다.

SVG 미사용. 내장 image_gen으로 정본의 무광 먹색 및 뼈흰색 표면을 재생성하고 래스터 외곽 마스크로 분절했다. 원화는 Generated/, 실제 생성 프롬프트는 PROMPTS.txt. 단색 처리는 그림자·선·눈금·3px 정예 칩에만 사용했다. 태그는 생성 먹색 표면을 재사용한다. 재생성으로 정본과 미세한 종이결·톤은 다르다.

모든 조각은 회전0°, 화면 크기 두 배의 RGBA PNG이며 외곽 알파는 0/255다. 좌표는 정본1685×934에서1920×1080으로 환산했다. 흰 판의 잘린 왼쪽 위 모서리와 띠 오른쪽 아래 모서리는 각각 마스크에 포함된다. Band/Serial_Block은 고정 크기. Line_Top 및 Tag만 가로로 늘린다. nine_slice_px 순서는 왼·아래·오른·위, PNG 픽셀이다. Tag 좌우72px는 사선 끝을 포함한다.

글자와 숫자는 전부 런타임 슬롯이다. 제목·일련번호·영문·태그뿐 아니라 오른쪽 큰 흐린06도 PNG에 없다. ghost 슬롯은 opacity0.10으로 출력하고 Band의 알파 범위로 잘라 아래쪽과 오른쪽 잘린 모서리 밖으로 넘치지 않게 한다. 정예에서는 tag 문구를 '정예 조우 · 적 02'로 교체하고 Tag_EliteMark만 표시한다. 칩 안에는 글자가 없다. Title_Rule과 Tag_Bar는 layout.instances의 좌우 위치에 같은 조각을 재사용한다.

Contact_Sheet는 조각 단독 및 정본/재조립 일반·정예 비교다. 재조립 화면에서만 정본 장면을 배경으로 사용했다. 상위 폴더 Operation_Start_Mockup_v7_Elite.png는 별도로 이미지 모델이 만든 방향 확인용 목업이며 칩 크기는 납품 PNG의 약3px가 최종 규격이다. 일반/정예 조립 결과의 글꼴은 Pretendard로 근사한 것으로 정본의 이미지 글자와 완전히 같지는 않다. Line_Top은 요청의 중성 팔레트에 맞춘 회색이다.

검증: 12개 PNG 크기·2배 배율·이진 알파 확인 통과. 일반·정예 재조립 시각 검토 완료.
