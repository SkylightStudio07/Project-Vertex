# 권총 총구 섬광 · 분절 결과

확정 `../Flash_Variants.png`, `../Smoke_Variants.png`에서 직접 추출했다. **새 생성·SVG·도형 조립·크기 변경·회전·색 보정·덧그리기 없이**, 요청서의 알파 분리와 정수 픽셀 이동만 적용했다. `Battle_Flash.png`는 사용하지 않았다.

## 납품

원본 뿌리는 요청서 수치를 그대로 사용했다. 연기 영역 중심에 .5px가 있는 경우 반올림해 정수 표본 중심을 잡았다. 원래 중심과 실제 이동 값은 `layout.json`에 함께 기록했다. 연기 표의 영역을 강제로 자르는 대신, 같은 중심의 512px 표본 창에서 희미한 가장자리까지 포함했다. 따라서 영역 끝의 옅은 연기도 잘리지 않았다.

## 알파 분리

섬광은 0~255 기준으로 `A=max(R,G,B)`, `A<=6`일 때 0, 나머지는 `RGB_straight=round(RGB_source×255/A)`로 계산했다. A=0인 픽셀은 RGB도 0이다. 불꽃의 밝기와 부드러운 가장자리는 원본과 같다.

연기는 `RGB=(235,235,235)`, `A=round(clamp((밝기−128)/107,0,1)×255)`다. 원본은 무채색이므로 밝기는 RGB 평균으로 계산했다. 투명 픽셀도 RGB 235로 유지하고 명암은 알파에 담았다.

섬광을 그릴 때는 **텍스처 RGB에 알파를 한 번 곱한 값을 배경에 더한다**. 예를 들어 straight-alpha 텍스처에 `SrcAlpha / One` 블렌딩을 쓰거나, 셰이더에서 RGB×A를 계산한 뒤 `One / One`을 쓸 수 있다. 두 방법을 동시에 쓰면 알파를 두 번 곱하게 된다. 알파를 무시하고 straight RGB만 더하면 옅은 불꽃 자락의 밝기가 원본과 달라진다. 연기는 일반 알파 합성이다.

## 좌표와 검수 자료

- `layout.json`: 캔버스, 섬광 원점/연기 중심, 알파가 있는 영역 `[x,y,w,h]`, 원본 뿌리, 원본 표본 창, 정수 이동값을 포함한다. 좌상단 원점이며 `source_window_px`는 원본 목업 기준이다. Unity용 좌하단 정규화 피벗도 함께 기록했다.
- `Contact_Sheet.jpg`: #1B2A3F 바탕 위에 9장을 1:1 크기로 배치했다. 섬광은 RGB×A 가산, 연기는 일반 알파 합성이다. 파일명·설명은 검수 시트에만 있다.
- `validation.json`: 저장된 PNG를 다시 읽어 검사한 결과다. 검수 시트의 JPG 압축본이 아닌 PNG를 대상으로 검사했다.
- 재현 스크립트: `../split_exact.py`.

## 검증 결과

9장 모두 크기·RGBA 모드·바깥 4px 투명 조건을 통과했다. 섬광의 원본 칸에서 A>6인 픽셀과 연기의 바탕보다 밝은 픽셀을 모두 보존했으며, 캔버스 밖으로 잘린 유효 픽셀은 없다. 알파는 부드러운 다단계 값이다.

섬광을 검정 바탕에 RGB×A로, 연기를 #808080 바탕에 일반 합성한 뒤 8비트로 반올림해 원본 표본 창과 비교했다. **9장 모두 최대 채널 오차 0/255, 평균 절대 오차 0**으로 요청 허용치(섬광 ±2, 연기 ±3)를 충족했다. 청색 검수 시트에서도 회색 배경 테두리나 잘린 불꽃이 없는지 시각 확인했다.

Unity 임포트·머티리얼 변경·게임 적용은 수행하지 않았다.
