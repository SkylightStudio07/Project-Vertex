# 권총 총구 섬광 · 방향 목업

`REQUEST.md` 기준 방향 검토용 PNG 3장. 내장 image_gen 이미지 모델로 생성·수정했다. SVG·도형 조립 미사용. 이번 작업은 완성 목업까지이며 프레임 분절·투명 알파 추출·Unity 적용은 하지 않았다.

## 결과물

- `Flash_Variants.png` — 1920×1080, 순흑 바탕, 3열 2행. 좌→우/상→하: 짧고 둥근 폭발 / 전방 원뿔 / 가는 가시형 / 세로 부채형 / 감쇠 A / 감쇠 B. 총구 시작점은 칸 왼쪽 약 18%, 세로 중앙 부근. 줄별 미세 위치 편차는 최종 분절 시 공통 원점에 맞출 수 있다.
- `Smoke_Variants.png` — 1920×1080, #808080 바탕, 무채색 화약 연기 3종. 왼쪽은 조밀한 덩어리, 중앙은 열린 굴곡, 오른쪽은 엷게 풀리는 형태.
- `Battle_Flash.png` — 1920×1080, 차가운 창고 장면에서 2번 원뿔형 섬광을 총구에 붙인 방향 검토 화면. 캐릭터 약 295px, 섬광의 총구 이후 가시 범위 약 180×100px. 흐린 끝을 어디까지 세는지에 따라 약간 달라진다.

## 참조와 제작

공격 시트의 `Good_PaintedFlash_A12/B09/C08`을 색·작화 질감 기준으로 사용했다. 거의 흰 노랑 코어→호박색→짙은 주황의 불규칙한 불꽃 몸통이며, 검은 먹선·시안 테두리·별도 불똥은 넣지 않았다. 연기는 별도로 생성했다.

실제 생성 프롬프트와 수정 프롬프트 전체는 `PROMPTS.txt`. 선택된 이미지 모델 원본은 `Generated/*_Raw.png`에 보존했다. 원본 1672×941을 1920×1080으로 리샘플링했다.

내보낼 때 섬광 바탕의 6/255 이하 미세 노이즈를 순흑으로 정리했다. 연기는 무채색 레벨 보정으로 바탕을 #808080에 맞췄고, 바깥 16px의 빈 여백은 지정 바탕색으로 고정했다. 연기·불꽃 윤곽을 코드로 다시 그리지 않았다. `export_mockups.ps1`에 내보내기 과정을 기록했다.

## 전투 화면의 범위

제공된 `Current_InGame_NoFlash.png`는 691×485의 일부 화면이다. 캐릭터를 약 285px로 유지하면서 1920×1080을 만들기 위해 이미지 모델로 주변 창고를 확장했다. 원본의 포즈·의상·무기·창고 구성은 참조했지만, **원본 픽셀을 고정한 단순 합성은 아니며 세부 캐릭터·배경에는 재생성 차이가 있다.** 따라서 전투 파일은 실제 크기·색 대비 검토용이다. 최종 게임 적용 시에는 선택한 섬광만 기존 게임 장면 위에 가산 합성해야 한다.

## 검수

세 파일의 1920×1080 크기를 확인했다. 섬광 시트는 6칸 각각의 10px 경계 띠와 화면 테두리가 모두 RGB(0,0,0)임을 검사했다. 연기 시트는 RGB 채널 동일성 및 화면 테두리 RGB(128,128,128)를 검사했다. 불꽃과 연기가 캔버스 끝에서 잘리지 않는지, 총구 부착과 크기·차가운 배경 위 색 대비를 시각 확인했다. 수치 기록은 `validation.json`.

감쇠안 5·6은 색·밝기 방향용이다. 최종 분절에서는 선택한 안을 고정 캔버스 512×256 / 원점 (40,128) 등 요청 좌표에 맞춰 내보내면 된다.
