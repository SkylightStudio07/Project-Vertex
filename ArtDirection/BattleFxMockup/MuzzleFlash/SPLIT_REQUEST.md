# 권총 총구 섬광 · 분절 요청

`Flash_Variants.png`, `Smoke_Variants.png`를 **정본으로 확정**한다. 이 두 장에서 게임용 조각을 잘라 달라.
작업 방식은 `../../UI_Mockup_Split_Workflow.md` 4단계를 따른다.

## 확정 · 바뀌는 점

- 섬광 6칸, 연기 3종을 **전부** 쓴다. 다시 그리지 않고 지금 그림을 그대로 자른다.
- `Battle_Flash.png`는 크기 · 색 확인용이다. 여기서는 아무것도 자르지 않는다.
- `REQUEST.md`에 참고로 적은 캔버스 512×256은 **취소한다.** 실제 섬광은 총구에서 위아래로 최대 206px까지 벌어져서 들어가지 않는다. 아래 512×512를 쓴다.

## 핵심 규칙

1. **새로 생성하지 않는다.** 목업의 픽셀을 그대로 쓴다. 크기 변경 · 회전 · 색 보정 · 덧그리기를 하지 않고, 위치만 정수 픽셀로 옮긴다.
2. **SVG · 도형 조립 금지.**
3. 조각에 글자 · 배경 · 안내선 · 다른 칸의 그림을 넣지 않는다.
4. 투명 PNG(RGBA 8비트), 회전 0°. 캔버스 바깥쪽 **4px 테두리는 알파 0**이어야 한다.
5. 그림이 캔버스 끝에서 잘리면 안 된다. 가장자리는 목업의 부드러운 번짐을 그대로 살린다(이진 알파 금지).

## 섬광 6장

원본: `Flash_Variants.png` (순흑 바탕, 3열 2줄, 칸 하나 640×540).

- **캔버스 512×512.** 총구 뿌리를 **원점 (24, 256)** 에 맞춘다(왼쪽 위 기준 픽셀).
- 게임은 이 원점을 총구에 붙이고 밝게 더하는 방식으로 그린다.

| 파일 | 칸 | 내용 | 뿌리 위치 (목업 픽셀) | 원점에서 오른쪽 / 위 / 아래 범위 |
|---|---|---|---|---|
| `Flash_A.png` | 1 | 둥글고 짧은 폭발 | (119, 273) | 340 / 153 / 145 |
| `Flash_B.png` | 2 | 앞으로 긴 원뿔 | (748, 272) | 462 / 171 / 161 |
| `Flash_C.png` | 3 | 가시가 많은 형 | (1397, 272) | 400 / 180 / 160 |
| `Flash_D.png` | 4 | 위아래로 벌어진 부채 | (108, 774) | 331 / 206 / 200 |
| `Flash_Fade_A.png` | 5 | 사라지는 순간 A | (758, 775) | 380 / 154 / 126 |
| `Flash_Fade_B.png` | 6 | 사라지는 순간 B | (1401, 775) | 321 / 103 / 75 |

뿌리 위치는 가장 왼쪽의 밝은 지점을 잰 값이다. 눈으로 볼 때 몇 px 어긋나면 고쳐도 되고, 쓴 값을 `layout.json`에 적는다.

**알파 뽑기** (검은 바탕 제거, 색은 바꾸지 않는다)

- `alpha = max(R, G, B)`
- `RGB = 원본 RGB / alpha` (straight alpha, alpha가 0이면 RGB 0)
- `alpha`가 6/255 이하인 잔여 노이즈는 0으로 정리한다.
- 확인: 조각을 검은 바탕에 `RGB × alpha`로 합성하면 목업 칸과 채널당 ±2 안에서 같아야 한다.

## 연기 3장

원본: `Smoke_Variants.png` (#808080 바탕).

- **캔버스 512×512**, 연기 덩어리의 영역 중심을 캔버스 가운데에 맞춘다.
- 파티클 텍스처로 쓰여 회전 · 확대된다.

| 파일 | 내용 | 목업 영역 (x0, y0 – x1, y1) |
|---|---|---|
| `Smoke_A.png` | 왼쪽, 조밀한 덩어리 | 107, 373 – 494, 713 |
| `Smoke_B.png` | 가운데, 열린 굴곡 | 683, 302 – 1176, 740 |
| `Smoke_C.png` | 오른쪽, 엷게 풀린 형태 | 1357, 305 – 1753, 699 |

**알파 뽑기** (회색 바탕 제거)

- `RGB = (235, 235, 235)` 단색
- `alpha = clamp((밝기 − 128) / 107, 0, 1)`
- 명암은 전부 알파에 담긴다. 게임이 색과 투명도를 곱해서 쓴다.
- 확인: 조각을 #808080 위에 일반 합성하면 목업과 채널당 ±3 안에서 같아야 한다. 회색 테두리가 남으면 안 된다.
