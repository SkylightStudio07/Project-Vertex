# Bite_Hund

`Bite_Hund.png`: 1920×1080 RGB PNG, 4열×3행, 칸당 480×360. 왼쪽 위부터 행 순서로 사용한다. 순흑 배경이며 가산 합성용 알파는 `max(R,G,B)`로 얻는다.

그림은 내장 imagegen으로 생성·수정했다. 실제 프롬프트 두 개는 `PROMPTS.txt`에 있다. 승인된 Bandit의 칠한 붓결을 기준으로 제작했으며 SVG나 코드로 새 이펙트를 그리지 않았다.

검수 결과:

- 전 칸의 외곽 12px에서 비검정 픽셀 **0개**. 실제 최소 검정 여백은 **24px**다. 칸을 가로지르는 그림·번짐이 없다.
- 전 픽셀이 `R=G=B`인 무채색이다. 배경은 정확한 `#000000`; 문자·테두리·가이드·캐릭터가 없다.
- 5번의 총밝기가 최대다. 5→12번의 총밝기 합은 **1,450,675 → 522,277 → 199,815 → 111,904 → 80,452 → 18,782 → 5,726 → 1,799**로 계속 감소한다. 마지막 칸에도 비검정 픽셀 768개가 남는다.
- 가이드에 정적 가산 합성하여 위치를 확인했다. 4·5·6번의 밝은 중심은 각각 칸 내부 **(119.4,149.8), (121.1,149.4), (115.5,149.6)**로, 붉은 가이드선 부근의 주둥이 앞에 놓인다. 각 칸의 그림을 가운데 정렬하지 않았다.

마무리 과정: 두 생성 원본은 모두 1672×941이었다. 전체 캔버스를 고품질 bicubic으로 1920×1080에 맞추고 4×3 격자 대응을 유지했다(잘라내기·여백 추가 없음). 1~3칸은 첫 생성, 4~12칸은 수정 생성에서 선택했다. 위치 보정 `(dx,dy)`는 4번 `(15,-40)`, 5번 `(0,-12)`, 6~7번 `(0,-22)`이며 나머지는 `(0,0)`이다. 이는 주둥이 기준 등록 보정이며 개별 가운데 정렬이 아니다. RGB 최댓값을 회색으로 정규화하고 0~2 단계의 배경 잡음을 검정으로 내렸다. 4번 밝기에 0.9, 9번에 0.7을 곱해 섬광 정점과 감쇠를 정리했다. 붓결·입김·방울은 모두 생성 그림의 픽셀이다.

요청한 세 파일을 납품했다. 미완료 항목은 없다.
