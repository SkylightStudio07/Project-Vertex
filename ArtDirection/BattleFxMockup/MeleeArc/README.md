# 근접 공격 궤적 방향 목업

`Arcs.png`: 1920×1080 RGB PNG, 순흑 바탕, 960×540의 보이지 않는 2×2 칸. 그림은 내장 imagegen으로 생성·수정했다. 세 가지 `Reference/Style_*.png`와 요청서 및 공통 목업 작업 방식을 읽고 확인했다.

좌표는 왼쪽 위 원점, 단위 px. 아래 경계 상자는 빛 번짐과 작은 조각을 포함한 **모든 비검정 픽셀**의 실제 `[x, y, 너비, 높이]`다.

| 칸 | 내용 | 실제 경계 상자 | 칸 안 순흑 여백 L/T/R/B |
|---|---|---|---|
| 왼쪽 위 | 둔기 A | `[370, 50, 219, 440]` | `370 / 50 / 371 / 50` |
| 오른쪽 위 | 둔기 B | `[1239, 39, 401, 461]` | `279 / 39 / 280 / 40` |
| 왼쪽 아래 | 베기 | `[353, 590, 254, 440]` | `353 / 50 / 353 / 50` |
| 오른쪽 아래 | 발톱 3줄 | `[1362, 599, 155, 421]` | `402 / 59 / 403 / 60` |

중앙 단면의 주된 밝은 몸체(명도 ≥32): 둔기 A 약 91px, 베기 32px. 발톱은 3줄이며 중앙 몸체 중심 간격은 약 44px다. 모든 호는 위에서 시작해 왼쪽으로 불룩하게 돌아 아래에서 끝나는 `(` 방향이며, 아래쪽 앞머리가 가장 밝다.

검수: 외곽 25px 및 가로·세로 중앙 50px 띠의 비검정 픽셀 **0개**. 각 칸의 전체 번짐이 경계 전에 순흑으로 끝나며 잘림·칸 간 접촉이 없다. RGB 채널이 동일한 무채색이며, 바탕은 정확히 `#000000`이다. 알파는 요청대로 후속 단계에서 `max(R,G,B)`로 추출할 수 있다.

납품 규격 보정은 생성된 래스터의 크기·배치 조정, 무채색 변환 및 검정점 정리만 했다. 검정점은 생성 원본의 `max(R,G,B) ≤3`을 0으로, 나머지를 `(값−3)×255/252`로 정규화했다. 붓결·윤곽은 imagegen 그림이며 SVG나 코드로 새로 그리지 않았다. 실제 생성·수정 프롬프트는 `PROMPTS.txt`에 기록했다.

요청한 목업 1장만 납품한다. 분절 파일·연속 프레임·Unity 적용은 이번 범위에 포함되지 않는다. 수행하지 못한 요청 사항은 없다.
