# Hit_Gunshot

`Hit_Gunshot.png`: 1920×1080 RGB PNG, 순흑(#000000) 바탕, 4열×3행, 칸 480×360. 왼쪽 위부터 행 순서로 재생한다. 앞 5칸 30fps, 뒤 7칸 15fps(총 약 0.633초). 가산 합성용이며 알파 채널은 없고, 사용하는 쪽에서 `max(R,G,B)`로 알파를 얻는다.

그림은 built-in **imagegen**으로 생성했다. 실제 입력은 `PROMPTS.txt`에 기록했다. 승인된 방망이 시트의 따뜻한 회백색 붓질·번짐·잔연 소멸을 기준으로, 오른쪽에서 맞고 주로 왼쪽으로 튀는 피탄을 그렸다.

검수: 12칸 모두 바깥 12px 띠의 RGB 최댓값이 **0**이다. 가장 가까운 비검정 픽셀도 경계에서 **19px** 안쪽이다. 9–12칸의 비검정 픽셀 수는 각각 21,260 / 8,996 / 3,672 / 979로, 빈 칸이 없다. 칸별 `sum(max(R,G,B))`는 3번에서 정점(2,780,637), 이후 1,519,711 → 817,650 → 351,179 → 298,889 → 207,204 → 147,947 → 48,560 → 11,461 → 2,562로 감소한다. 단일 픽셀 밝기와 전체 발광량을 구별해 검사했다.

정렬·크기 처리: 생성 원본은 **1672×941**이었다. 전체를 1920×1080으로 미세 비율 보정한 뒤, 동일한 4×3 격자에서 각 칸을 가로·세로 **90%**로 축소 배치해 여백을 확보했다. 1–6칸은 중앙 섬광/잔광의 밝은 핵을 기준으로 평행 이동하여 기준 탄착점을 로컬 **(240,180)**에 맞췄다. 7–12칸은 연속되는 잔광의 기준점을 이어받았으며, 연기 경계 상자의 중심을 탄착점으로 재정렬하지 않았다. 따라서 연기 자체는 왼쪽 위로 이동한다. 섬광이 사라진 칸의 탄착점은 고정된 배치 기준점이며, 눈에 보이는 점이 남아 있다는 뜻은 아니다.

리샘플링 후 `max(R,G,B)≤1`인 배경 잔차만 순흑으로 정리했다. 붓질·불티·연기를 코드로 추가하거나 다시 그리지 않았다. 최종 PNG를 육안으로 다시 확인했다. SVG는 사용하지 않았다. 게임 내 합성·재생 검수는 이번 시트 납품 범위에 포함하지 않았다.
