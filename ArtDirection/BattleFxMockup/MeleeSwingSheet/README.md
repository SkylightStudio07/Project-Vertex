# Swing_Bandit

- `Swing_Bandit.png`: 1920×1080, RGB PNG, 순흑 배경. 4열×3행, 칸 480×360. 좌상단부터 행 우선으로 30fps / 0.4초 재생. 알파는 `max(R,G,B)`로 추출한다.
- 내장 imagegen으로 그림을 생성했다. 실제 프롬프트와 참조 순서는 `PROMPTS.txt`에 기록했다. SVG 및 절차적 도형 작화는 사용하지 않았다.

## 크기 보정과 위치

생성 원본은 1672×941이었다. 원본을 4×3의 같은 격자로 읽고, 각 칸을 418×314로 정규화한 뒤 최종 480×360 칸의 동일한 위치 `(25,12)`에 배치했다. 모든 칸에 같은 변환을 사용했으며 그림마다 가운데 정렬하지 않았다. 원본의 RGB 최대값 3 이하 배경 잡음을 검정으로 정리하고, 원본 칸 둘레 12px에 코사인 감쇠를 적용해 가장자리 잔여 번짐을 검정으로 연결했다. 9~12번에는 각각 0.55 / 0.50 / 0.35 / 0.65 밝기 계수를 적용해 긴 소멸 꼬리를 정리했다. 그 외 그림을 새로 그리거나 합성하지 않았다.

가이드 위 가산 합성으로 위→왼쪽→왼쪽 아래 경로와 고정 원점을 육안 확인했다. 3번 칸의 잘린 방망이 경계인 로컬 `(120,190)`에서 이펙트 RGB는 `(243,233,225)`로, 밝은 앞머리가 경계를 덮는다. 4~5번의 섬광은 같은 왼쪽 아래 접촉 영역에 이어진다. 가이드의 캐릭터·무기·번호·선·기존 영상 찌꺼기는 결과물에 포함하지 않았다.

Unity 임포트 및 실제 게임 재생은 이번 시트 납품 범위에 포함하지 않았다.
