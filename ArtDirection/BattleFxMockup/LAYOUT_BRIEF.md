# 전투 연출 · 결과 화면 · 레이아웃 요청서

지금 아래 다섯 가지는 그림 조각 없이 코드로 만든 단색 띠와 글자뿐이다. 전투 HUD v3와 같은 문법으로 **그림 조각이 있는 연출**로 바꾼다.

| # | 연출 | 언제 | 지금 모습 |
|---|---|---|---|
| 1 | **작전 개시 배너** | 일반·엘리트 전투 시작 | `Reference_Current_Start.png` |
| 2 | **카드 컷인** | 파워 카드, 또는 유니크 이상 카드 사용 | `Reference_Current_CutIn.png` (유니크 라벨이 노란색 — 고칠 것) |
| 3 | **적 처치 기록** | 적이 쓰러질 때마다 왼쪽 위에 한 줄씩 | `Reference_Current_KillFeed.png` |
| 4 | **작전 종료 / 작전 실패** | 전투 승리 / 플레이어 쓰러짐 | `Reference_Current_Victory.png`, `Reference_Current_Defeat.png` |
| 5 | **결과 화면** | 런 클리어 / 작전 실패 후 / 훈련 완료·종료 | `Reference_Current_Result.png` (어두운 판 + 노란 제목 — 전면 교체) |

- 스타일 기준: `Reference_BattleHUD_v3.png`(전투 HUD v3 — 먹색 판, 헤어라인, 청록 강조), `Reference_TurnBanner_v3.png`(턴 배너 — 이 연출들과 한 가족), `Reference_LobbyMain.png`(로비)
- 화면은 1920×1080. 1~4는 **전투 화면 위에 잠깐 떴다 사라지는 띠**라 전투 화면이 비쳐 보이는 구성이다(띠 자체는 불투명).

## 0. 공통 스타일

- 명일방주식 작전 띠 문법이다.
  - 먹색 #16181B / 종이 #EEF0F2 띠, 사선으로 잘린 끝, 가는 헤어라인
  - 작은 영문 라벨 + 큰 한글
  - 청록 #0DB8F2는 선·작은 칸·글자 강조에만 쓴다.
- 턴 배너 v3와 같은 가족으로 보여야 한다. 선 굵기, 영문 글자 간격, 사선 각도를 맞춘다.
- **빨강·노랑·금색 금지.** 유니크나 보스를 강조할 때도 금색 대신 청록 + 먹색 대비, 이중선, 눈금 장식으로 등급을 표현한다.
- 반투명 판, 글로우, 별·꽃잎은 쓰지 않는다. 빛이 필요하면 흰 섬광 한 장을 그림에 굽는다.
- 움직이는 연출이므로 목업은 **가장 꽉 찬 순간(키 프레임)** 을 그린다. 등장·퇴장 방향은 아래 표의 "움직임"에 적었다. 분절은 띠·선·태그·장식을 따로 움직일 수 있게 나눌 예정이다.

## 1. 작전 개시 배너

| 항목 | 내용 |
|---|---|
| 위치 | 화면 위쪽 1/3 (y 약 180~340), 가로 전폭 |
| 구성 | 먹색 사선 띠 + 위 영문 "OPERATION START" + 가운데 큰 "작전 개시" + 아래 작은 태그 판("ELITE · 정예 조우 · 적 01" / "HOSTILE · 일반 조우 · 적 03") |
| 엘리트 | 같은 띠에 태그만 청록 강조 + 띠 끝에 짧은 청록 이중선 |
| 움직임 | 청록 선이 왼쪽→오른쪽으로 그어짐 → 띠가 펼쳐짐 → 글자 등장 → 약 0.8초 유지 → 띠가 오른쪽으로 빠지며 사라짐 |

## 2. 카드 컷인

| 항목 | 내용 |
|---|---|
| 위치 | 화면 왼쪽 위 (x 0~900, y 약 140~300). 손패·HUD를 가리지 않게 |
| 구성 | 사선 띠 안에 **카드 아트 창(가로로 긴 크롭)** + 위 영문 라벨("POWER ACTIVATED" / "ATTACK" / "SKILL ACTIVATED") + 카드 이름 + 등급 표식 |
| 파워 vs 유니크 | 두 변형을 한 장에 같이 그린다. 파워: 먹색 띠 + 청록 라벨. 유니크: 같은 띠에 **이중 테두리 + 눈금 장식 + 청록 "UNIQUE" 작은 칸**. 금색 금지 |
| 움직임 | 왼쪽에서 미끄러져 들어옴 → 아트가 띠 안에서 살짝 흐름 → 약 0.9초 → 왼쪽으로 빠짐 |

## 3. 적 처치 기록

| 항목 | 내용 |
|---|---|
| 위치 | 왼쪽 위 (x 30~420, y 약 250부터 아래로 쌓임), 줄 높이 약 40 |
| 구성 | 짧은 먹색 태그 줄: 왼쪽 청록 짧은 띠 + "TARGET DOWN" 작은 영문 + 적 이름 + "무력화". 보스는 같은 줄에 먹색 "BOSS" 작은 칸 |
| 움직임 | 왼쪽에서 톡 들어옴, 새 줄이 오면 기존 줄은 아래로 밀림, 2초 뒤 흐려지며 사라짐 |
| 목업 | 2~3줄이 쌓인 모습 |

## 4. 작전 종료 / 작전 실패

| 항목 | 작전 종료 (승리) | 작전 실패 (패배) |
|---|---|---|
| 위치 | 화면 가운데 띠 (y 약 420~640), 가로 전폭 | 같음 |
| 띠 | **종이색** 넓은 띠 + 위·아래 청록 헤어라인 | **먹색** 넓은 띠 + 회색 헤어라인 |
| 글자 | "MISSION ACCOMPLISHED" + 큰 "작전 종료" + 아래 먹색 태그 "ALL HOSTILES NEUTRALIZED" | "MISSION FAILED" + 큰 "작전 실패" + 회색 태그 "OPERATOR DOWN" |
| 분위기 | 흰 섬광이 한 번 스치고(짧은 슬로모션) 띠가 펼쳐짐 | 화면이 살짝 어두워지며 띠가 무겁게 내려앉음 |

두 변형을 각각 한 장씩 그린다.

## 5. 결과 화면

전체 화면이다. 세 경우가 **같은 판**을 쓰고 글자만 바뀐다.

```
┌──────────────────────────────────────────────────────────────┐
│  (전투 화면이 먹색으로 어둡게 깔림 — 불투명 0.9 정도로 그림에 굽기)    │
│                                                              │
│            RESULT / OPERATION REPORT                         │
│            작전 실패                     ← 큰 제목            │
│            1막 3층에서 쓰러졌습니다       ← 부제               │
│   ┌────────┬────────┬────────┬────────┐                      │
│   │ 도달 층 │ 격퇴   │ 획득 카드│ 진행 턴 │  ← 기록 칸 4개      │
│   │  03     │  07    │  04     │  21    │                      │
│   └────────┴────────┴────────┴────────┘                      │
│                              [ 기지로 귀환 → ] (종이 주 버튼)    │
└──────────────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|---|---|
| 판 | 화면 가운데 종이 보고서 판(약 1100×560) 또는 사선 띠 구성. 로비 문법(종이 판·헤어라인·번호)으로 "작전 보고서" 느낌 |
| 제목 | 영문 라벨 + 큰 한글: "작전 실패" / "런 클리어" / "훈련 완료" / "훈련 종료" |
| 기록 칸 | 숫자 4칸 (도달 층 / 격퇴 수 / 획득 카드 / 진행 턴). 훈련은 "상대 / 결과 / 진행 턴" 3칸이어도 된다 |
| 버튼 | "기지로 귀환 →" 주 버튼 (턴 종료 버튼과 같은 문법의 먹색, 또는 종이 판 위 먹색) |
| 상태 구분 | 클리어·훈련 완료는 청록 강조, 실패·훈련 종료는 회색 강조. 같은 판, 색 포인트만 다르게 |

## 6. 결과물

목업 6장(1920×1080, 전투 화면 위에 그린 상태. 5는 전체 화면):

1. `BattleFx_Start_Mockup.png`: 작전 개시(엘리트) + 왼쪽 위 처치 기록 2~3줄
2. `BattleFx_CutIn_Mockup.png`: 파워 컷인(위)과 유니크 컷인(아래)을 한 화면에 위아래로
3. `BattleFx_Victory_Mockup.png`: 작전 종료
4. `BattleFx_Defeat_Mockup.png`: 작전 실패
5. `Result_Defeat_Mockup.png`: 결과 화면 — 작전 실패
6. `Result_Clear_Mockup.png`: 결과 화면 — 런 클리어 (청록 강조 변형)

그림 규칙:
- 전투 화면 배경은 `Reference_BattleHUD_v3.png`를 깔고 그 위에 그린다.
- 카드 아트는 프로젝트 카드 그림을 쓴다. 적·캐릭터를 새로 그리지 않는다.
- 확정 후 분절은 따로 요청한다.
