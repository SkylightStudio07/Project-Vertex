# 의뢰 게시판 목업 요청서

로비 04 **의뢰 게시판** 화면 목업. 기존 승인 목업 `LoadoutMockup/Loadout_Mockup_v1.png`, `ArmoryMockup/Armory_Equipment_Mockup_v2_Sniper.png`, `ArmoryMockup/Armory_CardCatalog_Mockup_v1.png`와 **같은 시리즈**로 보여야 한다. 시스템 기획은 `Docs/의뢰.md`.

## 0. 공통 규격 (기존 목업과 동일하게)

- 캔버스 **1672 × 941**, 좌상단 원점.
- 흰 종이 질감 패널, 흑연색 선·아이콘, 포인트 색 **청록 #0DB8F2** 하나만. 경고·강조에 빨강 금지.
- 좌우 가장자리에 로비 배경(캠프·관측탑)이 사선으로 살짝 비친다. 무기고 목업과 같은 처리.
- 폰트 느낌: Pretendard. 제목 Bold, 본문 Regular, 작은 영문 캡션은 자간 넓게.
- 모서리 한쪽이 사선으로 잘린 패널, 얇은 십자(+) 장식, 1px 구분선 — 기존 문법 그대로.
- **모든 글자는 실제 게임에서 TMP로 다시 얹는다.** 목업의 글자는 참고용이니 분리 시 지울 수 있게 단색 면 위에 둔다.

## 4. 중 패널 — 의뢰 카드 목록

- 제목 `의뢰 목록`, 오른쪽 끝에 `게시 4`.
- 카드 **2열 × 2행**이 보이고 세 번째 행이 아래에 살짝 잘려 보이게(스크롤 암시). 오른쪽에 얇은 스크롤바.
- 카드 크기 약 **370 × 200**, 간격 약 15.

### 카드 구조 (한 장)

```
┌──────────────────────────────────────────┐
│ ▣ 회수                        [STORY]    │ ← 좌: 유형 기호+유형명 / 우: 태그 배지
│                                          │
│ 블랙박스 회수                  (굵게)     │
│ R&C 컴퍼니                     (회색)     │
│ ───────────────────────────             │
│ [의뢰물품 아이콘] 손상된 블랙박스          │ ← 퀘스트 아이템 있는 의뢰만
│                                          │
│ 보상  30 EXP                  1막 ·      │ ← 우하단: 획득 계기 요약
│                          스카웃 유닛 처치 │
└──────────────────────────────────────────┘
```

### 목업에 그려야 할 카드 4장 (상태가 다 달라야 함)

| 위치 | 의뢰 | 유형 | 태그 | 상태 |
|---|---|---|---|---|
| 1행 좌 | 블랙박스 회수 / R&C 컴퍼니 | ▣ 회수 | **STORY** | **선택됨** (청록 테두리, 무기고 선택 카드와 같게) |
| 1행 우 | 봉인된 서류 / 익명의 의뢰인 | ◆ 배달 | 없음 | **수주됨** (우상단에 청록 도장 `수주`, 살짝 기울임) |
| 2행 좌 | 들개 토벌 / 독일 학술특무국 | ⚔ 토벌 | 없음 | 기본 |
| 2행 우 | 구조 신호 / 캐나다 해병대 | ✚ 회수 | **구출** | **잠김** (회색 톤, 자물쇠, 하단에 `블랙박스 회수 완료 시 게시`) |

### 태그 배지

- **STORY**: 흑연색 면 + 흰 글자, 작은 평행사변형 배지.
- **구출**: 청록 테두리 + 청록 글자, 같은 모양. (포인트 색을 여기에만 쓰는 이유: 합류 캐릭터 해금이라 눈에 띄어야 함)
- 태그 없는 카드는 그 자리를 비운다.

### 유형 기호 (흑연색, 단순한 선 아이콘)

- 회수 ▣ (상자), 배달 ◆ (봉투), 토벌 ⚔ (교차된 칼 또는 조준선), 구출 ✚ (신호/십자)

## 6. 분리(Extract)용으로 꼭 필요한 상태

기존처럼 `*_Normal` / `*_Normal_Hover` / 잠금·비활성 조각으로 나눌 수 있게 그린다.

| 컨트롤 | 필요한 상태 |
|---|---|
| 로비 버튼 | Normal, Hover |
| 탭 3개 | Selected, Normal, Hover (각각) |
| 의뢰 카드 | Normal, Hover, Selected, 수주됨(도장 포함), Locked |
| 필터 행 | 체크됨, 체크 안 됨, Hover |
| 수주 버튼 | Normal, Hover, **Disabled** (진행 중 2/2일 때. 회색, 글자 자리 비움) |
| 수주 취소 버튼 | 진행 중 탭용. 수주 버튼 자리에 같은 크기, 흰 면 + 흑연 테두리 (Normal, Hover) |
| 빈 카드 바탕 | 카드 내용을 바꿔 끼울 수 있는 복원 빈 면 1장 |
| 빈 상세 바탕 | 우 패널 내용 없는 복원 빈 면 |
| 태그 배지 | STORY, 구출 각각 단독 조각 |
| 유형 기호 | 회수·배달·토벌·구출 각각 단독 조각 |
| 수주 도장 | 단독 조각 (투명 배경) |
| 완료 도장 | **추가 요청**: `완료` 청록 도장. 로비 복귀 연출용 단독 조각 |

## 7. 하지 말 것

- 새 색(빨강·노랑·초록) 추가 금지. 강조는 청록 하나.
- 캐릭터 일러스트를 크게 넣지 않는다. 의뢰인은 세력 문장(엠블럼) 수준.
- 카드에 긴 본문을 넣지 않는다. 본문은 상세 패널에만.
- 헤더·로비 버튼·경험치 게이지 위치를 무기고와 다르게 두지 않는다 (화면 전환 시 고정돼 보여야 함).
