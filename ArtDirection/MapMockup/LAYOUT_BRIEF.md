# 맵 화면 · 레이아웃 요청서 (작전 지도)

맵 화면을 **로비·상점과 같은 문법의 "작전 지도"**로 바꾼다. 판은 공통이고, **막마다 바탕 지형 선화만 바뀐다.**
- 현재 화면: `Reference_Current.png` (1563×869 캡처)
- 스타일 기준: `Reference_LobbyStyle.png` (로비), `Reference_Shop_v2.png` (상점 v2)
- **그대로 두는 것:** 노드 아이콘 그림 9종(`Assets/Art/Maps/Nodes/UI_MapNode_*_WhiteVertex`), 노드 사이 연결 구조(맵 생성 결과), 상단 작전 바와 MAP·DECK
- 맵이 열려 있는 동안 HP 바·END TURN·자원 모듈은 게임에서 숨긴다. 목업에서도 빼고 그린다.

## 0. 지금 화면의 문제

1. **정보가 없다.** 층 눈금, 현재 위치, 보스까지 남은 층, 범례가 없어 지금 몇 층인지, 끝이 어디인지 읽히지 않는다.
2. **노드에 위계가 없다.** 모든 종류가 같은 회색 사각 칸이다. 엘리트·보스·휴식이 묻히고, 이동 가능·방문함·잠김 상태도 색 차이만 미세하다.
3. **장소감이 없다.** 흰 종이에 기계 도면 선만 있어서 "1막 · 만발한 백피안화의 정원"이라는 지역이 느껴지지 않는다.

## 1. 구조 — 두 층

| 층 | 무엇 | 막마다 |
|---|---|---|
| **지도 판 (공통)** | 종이 판, 정보 띠(제목·층 눈금·남은 층), 범례, 닫기, 노드 칸·선 스타일 | 같음 |
| **지형 바탕 (막 전용)** | 그 막 지역의 **등고선 + 지형 선화**. 판 안쪽 스크롤 영역에 깔린다 | **막마다 1장** |

## 3. 노드 · 선 (공통 조각)

노드 아이콘 그림은 기존 것을 쓰고, **칸(틀)과 상태 표시만** 새로 그린다.

| 종류 | 칸 | 크기 |
|---|---|---|
| 일반 전투 · 이벤트 · 상점 · 성소 · 상자 | 종이 칸 + 흑연 테두리 1px, 모서리 하나 사선 컷 | 76 × 76 |
| **휴식** | 같은 칸 + 아래쪽에 청록 가는 띠 (안전 지점 표시) | 76 × 76 |
| **엘리트** | **먹색 칸** (아이콘은 흰색으로 게임에서 반전) | 84 × 84 |
| **보스** | 먹색 큰 칸 + 바깥 이중 테두리 + 아래 이름표 자리 | 128 × 128 |
| 축복(시작) | 칸 없이 아이콘 + 원형 헤어라인 | 76 × 76 |

| 상태 | 표시 |
|---|---|
| 이동 가능 | 청록 테두리 1.5px + 바깥 얇은 청록 원호 (게임에서 맥동) |
| 현재 위치 | 칸 위 작은 청록 마름모 마커 + "HERE" 작은 꼬리표 |
| 방문함 | 칸 흐림 + 오른쪽 아래 작은 체크 |
| 잠김(아직 못 감) | 테두리·아이콘 회색 60% |
| 호버 | 칸이 2px 떠오르고 아래에 노드 이름 꼬리표 (게임 글자) |

| 연결선 | 표시 |
|---|---|
| 지나온 길 | 청록 실선 2px |
| 지금 갈 수 있는 길 | 흑연 실선 2px |
| 그 외 | 흑연 점선 1.5px (간격 6) |

- 노드 칸 상태별 PNG + 선은 9-slice용 짧은 조각(실선·점선 각 1)으로.
- 의뢰 표식 태그(`../QuestRunUI`)가 칸 오른쪽 위 모서리에 걸친다 — 겹쳐도 읽히는지 목업에서 한 칸 보여 줄 것.

## 4. 지형 바탕 (막 전용) — 이번에는 1막

- **크기:** 3320 × 600 (스크롤 영역 전체 폭: 16층 × 층 간격 200 + 양옆 여백 160). 게임에서 가로로 늘리지 않고 그대로 깐다.
- **내용:** 그 막 지역을 위에서 내려다본 **등고선 + 지형 선화**. 흑연 선, 판 종이 위에서 **명도 차 5~8%**로 아주 옅게. 노드·선이 항상 먼저 읽혀야 한다.
- **흐름:** 왼쪽(시작)에서 오른쪽(보스)으로 지형이 이어지고, **오른쪽 끝 보스 자리(x 3060~3320)에는 그 막의 상징적인 지형**을 조금 더 진하게(10~12%) 둔다.
- **1막 · 만발한 백피안화의 정원:** 무너진 정원 담장과 회랑, 물길과 작은 다리, 피안화 군락(꽃은 작은 점·선 묶음으로), 석주 기둥 터. 보스 자리는 정원 중심의 원형 광장(분수 또는 제단 터).
- **글자 없음.** 지명 표기가 필요하면 게임에서 넣는다.
- 2막 이후는 같은 규격으로 따로 요청한다. 막 이름·테마가 정해지면 이 절만 바꿔 다시 보낸다.
