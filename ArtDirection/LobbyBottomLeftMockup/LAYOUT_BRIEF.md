# 로비 좌하단 묶음 · 레이아웃 요청서 (드래프트)

로비 화면 왼쪽 아래를 명일방주처럼 **대사 박스 + 배너 카드 + 작은 버튼 두 개** 묶음으로 바꾼다. 우리는 가챠가 없으므로 배너 자리에는 **지금 진행 중인 스토리 챕터**가 들어간다. 기획: `Docs/기획/로비_좌하단.md`

- 참고 이미지
  - `Reference_Lobby_Current.png`: 지금 로비(1280×720 캡처, 1920×1080으로 키워 쓴다). 오른쪽 메뉴는 바깥이 가깝게 기울어 있고, 오른쪽 위에 흰 재화 바가 있다. 왼쪽 아래에는 지금 작은 대사 상자("다음 여정을 준비할까요?")가 있다. **이 자리를 바꾼다.**
  - `Reference_Arknights_Lobby.png`, `Reference_Arknights_BottomLeft.png`: 명일방주 로비 좌하단. **구성과 크기 비율만** 참고한다. 색·장식·질감(종이, 일러스트 테두리)은 따르지 않는다.
- 화면 크기는 1920×1080이다.

## 0. 공통 스타일

- 색: 회백색 #EEF0F2(판), 먹색 #16181B(글자·선·어두운 판), 청록 #0DB8F2(강조, 한두 곳만).
- **빨강·노랑·금색 금지.** 반투명 유리 판·글로우 금지. 판은 불투명하다.
- 오른쪽 메뉴 버튼(탐색 개시·베이스캠프·무기고…)과 **같은 판 언어**를 쓴다: 모서리 하나 절단, 얇은 먹색 테두리, 좌상단 작은 번호(`01`)와 짧은 밑줄, 영문 캡션 한 줄.
- 그림자는 그리지 않는다(게임에서 오른쪽 아래로 넣는다).
- 글자는 게임에서 TMP로 얹는다. 목업에는 넣되, 조각 PNG에는 **글자를 굽지 않는다.**

## 1. 들어갈 요소

| # | 요소 | 내용 |
|---|---|---|
| ① | 대사 박스 | 위 줄: 캐릭터 이름(예: 치하라 쇼). 아래: 대사 1~3줄. 오른쪽 아래에 작은 "다음" 표시(▸ 또는 깜빡이는 사각). 가장 넓다 |
| ② | 스토리 카드 | `STORY` 라벨, 챕터 번호 `CH.2-1`, 제목 2줄 "영원하지 않기에 / 빛나는 것들", 오른쪽 절반은 **챕터 썸네일**(잘린 일러스트), 맨 아래 "▸ 다음 목표: 1막 보스 격파" 한 줄. 명방 배너 자리 |
| ③ | 아카이브 버튼 | 작은 판. 아이콘 + "아카이브" + 영문 "ARCHIVES" |
| ④ | 동료 버튼 | 작은 판. 아이콘 + "동료" + 영문 "COMPANIONS" |

- ③·④는 ② 오른쪽에 위아래로 쌓는다(명방 친구·파일처럼).
- 대략 자리(1920×1080): ① x 40–760, y 760–880 / ② x 40–560, y 895–1050 / ③④ x 575–760, 각 높이 약 72.
- 지금 그 자리에 있는 캐릭터 다리와 겹쳐도 된다(명방도 겹친다). 다만 대사 박스가 얼굴·손을 가리지 않게.

### 아이콘 방향 (흰 판 위 먹색 선화, 단순 도형)
- 아카이브: 겹친 서류철 또는 책등 3개
- 동료: 두 사람 어깨 실루엣(겹침)
- 대사 "다음" 표시: 작은 청록 삼각형

### 썸네일 견본
- 지금 로비 배경 톤(회색 산악 기지, 비)과 맞는 **흑백에 가까운 풍경 일러스트** 한 장. 챕터마다 바뀔 자리라 견본이면 된다.

## 4. 수정 요청 — A안 기준 다시 (2026-10-22)

**A안으로 간다.** 판 언어(번호·밑줄·절단 모서리), 아이콘, 썸네일 톤은 좋다. B안은 대사가 배경 위에서 안 읽혀서 뺀다.
고칠 것은 **크기와 비율**이다. 1절 크기가 너무 길었다(우리 쪽 잘못). 명일방주 좌하단 비율에 맞춘다.

| 요소 | 새 자리 (1920×1080, x·y·w·h) | 비고 |
|---|---|---|
| ① 대사 박스 | 40, 800, 480, 90 | 이름 줄 + 대사 2줄. 폭이 ②+③④ 합과 같다 |
| ② 스토리 카드 | 40, 905, 320, 136 | **약 2.35:1** (명방 배너 비율). 썸네일이 카드 **전체**를 채우고, 왼쪽에서 오른쪽으로 먹색 그라데이션을 깔아 글자를 얹는다 |
| ③ 아카이브 | 372, 905, 148, 64 | |
| ④ 동료 | 372, 977, 148, 64 | |

- ② 글자: `02 / STORY CH.2-1`(작게) → 제목 1~2줄(24pt 정도) → `▶ 다음 목표: …`(작게). 지금 A안 글자 배치를 줄인 그대로.
- ③④는 폭이 좁아지므로 아이콘 + 한글 이름만, 영문은 아주 작게 또는 생략.
- **배경이 바뀌었다.** 목업은 새 캡처 `Reference_Lobby_Current_v2.png`(1920×1080, 좌하단 비어 있음) 위에 그린다. 이것도 다시 그리지 않는다.
- 결과물: `LobbyBottomLeft_A2_Mockup.png` + 3절 2번 조각(`Extracted_Draft/`, `layout.json`, SVG 원본)까지 한 번에.
