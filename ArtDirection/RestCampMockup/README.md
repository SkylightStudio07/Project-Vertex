# 휴식 야영지 UI 목업

요청서와 `../UI_Mockup_Split_Workflow.md`에 따른 완성 화면 목업입니다. 세 PNG 모두 **1920×1080**입니다.

| 파일 | 내용 |
|---|---|
| `Rest_Menu_Default.png` | 오른쪽 행동 메뉴. 세 행동 모두 기본 상태. 뒤 장면은 어둡게 처리했습니다. |
| `Rest_Menu_States.png` | 같은 메뉴에서 `휴식`은 청록 테두리·막대·화살표의 마우스 올림 상태, `동료 귀환`은 낮은 대비와 자물쇠의 잠김 상태입니다. `강화`는 기본 상태입니다. |
| `Rest_Camp_Labels.png` | 메뉴를 닫은 원래 밝기의 야영지. 모닥불 안내와 왼쪽 알케미스트의 이름·행동 표시입니다. |
| `PROMPTS.txt` | 내장 imagegen 도구에 실제로 제출한 생성·편집 프롬프트 3개와 합성 처리 기록입니다. |

## 디자인과 원본 보존

- `Reference/Current_Camp.png`를 세 장의 실제 바탕으로 사용했습니다. 배경·텐트·동료·소품을 재생성하지 않았습니다. `Current_Menu.png`, `Current_NameTag.png`, `Base_Quarters.png`, `LobbyKit_v2`의 기준 이미지와 설명도 확인했습니다.
- 새 패널·종이 면·일러스트·표지·글자는 모두 **내장 imagegen**으로 그렸습니다. 먹색의 잘린 모서리, 낮은 명도의 종이 띠, 작은 정합 표시, 짧은 청록 선으로 구성했습니다. SVG 및 코드로 그린 판·아이콘은 사용하지 않았습니다.
- 후처리는 생성된 래스터의 크롭·크기 조정·알파 합성과 명도 조정뿐입니다. 원본 장면에 새 UI를 얹었으며, 기존 모닥불 안내는 새 불투명 안내판으로 덮었습니다.
- 메뉴는 화면 약 `[1200,145,660,763]` 안에 있습니다. 중앙의 불꽃·냄비를 가리지 않습니다. 메뉴 장면의 RGB는 원본의 70%로 낮추고 상단 HUD와 지도·덱 버튼의 원본 픽셀을 보존했습니다. 메뉴 그림도 RGB 74%로 눌러 밤 장면에 맞췄습니다.
- 이름표의 이름 띠는 약 200×44px입니다. 아래에 `시약 가열 중` 한 줄과 머리 쪽의 짧은 연결선을 두었습니다. 모닥불 안내는 x960, y370 부근입니다.
- 목업의 글자·숫자는 예시입니다. 게임 적용 단계에서는 제목·이름·행동 설명·회복량을 런타임 텍스트로 분리해야 합니다.

## 검증

- 세 PNG의 크기와 최종 외관을 확인했습니다. 한글 문구, 행동별 그림, 텍스트 겹침, 불꽃 가림 여부를 확인했습니다.
- 기본/상태 화면의 차이는 **221,535픽셀**, 범위는 x1216–1836, y291–834입니다. 두 상태 행의 지정 영역 밖 차이는 **0픽셀**입니다. 배경의 어둡기, 메뉴 외곽·제목·강화 행은 두 장에서 동일합니다.
- 이름표 화면에서 두 표지 합성 영역 밖의 원본 대비 차이는 **0픽셀**입니다.
- 이 결과물은 검토용 완성 목업만 제공합니다. 분절 에셋, 에셋 시트, layout.json, Unity 적용은 이번 요청 범위에 따라 만들지 않았습니다.
- 요청된 산출물 중 미완료 항목은 없습니다. 기존 파일을 보존했으며, 작업 파일 작성은 `ArtDirection/RestCampMockup/` 안에서만 수행했습니다. `Assets/`, `Packages/`, `ProjectSettings/` 변경 및 git 사용은 없습니다. imagegen 자체의 자동 저장 원본은 도구 기본 저장 위치에 남습니다.
