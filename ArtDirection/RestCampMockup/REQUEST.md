# 휴식 노드 야영지 UI · 목업 요청

휴식 노드 화면을 밤의 야영지로 새로 만들었다. 배경 · 텐트 · 모닥불 · 동료는 게임에 이미 들어가 있고, **그 위에 뜨는 UI만** 새로 디자인한다.
이번에는 **완성 화면 목업만** 받고, 분절은 그림을 고른 뒤 따로 요청한다. 작업 방식은 `../UI_Mockup_Split_Workflow.md`를 따른다.

## 바꾸는 것 / 그대로 두는 것

| 바꾼다 | 그대로 둔다 |
|---|---|
| 모닥불을 누르면 열리는 행동 메뉴 (휴식 · 강화 · 동료 귀환) | 야영지 그림 전체 (배경, 텐트, 모닥불, 동료) |
| 동료에 마우스를 올리면 뜨는 이름표 | 맨 위 HUD 바와 오른쪽 위 지도 · 덱 버튼 |
| 모닥불 위에 뜨는 안내 글자 표시 | |

지금 메뉴는 예전 조각을 복제한 임시 판이라 틀과 버튼이 어긋나 있다. 고쳐 쓰지 말고 **새로 디자인한다.** (`Reference/Current_Menu.png`)

## 게임 동작 (그림이 이걸 견뎌야 한다)

- 처음에는 메뉴 없이 야영지만 보인다. 모닥불을 누르면 메뉴가 열리고 뒤 장면이 어두워진다. 메뉴 밖을 누르면 닫힌다.
- 행동은 셋이고 하나를 고르면 휴식이 끝난다. 항목별 상태는 **기본 · 마우스 올림 · 잠김**이다. 강화는 강화할 카드가 없으면 잠기고, 동료 귀환은 동료가 없으면 잠긴다.
- 메뉴가 열려도 **화면 가운데의 모닥불은 보여야 한다.** 메뉴는 화면 오른쪽 세로 판으로, 대략 x 1200~1860 · y 130~980 안에 놓는다. 오른쪽 동료는 어두워진 판 뒤로 가려져도 된다. 더 나은 구성이 있으면 바꿔도 되지만 불을 가리면 안 된다.
- 이름표는 동료 머리 위 약 200×44px, 그 아래에 하는 일 한 줄이 붙는다. 동료는 화면 왼쪽 끝부터 오른쪽 끝까지 어디든 앉을 수 있다.
- 모닥불 안내는 삼각대 위(화면 x 960, y 340~400 부근)에 뜬다. 불을 가리면 안 되며, 밤 배경 위에서 읽혀야 한다.
- 글자 · 숫자는 게임이 쓴다. 회복량(HP 20)처럼 바뀌는 값이 있다.

## 그림 방향

- 게임의 UI 언어를 따른다: 흰 종이 판, 먹색 잘린 모서리, 사선 제도선, 작은 정합 십자, 짧은 청록 막대, 작은 번호 + 넓게 띄운 영문 소제목 + 굵은 한글.
- 다만 밤의 모닥불 곁이다. **판이 화면에서 튀어 불빛을 죽이면 안 된다.** 흰 판을 조금 낮은 명도로 눌러 쓰거나, 먹색 판에 종이 띠를 얹는 식으로 야영지에 어울리게 조정해도 된다.
- 각 행동에는 작은 그림을 하나씩 넣는다: 휴식 = 담요나 머그, 강화 = 망치와 렌치, 동료 귀환 = 멀어지는 발자국이나 거점 방향 표지. 칠한 그림으로.
- 금지: 네온 글로 · 금색 · 그런지 · 빽빽한 회로무늬 · SVG · 도형 조립 · 에셋 시트 · 나무 판자나 양피지 같은 판타지 질감.
