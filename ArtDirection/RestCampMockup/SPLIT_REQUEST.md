# 휴식 노드 야영지 UI · 분절 요청

`Rest_Menu_Default.png` · `Rest_Menu_States.png` · `Rest_Camp_Labels.png`를 **정본으로 확정**한다. 이번에는 **UI만** 잘라 달라.
야영지 그림(배경, 텐트, 모닥불, 동료)과 맨 위 HUD는 조각에 넣지 않는다. 작업 방식은 `../UI_Mockup_Split_Workflow.md` 4단계를 따른다.

## 핵심 규칙

1. **표면은 이미지 모델로 그린 그림.** 정본의 무광 먹색 판, 눌린 명도의 종이 띠, 연필 질감의 그림을 살린다. 정본과 같은 프롬프트로 **UI만 단독으로**(야영지 없이 평평한 바탕 위에) 고해상도로 다시 그려 자르는 방식을 권장한다. 어둡게 깔린 야영지 픽셀이 판 안이나 가장자리에 묻어 나오면 안 된다.
2. **SVG 금지.** 1~2px 선, 짧은 막대, 작은 십자는 단색으로 그려도 된다.
3. **글자 · 숫자 · 영문을 조각에 넣지 않는다.** `REST / MAINTENANCE`, `01`, `REST`, `휴식`, `HP 20 회복`, `모닥불`, 동료 이름, 하는 일은 모두 게임이 쓴다.
4. **2배 PNG**(화면 1px = PNG 2px), 투명 배경, 회전 0°.
5. 외곽은 **이진 알파**(0/255). `soft`로 표시한 조각만 부드러운 알파를 허용한다.
6. 판 · 칸 · 그림 · 글리프를 **나눠** 받는다. 메뉴 판이 밀려 들어오고, 칸이 마우스 올림에 바뀌고, 그림이 살짝 움직이게 하려고.
7. 늘어나는 조각만 **9-slice**. 눈에 띄는 무늬는 고정 모서리 칸에만 둔다. 나머지는 고정 크기.
8. 이 조각은 새 디자인이다. 기존 `UI_Rest_*` 조각과 이름 · 크기를 맞출 필요 없다.

## `layout.json`

- 기준 1920×1080, 왼쪽 위 원점, `[x,y,w,h]` 화면 px (정본에서 잰 값).
- 조각마다 `file` · `png_size_px` · `screen_rect` · `alpha` · `nine_slice_px`.
- 메뉴의 칸 3개 위치, 칸 안의 그림 · 화살표 · 자물쇠 위치는 **칸 왼쪽 위 기준 오프셋**으로도 적어 달라.
- `text_slots`: 제목, 칸의 번호 · 영문 · 한글 제목 · 설명, 모닥불 두 줄, 이름, 하는 일. 자리마다 `[x,y,w,h]` · 정렬 · 크기(px) · 굵기 · 상태별 색(hex: 기본 / 올림 / 잠김) · 자간(px).
- 메뉴 뒤 어둡기: 정본의 곱할 값.
