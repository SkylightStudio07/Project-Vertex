# 성소 화면 · 레이아웃 요청서 (후보 선택 + 후보 상세)

성소 노드는 합류할 동료를 고르는 곳이다. **두 화면**을 다시 그린다.
1. **후보 선택**: 후보 최대 3명을 **사선 띠**로 나란히 보여 준다 (블레이블루 캐릭터 선택처럼, `Reference_DiagonalStrip.png`)
2. **후보 상세**: 고른 후보 한 명의 정보를 보고 합류를 확정한다 (선택과 **분리된 화면**)

- 현재 화면: `Reference_Current_Select.png`, `Reference_Current_Detail.png`
- 스타일 기준: `Reference_LobbyStyle.png` (로비), `Reference_Shop_v2.png` (상점), `Reference_Dialogue_v1.png` (대화창: 이름 + 청록 소속 + 고유색 선)
- **그대로 두는 것:** 캐릭터 그림(스탠딩·성소 전신 아트). 상단 작전 바·MAP·DECK(HUD)는 위에 떠 있으니 자리만 비운다.

## 0. 지금 화면의 문제

1. **배경 그림에 예전 HUD가 그려져 있다** (상단 아래 검은 사다리꼴 패널, 오른쪽 위 육각 MAP/DECK). 배경을 새로 그려야 한다.
2. **선택 화면 왼쪽 정보 칸이 비어 있다** (이름·한 줄 소개뿐, 큰 빈 칸 두 개).
3. **상세 화면이 따로 논다** (먹색 카드 + 별 장식, 전신 아트가 없으면 "전신 아트 미지정" 글자).
4. 후보가 1명이면 화면 오른쪽 절반이 비어 보인다.

## 1. 공통 스타일

- 로비·상점 문법: **오프화이트 종이 판** #EEF0F2, 흑연 선, 사선 컷 모서리, 작은 번호 + 밑줄, 큰 한글 제목 + 작은 영문 라벨, 청록 #0DB8F2는 선·점·강조에만.
- 성소는 "동료와의 연결" 장소다 — 축복(마키나)처럼 신비 쪽은 아니고, **작전 기록실** 느낌. 별·꽃잎은 쓰지 않는다.
- 이름 표기는 대화창 v1과 같게: **이름(먹색 굵게) + 옆 청록 소속 + 이름 아래 캐릭터 고유색 가는 선**.
- 반투명 금지 (불투명 판, 그라데이션이 필요하면 그림에 굽기).

## 2. 후보 선택 화면

```
┌──── 상단 작전 바 (HUD) ────┐                                         [MAP][DECK]
 01 ─
 성소  SANCTUARY / COMPANION SELECT                                   ← 제목 줄 (72,120)
 동료를 한 명 고르십시오                                               ← 안내 한 줄

 ╱────────────╱────────────╱────────────╱
╱  01         ╱  02         ╱  03 🔒      ╱      ← 사선 띠 3장, 기울기 -12°
│  (스탠딩     │  (스탠딩     │ (흐린        │         각 띠: 폭 520, 높이 720
│   크롭)      │   크롭)      │  실루엣)     │         (x 140 ~ 1780, y 200 ~ 920)
│             │             │             │
│▔▔▔▔▔▔▔▔▔▔▔▔│▔▔▔▔▔▔▔▔▔▔▔▔│▔▔▔▔▔▔▔▔▔▔▔▔│      ← 띠 아래 이름 띠 (먹색)
│ 치하라 쇼    │ 이름         │ 잠긴 후보    │         이름 + 청록 소속, 아래 고유색 선
╱  VERTEX/협력자╱             ╱ 구출 의뢰 필요╱
                                                                      [ 후보 확인 → ]
```

| 영역 | 위치 · 크기 (1920×1080) | 형태 |
|---|---|---|
| 제목 줄 | (72, 120) | 번호 "01" + 큰 "성소" + 영문 "SANCTUARY / COMPANION SELECT" + 아래 안내 한 줄 |
| **후보 띠 ×3** | x 140~1780, y 200~920, 띠 폭 약 520, 기울기 -12°, 띠 사이 흑연 헤어라인 + 얇은 청록 선 | 종이 판 안에 캐릭터 스탠딩을 크롭해 채운다(얼굴~허리). 띠 왼쪽 위 작은 번호 01~03 |
| 띠 아래 **이름 띠** | 각 띠 하단 120px | 먹색 띠: 이름(흰색 굵게) + 청록 소속 + 고유색 선. 블레이블루의 이름 띠처럼 띠 기울기를 따라 잘림 |
| 띠 상태 | — | **기본** / **호버**(띠가 앞으로 나오며 밝아짐, 청록 테두리, 다른 띠 흐려짐) / **선택됨**(청록 두꺼운 아래 선 + 번호 칸 청록 채움) / **잠김** |
| **잠긴 후보** | 띠 자리 그대로 | 캐릭터 대신 **흐린 실루엣**(먹색 10%) + 가운데 자물쇠 기호 + 이름 띠에 "잠긴 후보" / 아래 작은 해금 조건 ("구출 의뢰 · 구조 신호") |
| 후보 확인 버튼 | (1566, 938) 326 × 72 | 상점 나가기 버튼과 같은 자리·문법 ("후보 확인 / DETAIL" + →). 선택 전에는 비활성 |
| 배경 | 전체 | 예전 HUD가 없는 새 배경: 작전 기록실 도면 느낌의 종이 바탕 + 옅은 격자·눈금. 상단 0~106px은 HUD 자리라 비운다 |

- 후보가 1~2명일 때도 **띠는 항상 3장**. 비는 자리는 잠긴 후보 띠로 채운다.
- 띠 안의 캐릭터 크롭은 게임에서 한다 (그림 원본 + 마스크). 목업에는 `Assets/Art/Characters/Joining Characters/CP01 복사.png` 를 넣고, 나머지 자리는 잠긴 후보로.

```

│ 피를 매개로 상대를 베어버리는 …    │        │   (성소 전신 아트 / 없으면 스탠딩) │
```

| 영역 | 위치 · 크기 | 형태 |
|---|---|---|
| 이름 줄 | (72, 130) | 번호 "02" + 이름(큰 굵게) + 청록 소속 + 아래 고유색 선 |
| **정보 판** | (72, 230) 620 × 640 | 종이 판, 왼쪽 위 사선 컷. 위에서부터: PROFILE 소개 문단 / 호감도 레벨 + 단계 막대 / **합류 카드 칸**(카드 아트 크롭 + 이름 + 코스트 + 설명) / 보상 풀 요약 한 줄. 각 구역 앞 줄표 라벨 |
| **전신 아트 영역** | (760, 130) 1100 × 790 | 종이 판 없이 배경 위에 캐릭터가 크게. 뒤에 옅은 원형 눈금·사선 장식. **아트가 없을 때**는 같은 자리에 스탠딩 그림을 쓴다 — "미지정" 같은 글자 칸은 두지 않는다 |
| 뒤로 · 합류 | (72, 938) 280 × 72 / (1566, 938) 326 × 72 | 뒤로는 흰 종이 버튼, 합류는 먹색 강조 버튼 (주 동작) |
