- **좌표는 1920×1080 기준**. 원본이 1672×941이므로 ×1.148로 옮긴다. 다른 시설 화면(`../../LoadoutMockup/Extracted_Draft/layout.json`)과 같은 규칙.
- SVG 원본과 2배 PNG를 같이 준다. **글자는 굽지 않는다 (게임 TMP).**
- 이번 범위는 **후보 선택 화면만**. 후보 상세 화면은 다음 요청.

## 0. 이 화면은 조각이 적다

대부분 게임에 이미 있는 것을 다시 배치한다. 새로 그릴 것은 바탕판과 버튼 정도다.

| 요소 | 처리 |
|---|---|
| 캐릭터 전신 | **조각에 넣지 않는다.** 게임의 성소 전신 아트를 쓴다. 치하라는 그림 자체에 피 웅덩이가 있다. 자리 rect만 `layout.json`에 |
| 잠긴 후보 실루엣 | **조각에 넣지 않는다.** 게임이 실제 캐릭터 그림을 실루엣 셰이더로 칠한다. 자리 rect만 |
| 상단 작전 바 · MAP · DECK | 게임 HUD. 상단 0~106px는 비워 둔다 |
| 자물쇠 | 기존 `Icon_Lock` 재사용 (`../../LoadoutMockup/Extracted_Draft/`) |
| 제목 · 이름 · 소속 · 해금 조건 · 버튼 글자 | 전부 TMP. 글자 상자만 `layout.json`에 |

## 1. 고칠 것

| # | 고칠 것 |
|---|---|
| 1 | **`01`이 두 번 나온다.** 왼쪽 위 화면 제목 `01 성소`와 후보 번호 `01 선택 중`이 같은 크기라 헷갈린다. 화면 제목의 번호를 지우고 `성소` + `SANCTUARY / COMPANION SELECT` + 안내 한 줄만 남긴다. 후보 번호(01·02·03)는 그대로 |
| 2 | **잠긴 칸 문구 대비가 약하다.** 회색 면 위 회색 글자라 해금 조건이 거의 안 보인다. `잠긴 후보`는 먹색 70%, 해금 조건 한 줄은 먹색 55% 정도로 올린다. 해금 조건 문구는 후보마다 다르다 (게임이 채움, 예: `구출 의뢰 · 구조 신호`). 두 줄까지 들어가는 글자 상자로 |
| 3 | **소속 글자도 캐릭터 테마색.** 이름 아래 가는 선과 소속(`VERTEX / 협력자`)을 같은 테마색으로 칠한다 (치하라 진홍, 알레시아 황동). 목업은 치하라 기준 진홍으로. 시안 청록은 `선택 중` 표시와 활성 면 경계선에만 |
| 4 | **그림자는 오른쪽 아래 하드 섀도우만.** 흐리게 번지는 그림자는 쓰지 않는다. `후보 확인` 버튼은 오른쪽 아래 12px, 먹색 35% 정도의 딱 떨어지는 그림자 (출정 준비 화면과 같은 규칙, `../../ArtDirection.md` 그림자 절) |
| 5 | **잠긴 실루엣 크기.** 실루엣 자리 rect는 활성 후보의 전신 자리와 같은 높이로 잡는다 (게임이 그림 비율대로 맞춤). 목업의 망치 실루엣은 예시일 뿐이다. 02 자리는 실제로 **자기 키 1.5배 방패 + 짧은 창**을 든 캐릭터(알레시아)가 들어간다 |

## 2. 조각 `Extracted_Draft/`

| 파일 | 내용 |
|---|---|
| `Sanctuary_BG.png` (1920×1080) | 바탕 회백 면 + 사선 면 3장 경계 + 옅은 격자 · `+` 표식만. **캐릭터 · 글자 · 버튼 없이** |
| `Panel_Active`, `Panel_Locked` | 사선 면 하나씩 (활성 = 밝은 회백, 잠김 = 한 단계 어두운 회백). 면 3장을 게임에서 바꿔 칠할 수 있게 따로. 사선 기울기는 목업과 같게 |
| `Line_ActiveEdge` | 활성 면 왼쪽 경계의 가는 청록 선 |
| `Mark_Selected` | 후보 번호 옆 청록 점 + `선택 중` 자리 |
| `Rule_Name` | 이름 아래 가는 선 (흰색으로 그려 두면 게임이 테마색으로 칠한다) |
| `Button_Detail`, `Button_Detail_Hover`, `Button_Detail_Disabled` | `후보 확인 / DETAIL →` 버튼 (먹색 판 + 아래 청록 줄 + 하드 섀도우는 따로) |
| `Shadow_Button` | 버튼 아래 하드 섀도우 (버튼과 따로) |
| `layout.json` | 아래 rect 전부 + 글자 상자(크기 · 색 · 정렬 · 자간) |

`layout.json`에 꼭 들어갈 rect:
- 후보 자리 3개: 각 사선 면 다각형 꼭짓점, 캐릭터 전신 자리 rect, 후보 번호 · `선택 중` 위치
- 이름 블록: 이름 · 이름 아래 선 · 소속 · `합류 가능` 상태 줄
- 잠긴 칸: 자물쇠 · `잠긴 후보` · 해금 조건(두 줄)
- 제목 줄: `성소` · 영문 라벨 · 안내 한 줄
- `후보 확인` 버튼과 그 그림자
