# 성소 후보 선택 v2 — 2026-10-23

지도 기하학 v3는 과하다는 사용자 판단으로 미채택, 지도는 현행 유지. 성소는 별도 요청으로 절제된 선택 화면 재설계를 진행했다.

- 결과: Sanctuary_Select_Mockup_v2.png (1672×941 생성 원본).
- 프롬프트: GENERATION_PROMPT_Select_v2.txt.
- 방식: 내장 image_gen. 현행 캡처와 현재 치하라 쇼 전신 CP_01/CP_01_Chihara.png를 참조.
- 사선 캐릭터 크롭 카드와 큰 검은 이름 띠를 없애고, 화면을 연속된 회백 배경 면으로 나눴다. 캐릭터는 기울이거나 사선으로 자르지 않는 전신 배치. 활성 후보는 넓게, 잠김 후보 둘은 낮은 대비로 배치했다.
- 이름/소속은 배경 위 간결한 텍스트, 후보 확인은 오른쪽 아래 먹색 버튼. HUD·MAP·DECK·잠김 조건을 유지했다.

검토용 이미지이며 원본 픽셀 보존 합성본은 아니다. 잠김 실루엣은 배치 예시이며 실제 캐릭터 자산으로 확정한 것이 아니다.

## 후보 상세 v2 — 2026-10-23

- 결과: `Sanctuary_Detail_Mockup_v2.png` (1672×941 생성 원본).
- 프롬프트: `GENERATION_PROMPT_Detail_v2.txt`. 내장 image_gen으로 생성.
- 참조: 새 선택 화면과 사용자가 추가 제공한 최신 상세 캡처 `Reference_Current_Detail.png`.
- 최신 캡처의 공격 자세, 호감도 Lv.1, 재장전 카드의 에너지 1 · 탄약 0 및 최대 탄약 재장전 설명, 보상 카드 없음 상태를 반영했다.
- 왼쪽 정보판과 오른쪽 전신 구성, 뒤로/합류 동선을 유지하고 원형 눈금과 촘촘한 격자 대신 저대비 사선 면을 적용했다. 이름 선과 소속은 진홍색, 버튼과 정보판에는 작은 우하단 그림자를 사용했다.
- 캐릭터와 카드 그림은 생성 모델이 재현한 검토용 이미지다. 실제 적용 시 원본 아트와 TMP 텍스트를 사용한다. 상세 화면 분절 및 Unity 적용은 진행하지 않았다.

## 후보 선택 v3 · 분절 완료

- 요청서: `SPLIT_REQUEST_v2.md`. 이번 분절은 **선택 화면만** 대상이다.
- `Sanctuary_Select_Mockup_v3.png`: 1920×1080, 제공 SVG 조각과 프로젝트 캐릭터 원본으로 조립한 검수 이미지.
- `Extracted_Draft/`: SVG 15종과 대응 PNG 15종. UI 12종은 2배, 전체 배경/베이스/가이드 3종은 1920×1080. `layout.json`, `README.txt`, `validation.json`, `Asset_Overview.png` 포함.
- `Sanctuary_Select_v3_Package.zip`: 검수 목업 및 Extracted_Draft 전체.
- 화면 제목 번호 제거, 소속/이름 선 진홍색 통일, 잠금 문구 70%와 해금 조건 55%, 동일 높이 전신 rect, 확인 버튼 12px 우하단 하드 섀도우 반영.
- PNG/SVG에 글자·캐릭터·실루엣을 포함하지 않는다. HUD 및 기존 자물쇠는 외부 재사용. 텍스트 크기·색·정렬·자간과 상태 전이는 layout에 기록.
- 현재 알레시아 원본은 요청서의 ‘키 1.5배 방패·짧은 창’과 다르다. 검수 이미지에는 기존 원본의 실루엣을 그대로 사용했다. 런타임 캐릭터 참조는 외부이며 슬롯 높이는 동일하게 지정했다.
- 선택 경계선은 승인된 목업의 위치(활성 면 오른쪽/02 면 왼쪽)를 따른다.
- SVG 크기, PNG 배율/투명도, 글자 및 임베디드 그림 미포함, 텍스트 박스 폭, HUD 상단 여백, 외부 경로를 검사했다. 두 검수 이미지를 시각 확인했다.
- 재생성: `python ArtDirection/SanctuaryMockup/Redesign_v2/build_select_delivery.py` (Pillow, Node, 로컬 resvg 사용). Unity 씬·임포터·meta 파일은 수정하지 않았다.
