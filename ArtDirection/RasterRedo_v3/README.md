# 작은 UI v3 방향 목업

이미지 모델로 생성한 완성 화면 3장. SVG·도형 조립·에셋 시트 미사용. 이번 납품은 방향 검토용으로 분절 및 Unity 적용은 하지 않았다.

- Battle_SmallUI.png: 현행 전투 장면에서 일시적인 대형 컷인을 비우고 처치 기록 두 줄(보스 칩 포함), 펼친 동료 지시 두 줄(READY/충전 중), 접힌 탭, 맵·덱 버튼을 배치했다. 덱 버튼은 Hover다.
- DeckList_Close.png: 카드 목록 하단 CLOSE와 우측 상단 Normal/Hover 비교. 흰 종이와 얇은 중성 테두리, 잘린 모서리 및 딱딱한 받침을 사용했다.
- CardDetail_Buttons.png: 확대 카드 오른쪽 제거/Cancel, 우측 비교 칸의 Normal/Hover. 제거는 먹색+작은 청록 막대, Cancel은 뼈흰색이다.

## 기준 및 제작

무광 먹색/뼈흰색, 끝부분에 제한한 옅은 톤 면, 짧은 청록 강조를 적용했다. 실제 생성 프롬프트는 PROMPTS.txt. 내장 image_gen으로 전체 화면을 생성하고 반환된1672×941 원본을1920×1080으로 리샘플링해 저장했다. 별도 글자·도형을 덧그리지 않았다.

전투는 Current_Battle_Full 장면을 참조했다. 덱 목록과 카드 상세는 전체 화면 캡처가 제공되지 않아 해당 버튼 크롭과 전투 장면으로 주변 화면을 구성했다. 따라서 주변 목록·카드 설명·카드 상세 배경은 방향 확인용이며 현행 화면의 정확한 복원이 아니다. 생성 과정에서 버튼 및 목록 크기가 일부 확대됐으며 비교 칸 안 상태끼리의 모양/크기를 맞춘 시안이다. 실제 적용 좌표와 픽셀 단위 동일 외곽은 목업 확정 후 분절 단계에서 고정한다.

확인: PNG3장 모두1920×1080. 요청한 여섯 UI와 상태 비교 포함. 기존 Reference 및 게임 Assets는 변경하지 않았다.
