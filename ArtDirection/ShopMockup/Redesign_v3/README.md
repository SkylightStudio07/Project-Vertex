# 전투 중 보급 상점 v3

- 결과: `Shop_Mockup_v3.png`, 1672×941 생성 원본.
- 참조: 사용자가 제공한 현행 상점 캡처 `Reference_Current.png`.
- 생성 방식: 내장 image_gen, 프롬프트 `GENERATION_PROMPT.txt`.
- 토냐와 유적 배경은 왼쪽, 상품은 오른쪽으로 구성. 얼굴을 가리던 이름판을 카운터 아래로 이동했다.
- 상품별 받침과 가격표를 묶고, 백색·회청색 배경 면 및 우하단 그림자로 진열 영역의 구분을 강화했다.
- 카드 6장, 보급품 4개, 크레딧 33, 카드 제거 75와 나가기 동선을 유지했다. 현재 잔액보다 비싼 가격은 회색이다.
- 시각 검토용 생성 이미지이며 원본 픽셀 보존 합성본은 아니다. 캐릭터·카드·아이템·문자 일부는 생성 과정에서 달라질 수 있으므로 실제 적용 시 프로젝트 원본과 TMP를 사용한다.
- 분절, layout.json, Unity 적용은 이번 작업 범위에 포함하지 않았다. 기존 상점 파일은 보존했다.

## SPLIT_REQUEST_v3 · v4 분절 완료

- 수정 검수본: `Shop_Mockup_v4.png` (1920×1080). 프로젝트 토냐·유적·카운터·아이템 원본, 실제 게임 캡처의 카드 6장을 사용해 조립했다. 생성 목업에서 카드 그림을 추출하지 않았다.
- `Extracted_Draft/`: 신규 SVG 20종 및 대응 PNG 20종 (Shop_BG 1배, 나머지 19종 2배), `layout.json`, `README.txt`, `validation.json`, `Asset_Overview.png`.
- `Shop_v4_Package.zip`: 수정 목업 및 위 폴더 전체. 기존 자산 15종은 요청대로 외부 참조이며 ZIP에 중복 포함하지 않는다. 같은 Redesign_v3 폴더 구조로 풀어야 상대경로가 유지된다.
- 구매 불가 받침/보급품 칸/가격표, Hover와 서비스 Disabled, 나가기 Pressed를 제공한다. 가격은 실제 컴포넌트 기본값인 Color.red로 표시하고 런타임 `unaffordableColor`에 바인딩한다.
- 보급품 이름은 전투 부스터·최루탄·열화 수류탄·가스 마스크로 확인했다. 각 칸에 16px 한 줄 말줄임 영역을 추가했다.
- 재화 숫자 앞 Icon_Credit, 닫기·나가기 아이콘, 워터마크·품절 표시 등은 v2 재사용. 가격표는 원본 PNG 기준 사방 24px 9-slice.
- 그림자는 조각에 굽지 않았으며 layout에 Unity Shadow 설정을 기록했다. 큰 판 12px/먹색30%, 받침·칸8px 및 가격표6px/먹색24%, 흐림0.
- PNG 크기·투명도, 텍스트/그림/필터 미포함, 9-slice 경계, 외부 참조, TMP 박스 폭, ZIP 무결성을 검사했다. v4 및 조각 시트를 시각 검수했다.
- 카드 캡처 해상도는 제공된 게임 스크린샷에 한정된다. 런타임은 원래 카드 프리팹을 사용한다. Unity 씬·에셋·meta 파일은 변경하지 않았다.
- 재생성 스크립트: `build_shop_delivery.py` (Pillow + Node/resvg).
