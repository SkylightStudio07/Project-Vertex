# 상점 화면 · 레이아웃 요청서 (v2 — 로비 스타일)

상점 화면을 **로비 메인(`Reference_LobbyStyle.png`)과 같은 문법**으로 다시 짠다.
- 현재 화면: `Reference_Current.png`
- 반려된 v1: `Shop_Mockup_v1_Rejected.png`
- **그대로 두는 것:** 상점 주인 스탠딩, 카운터(진열대) 그림, 카드 그림(카드 프리팹), 아이템 아이콘, 배경.
- **상단 작전 바와 MAP·DECK 버튼은 상점에서도 보인다.** 이 둘은 전투 HUD(먹색)이다. 상점 패널이 이것들을 가리면 안 된다.

## 0. v1이 안 된 이유

v1은 전투 HUD의 먹색 판을 그대로 가져와서 **"검은 상자 하나에 카드와 아이템을 넣은 화면"**이 됐다. 기능은 맞지만 이 상점만의 얼굴이 없다.
- 상점은 전투가 아니라 **시설**이다. 로비의 탐색 개시, 베이스캠프, 무기고 같은 쪽 화면이다. 그래서 전투 HUD가 아니라 **로비의 문법**을 따른다.
- 전투 HUD(상단 바, MAP·DECK)는 위에 떠 있는 먹색 층이고, 그 아래 상점 본문은 로비처럼 **종이 톤**이다. 두 층이 겹치는 모습이 오히려 대비가 된다.

## 1. 로비에서 가져올 문법 (`Reference_LobbyStyle.png`)

| 로비 요소 | 상점에서 |
|---|---|
| **오프화이트 종이 패널** + 모서리 사선 컷 + 얇은 흑연 테두리 | 진열 패널 전체. 한 판이 아니라 **구역마다 따로 잘린 판** 여러 장이 어긋나게 겹친다 |
| **작은 번호** "01 / 02 / 03" + 짧은 밑줄 | 각 구역 왼쪽 위: 01 카드, 02 보급품, 03 서비스 |
| **큰 한글 제목 + 작은 영문 라벨**(자간 넓게) | "카드 / CARD MODULE", "보급품 / SUPPLY", "카드 제거 / REMOVE SERVICE" |
| **흐린 선화 워터마크 엠블럼** (탐색 개시 판의 나침반처럼) | 구역마다 판 오른쪽에 크게, 아주 옅게(흑연 6~8%). 카드 = 카드 묶음, 보급품 = 상자, 서비스 = 가위·절단선. **별·나침반은 금지** |
| **반전된 먹색 판 하나** (베이스캠프 판) | **상점 주인 이름판**. 상점 전체에서 먹색 판은 이것 하나뿐 |
| **청록 가로 막대** (탐색 개시 판 아래) | 크레딧 판 아래 한 줄 |
| **"→" 화살표 + Lv 같은 작은 꼬리표** | 가격표 오른쪽 끝, 나가기 버튼 |
| **가장자리 마이크로 카피** (EXPEDITION / PEOPLE …) | 패널 귀퉁이 작은 영문 두세 줄: "SUPPLY DEPOT / OPEN FOR TRADE" 류 |
| **등록 표시 "+" · 얇은 모서리 선** | 패널 바깥 모서리 몇 곳 |

## 2. 색

| 역할 | 값 |
|---|---|
| 패널 바탕 | 오프화이트 #F1F0EC (로비 판과 같은 종이 질감, **불투명**) |
| 테두리·선 | 흑연 #2A2C30, 1~2px |
| 큰 글자 | 먹색 #16181B |
| 작은 영문·보조 | #6B7078 |
| 반전 판 (상점 주인 이름판) | 먹색 #16181B + 흰 글자 |
| 청록 #0DB8F2 | 크레딧 아래 막대, 살 수 있는 가격 숫자, 호버 테두리. **면 채움 금지** |
| 살 수 없음 | 가격 숫자 #A2A7AE (흐린 회색) |
| 빨강·노랑 | 금지 |

흰 배경 위의 흰 판이 녹지 않게, 판 바깥에 **불투명 회색 #C9CCD1 그림자 띠**를 오른쪽 아래로 4px 둔다(로비 판처럼). 굵은 검은 외곽선은 쓰지 않는다.

## 3. 배치 (1920×1080, 왼쪽 위 원점)

```
┌──── 상단 작전 바 (HUD) ────┐                                   [MAP][DECK]
                                                     ┌ 크레딧 판 (1500,120) 380×92 ─┐
                                                     │ CREDITS         14 │ 청록 막대 │
 ┌ 이름판 (먹색, 반전) ┐                                └──────────────────────────────┘
 │ 02 · 상점 주인      │     ┌ 01 카드 판 (760,150) 760×620, 사선 컷 ──────────────┐
 │ 토냐                │     │ 01                                     (카드 묶음    │
 │ "필요한 게…"        │     │ 카드  CARD MODULE                        워터마크)  │
 └────────────────────┘     │ [카드][카드][카드]                                  │
                             │  가격→ 가격→ 가격→                                  │
   (상점 주인 스탠딩)         │ [카드][카드][카드]                                  │
                             │  가격→ 가격→ 가격→                                  │
  ═════ 카운터 ═════          └─────────────────────────────────────────────────────┘
                                   ┌ 02 보급품 판 (1540,230) 340×460 ┐
                                   │ 02 보급품 SUPPLY   [칸][칸]     │ ← 카드 판과 살짝 겹쳐
                                   │                    [칸][칸]     │   어긋나게 놓인다
                                   └────────────────────────────────┘
                             ┌ 03 서비스 판 (760,790) 560×110 ┐       [ 나가기  LEAVE → ]
                             │ 03 카드 제거 REMOVE   75 →    │        (1566,938) 326×72
                             └──────────────────────────────┘
```

| 영역 | 위치 · 크기 | 내용 |
|---|---|---|
| **01 카드 판** | (760, 150) 760 × 620 | 번호 + "카드 / CARD MODULE" + 카드 3×2 (카드 150×230, 열 간격 40, 줄 간격 18) + 카드 아래 가격표 150×28. 제목 줄 높이 70 → 격자 y 220~754로 판 안에 들어간다 (카드는 게임에서 호버 시 확대). 오른쪽 위에 카드 묶음 워터마크 |
| **02 보급품 판** | (1540, 230) 340 × 460 | 카드 판 오른쪽 끝에 **20px 겹쳐** 올라탄다(로비 버튼판들이 어긋나 붙는 느낌). 번호 + "보급품 / SUPPLY" + 아이템 칸 2×2 (130×130) + 가격표 |
| **03 서비스 판** | (760, 790) 560 × 110 | 번호 + "카드 제거 / REMOVE SERVICE" + 오른쪽 가격 + →. 로비 하단 시설 버튼(무기고·의뢰)과 같은 모양 |
| **크레딧 판** | (1500, 120) 380 × 92 | 작은 "CREDITS" + 큰 숫자(52pt 먹색) + 판 아래 청록 막대 4px. 로비 상단 경험치 바 느낌 |
| **상점 주인 이름판** | (40, 260) 520 × 150 | **유일한 먹색 반전 판.** "02 · SHOPKEEPER" 작은 라벨 + 이름 "토냐"(큰 글자) + 대사 한 줄(말풍선 역할) |
| **나가기** | (1566, 938) 326 × 72 | 로비 버튼 문법: 종이 판 + "나가기 / LEAVE" + → (전투 END TURN과 **같은 자리**, 다른 옷) |
| **닫기(×)** | 크레딧 판 오른쪽 끝 안쪽 | 작은 × 선화 |

- **가격표:** 종이 띠 + 작은 크레딧 기호 + 숫자 + 오른쪽 작은 →. 살 수 있으면 숫자 청록, 없으면 흐린 회색.
- **품절:** 카드·칸 위에 사선 해칭 + "SOLD OUT" 작은 먹색 도장.
- **호버:** 청록 테두리 1px + 판이 2px 떠오른 그림자 (게임에서 처리).
- 판들이 전부 네모 반듯하지 않고 **한 모서리씩 사선으로 잘려** 있어야 로비 같다. 자르는 모서리는 판마다 다르게(01은 오른쪽 위, 02는 왼쪽 아래, 03은 오른쪽 아래).
