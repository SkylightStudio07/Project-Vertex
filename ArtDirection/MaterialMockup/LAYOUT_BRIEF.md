# 마테리얼 화면 · 레이아웃 요청서

마테리얼은 로비 시설 05로, **작전 기록 / 도감**이다. FGO 인연 자료처럼 대상(적·동료)마다 기록이 **5편**씩 있다. 적은 격퇴할수록, 동료는 호감도가 오를수록 한 편씩 열린다.

**글을 읽는 화면**이라 본문 칸이 넓고 읽기 편해야 한다. 대상은 늘어난다(적 수십, 동료 12~20).

- 지금 화면(훈련장 조각으로 임시 조립): `Reference_Current_Enemy.png`, `Reference_Current_Companion.png`
- 같은 틀: `Reference_Training_Companion.png`(훈련장 동료 편성), `Reference_CardCatalog.png`(무기고 카드 목록)
- 로비 스타일: `Reference_LobbyMain.png`
- 기획: `Docs/기획/마테리얼.md`

## 1. 공통 스타일

- 훈련장·무기고와 같은 틀이다.
  - 1672×941 판, 왼쪽 위 "05 │ 마테리얼 / MATERIAL / ARCHIVE", 오른쪽 위 "← 로비"
- 오프화이트 종이 #EEF0F2, 흑연 선, 청록 #0DB8F2는 선·점·배지에만 쓴다.
- 마테리얼은 **"기록 보관실"** 느낌이다.
  - 읽는 칸은 서류철·관측 보고서처럼 표현한다: 왼쪽 위 문서 번호, 얇은 괘선, 모서리 접힘이나 클립 정도.
  - 장식은 절제한다. 별·꽃잎은 쓰지 않는다.
- 잠김은 회색 + 자물쇠 + 조건 한 줄이다. 미확인 대상은 회색 실루엣 + "???".
- 반투명 판·글로우·빨강·노랑은 쓰지 않는다. 보스 배지도 먹색이다.
