# 무기고 입구 목업 v1

사용자 제공 정비 담당 캐릭터와 아카이브 UI를 참고한 입구 화면. 오른쪽에 장비 강화 / 카드 강화 두 메뉴, 왼쪽에 정비 담당 전신과 대사창을 배치했다. 작업실 배경, 먹색 반투명 패널, 청록 강조를 사용했다.

- 결과: Armory_Hub_Mockup_v1.png
- 입력: Source_Mechanic.png, Reference_Archive.png (사용자 첨부 원본 보존)
- 프롬프트: GENERATION_PROMPT_v1.txt
- 생성: 내장 image_gen, 원본 출력 1672×941.

검토용 목업이다. 캐릭터는 입력을 참조한 생성 결과이며 원본 픽셀을 그대로 합성한 것은 아니다. 제목의 시설 번호는 미지정으로 생략했다. 대사는 배치용 예시. 강화 상세 화면, 분절 및 Unity 적용은 아직 진행하지 않았다.
