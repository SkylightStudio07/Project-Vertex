# 의뢰 · 런 중 UI 조각 요청서

의뢰 게시판에서 받은 의뢰를 **런 중에 보여주는 작은 UI 네 가지**. 화면 전체 목업이 아니라, 기존 화면 위에 얹는 **조각 시트**로 요청한다. 시스템 기획: `Docs/의뢰.md`. 스타일 기준: `QuestBoardMockup/QuestBoard_Posted_Mockup_v1.png`와 같은 시리즈.

## 0. 공통

- 흰 종이 면, 흑연색 선·기호, 포인트 색 **청록 #0DB8F2** 하나. 빨강·노랑 금지.
- 글자는 게임에서 TMP로 얹는다. 목업 글자는 참고용 → 분리 시 지울 수 있게 단색 면 위에.
- 의뢰 유형 기호(회수 상자 · 배달 봉투 · 토벌 교차검 · 구출 십자)는 게시판 키트의 `Icon_Recovery/Delivery/Elimination/Rescue`를 그대로 쓴다.
- 결과물: 각 조각의 **Normal / Hover(필요한 것만)** PNG + 조립 예시 1장씩. 기존처럼 `layout.json` 좌표 포함.

## 1. 진행 알림 토스트 (전투·맵 공통)

의뢰 진행이 생길 때 화면 **오른쪽 위, MAP/DECK 버튼 아래**에 2초 떴다 사라진다. 입력은 막지 않는다.

- 기준 화면: 1920×1080 전투 화면 (`Loadout` 아님). 위치 약 **x 1470, y 130**, 크기 **420 × 76**.
- 여러 개면 아래로 쌓인다 (최대 3개, 간격 8).

```
┌──────────────────────────────────────────┐
│ ▣ │ 의뢰 물품 획득                  [STORY]│  ← 작은 윗줄: 알림 종류 (청록)
│   │ 손상된 블랙박스                       │  ← 큰 줄: 내용 (흑연, Bold)
└──────────────────────────────────────────┘
 ↑ 왼쪽 64px 사각 칸에 유형 기호, 칸과 본문 사이 청록 세로선 2px
```

필요한 변형 (같은 틀, 왼쪽 강조색만 다름):

| 종류 | 윗줄 예시 | 아래줄 예시 |
|---|---|---|
| 획득 | 의뢰 물품 획득 | 손상된 블랙박스 |
| 진행 | 들개 토벌 | 2 / 3 |
| 달성 | 의뢰 달성 — 귀환 시 보상 | 봉인된 서류 |
| 보류 | 아이템 칸이 가득 찼습니다 | 다음 노드에서 다시 획득 |

- **달성**은 틀 전체에 얇은 청록 테두리 + 오른쪽 끝에 작은 `완료` 도장(게시판 `Stamp_Completed_KO` 축소).
- **보류**는 청록 대신 흑연 회색 강조 (경고색 쓰지 않음).

## 2. 출정 준비 · 진행 중 의뢰 요약

출정 준비 화면(`LoadoutMockup/Loadout_Mockup_v1.png`, 1672×941)의 **헤더 오른쪽 빈자리**에 넣는다. 무기고·게시판에서 로비 경험치가 있던 자리와 같은 높이.

- 위치 약 **x 1100, y 26**, 전체 폭 **310**, 높이 **56**. 로비 버튼(1429,27) 왼쪽에 붙는다.

```
진행 중 의뢰  1 / 2                         ← 작은 라벨 (흑연 Medium)
[▣ 블랙박스 회수 ][◆ 봉인된 서류 ]          ← 칩 2개, 각 약 150 × 30
```

- 칩: 종이 면 + 1px 흑연 테두리, 왼쪽 유형 기호, 제목 한 줄(넘치면 말줄임). STORY/구출 의뢰는 칩 오른쪽 끝에 작은 배지 점.
- 칩 **Hover**: 청록 테두리 → 게임에서 아래쪽에 목표 툴팁(기존 상세 패널 축소판)을 띄운다. 툴팁 틀도 한 장 요청: **300 × 110**, 목표 2줄 + 획득 계기.
- 수주한 의뢰가 없을 때: 칩 자리에 흐린 글자 `의뢰 없음 · 의뢰 게시판에서 수주`.

## 3. 맵 노드 표식

맵에서 **의뢰와 관련된 노드**(퀘스트 아이템을 얻는 층, 배달 목적지 상점 등)에 붙는 작은 표식.

- 기존 맵 노드(흑연 테두리 사각 아이콘, 약 86 × 56) **오른쪽 위 모서리에 걸치는 청록 태그** 약 **28 × 28**.
- 태그 안에 유형 기호 축소판(흰색). 모서리가 잘린 평행사변형 또는 작은 깃발 모양.
- 필요한 조각:
  - 태그 기본
  - 태그 강조 (현재 이동 가능한 노드일 때, 청록 외곽 글로우)
  - 노드 호버 시 뜨는 한 줄 말풍선 틀 **220 × 40**: `봉인된 서류 — 상점에 전달`

## 4. 아이템 바 · 의뢰 물품 칸

퀘스트 아이템은 일반 아이템 칸을 차지한다. 일반 아이템과 **한눈에 구분**되게 칸 테두리만 바꾼다.

- 기존 아이템 슬롯과 같은 크기, **청록 테두리 + 왼쪽 아래 작은 유형 기호 배지**.
- 툴팁 끝줄 `의뢰 물품 · 사용 불가`는 게임에서 텍스트로 처리 (이미지 불필요).
- 필요한 조각: 의뢰 칸 테두리 오버레이 1장 (투명 배경, 기존 슬롯 위에 겹친다).

## 하지 말 것

- 토스트에 캐릭터·일러스트 넣지 않기. 기호 + 두 줄 글자만.
- 맵 표식이 노드 아이콘을 가리지 않게 (모서리에만 걸친다).
- 출정 준비 헤더의 제목·로비 버튼 위치를 건드리지 않기.
