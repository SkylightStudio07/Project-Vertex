# 동료 스킬 (지시 · 컷인) · 레이아웃 요청서

전투에 동행한 동료는 저마다 스킬을 하나씩 가진다. 플레이어는 전투 화면 왼쪽 아래의 **지시 버튼**으로 동료 스킬 목록을 펼쳐 스킬을 고른다. 스킬을 쓰면 화면 왼쪽 위로 그 동료의 **컷인**이 짧게 지나간다.

이번에 그릴 것은 지시 버튼, 펼친 스킬 목록, 동료 컷인이다. 기획 문서는 `Docs/기획/동료_스킬.md`이다.

- 참고 이미지
  - `Reference_BattleHUD_v3.png`: 뒤에 깔리는 전투 화면(v3 Oratio). 색과 선은 이 화면을 따른다.
  - `Reference_CardCutIn.png`: 지금 쓰는 **카드 컷인**(파워·유니크)이다. 위치가 비슷하다. 동료 컷인은 한눈에 다른 것으로 보여야 한다. 3절에서 설명한다.
  - `Reference_Motion_LoL_BattleAcademia.png`: 컷인의 **움직임과 구도** 참고. LoL 전투사관학교 케이틀린 궁극기 컷인이다. 모서리에 사선 띠가 박히고, 그 안에 캐릭터 얼굴이 들어간다.
  - `Reference_Look_Persona_Eyes.png`: 컷인의 **그림 구성** 참고. 페르소나식이다. 찢긴 띠 사이로 눈매만 보이고, 굵은 붓 글자가 띠를 가로지른다. **색은 따르지 않는다.** 빨강·검정 대신 우리 색을 쓴다.
  - `Reference_Chihara_Sho.png`: 이번 예시 동료 **치하라 쇼**. 회백색 긴 머리, 붉은 눈, 피를 다루는 능력이다.
- 화면 크기는 1920×1080이다.

## 0. 공통 스타일

- 색:
  - 회백색 #EEF0F2: 판, 컷인 바탕, 글자(먹색 위)
  - 먹색 #16181B: 버튼, 띠, 찢긴 띠, 글자
  - 청록 #0DB8F2: 가는 선, 작은 칸, 준비 표시. 이 셋에만 쓴다.
- **UI 조각에는 빨강·노랑·금색 금지.** 다만 캐릭터 그림(쇼의 붉은 눈, 피) 안의 색은 원화 그대로 둔다.
- 반투명 판과 글로우는 쓰지 않는다. 판은 불투명하다.
- 모서리 절단, 헤어라인, 작은 마름모, `+` 좌표 표식, 4방향 별(Vertex Mark)은 전투 HUD v3와 같은 굵기와 각도로 쓴다.
- 글자(라벨, 스킬 이름, 대사, 숫자)는 게임에서 TMP로 얹는다. 목업에는 넣되 평평한 단색 면 위에 둔다. **단, 컷인의 붓 획 스킬 이름은 그림이다.** 4절에서 설명한다.

## 1. 지시 버튼 (접힌 상태)

| 항목 | 내용 |
|---|---|
| 위치 | 왼쪽 아래. HP 바 위 상태 아이콘 줄(방어·삼각·과녁) 오른쪽, 손패 왼쪽 끝 앞. 대략 x 240~470, y 880~925 |
| 모양 | 먹색 가로 칸, 한쪽 모서리 사선 절단 (END TURN 버튼과 같은 문법, 더 작게) |
| 내용 | 왼쪽 작은 마름모 + "지시" (굵게) + 작은 영문 "ORDER" + 오른쪽 끝 숫자 배지(지금 쓸 수 있는 스킬 수) |
| 준비된 스킬 있음 | 마름모가 청록, 숫자 배지는 청록 작은 칸에 먹색 숫자 |
| 준비된 스킬 없음 | 마름모 회색, 배지 없음 |
| 못 누름 (적 턴) | 칸 전체가 회색 톤 |
| 펼침 | 버튼 위쪽 가장자리에 짧은 청록 선 |

## 2. 펼친 스킬 목록

지시 버튼을 누르면 버튼 **위로** 동료 줄이 펼쳐진다. 동료는 최대 3명이다.

```
   ┌──────────────────────────────────────────────┐
   │ ORDER / 동료 지시                     03     │ ← 얇은 머리 (작은 영문 + 한글, 오른쪽 동행 수)
   ├──────────────────────────────────────────────┤
   ▌[얼굴] 치하라 쇼     흡혈            READY    │ ← 준비됨: 왼쪽 청록 세로선, 또렷함
   │ [얼굴] 동료 B       엄호       ▬▬▬░  1턴     │ ← 턴 충전 중: 흐림 + 진행 막대 + 남은 수
   │ [얼굴] 동료 C ✦     표적 지정  ▬░░░  1/3     │ ← 전투 충전 중 + 인연 강화(✦ 표식)
   └──────────────────────────────────────────────┘
   [◇ 지시 ORDER  1]
```

| 부분 | 내용 |
|---|---|
| 판 | 회백색 불투명 판, 약 460 × 230. 모서리 하나 사선 절단, 가장자리 헤어라인 |
| 줄 | 높이 약 60. 왼쪽부터 **얼굴 칸**(정사각 약 48, 먹색 테두리, 동료 얼굴 크롭) → 동료 이름(작게) → 스킬 이름(굵게) → 오른쪽 충전 표시 |
| 준비됨 | 줄 왼쪽 청록 세로선, 오른쪽 먹색 작은 태그 "READY"(청록 점 하나) |
| 충전 중 | 얼굴·글자 흐림(채도 낮춤), 오른쪽에 얇은 진행 막대(먹색 바탕 + 청록 채움, 4칸 눈금) + 남은 수("1턴" / "1/3") |
| 인연 강화 | 동료 이름 옆에 작은 4방향 별(Vertex Mark), 얼굴 칸 테두리가 **이중선** |
| 호버 | 줄 바탕이 먹색으로 반전되고 글자가 회백색으로 바뀐다(축복·로비 선택지와 같은 문법). 목업에서는 첫 줄을 호버로 그린다 |

- 툴팁(스킬 설명)은 게임의 기존 툴팁을 쓴다. 그리지 않는다.
- 얼굴은 목업에서 첫 줄에 쇼를 넣고, 나머지 두 줄은 회색 실루엣으로 둔다.

## 3. 동료 컷인

스킬을 쓰면 왼쪽 위 모서리로 컷인이 들어와 약 1.2초 머물고 빠진다. 게임은 멈추지 않는다.

### 카드 컷인과 구별하기

`Reference_CardCutIn.png`의 카드 컷인은 **수평** 띠 안에 **카드 그림**을 넣고 먹색 판에 글자를 얹는다. 동료 컷인은 다음 세 가지로 다르게 보여야 한다.

1. **띠가 기울어 있다.** 약 8~10°. 왼쪽 위 화면 밖에서 들어와 오른쪽 아래로 내려가는 사선 띠로, LoL 레퍼런스처럼 모서리에 꽂힌 느낌을 준다.
2. **바탕이 회백색이다.** 카드 컷인은 먹색이다. 회백색 띠 위를 **찢긴 먹색 띠** 여러 줄이 가로지른다.
3. **그림이 눈매 클로즈업이다.** 찢긴 띠 사이로 동료의 눈매가 크게 보인다.

### 구성

```
 (화면 왼쪽 위, 대략 x 0~1050, y 90~440)
 ╲───────────────────────────────────────────╲
  ╲ ORDER · CHIHARA SHO          ◆─────      ╲   ← 작은 영문 라벨 + 청록 선·마름모
   ╲▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓╲   ← 찢긴 먹색 띠
    ╲  ( 눈매 클로즈업 — 회백색 바탕 위 )  흡  ╲  ← 붓 획 스킬 이름이 띠를 가로지름
     ╲▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  혈 ▓▓▓▓▓╲
      ╲───────────────────────────────────────────╲
        [ …쓴 만큼, 채울게. ]                         ← 대사 태그 (먹색 칸 + 회백색 글자)
```

| 부분 | 내용 |
|---|---|
| 사선 띠 | 회백색 바탕, 위·아래 가장자리에 먹색 헤어라인. 오른쪽 끝은 `/` 방향으로 비스듬히 자른다. 띠 높이 약 260 |
| 찢긴 먹색 띠 | 띠 안을 가로지르는 먹색 띠 2~3줄. 가장자리는 페르소나처럼 찢긴 종이 모양이고, 찢긴 틈에 회백색 조각이 튄다. 눈매의 위아래를 가린다 |
| 눈매 | 동료의 눈 부분만 가로로 길게 크롭한다. 선이 굵고 명암이 강한 페르소나 컷 느낌으로 그린다. 쇼의 붉은 눈은 그대로 두고, 눈매 그림 안에서만 피 몇 방울이 흩날려도 된다 |
| 붓 획 스킬 이름 | 띠 오른쪽에 "흡혈"을 굵은 붓 글자로 쓴다. 먹색 글자에 회백색 테두리를 두르고, 찢긴 띠 위로 넘어가게 한다. **그림으로 분절**한다(스킬마다 한 장) |
| 라벨 | 띠 위쪽에 작은 영문 "ORDER · CHIHARA SHO" + 청록 헤어라인 + 끝 마름모 |
| 속도선 | 띠 안 회백색 바탕에 청록·회색 가는 사선 몇 가닥. 띠의 기울기와 같은 방향 |
| 대사 태그 | 띠 아래 왼쪽, 먹색 가로 칸 + 회백색 글자 "…쓴 만큼, 채울게." + 왼쪽 청록 짧은 띠 |
| 인연 강화 | 같은 컷인에 띠 위·아래 **청록 이중선**, 띠 오른쪽 배경에 얇은 Vertex Mark(4방향 별) 워터마크(명도 차 6% 이내). 대사는 "…우리 둘 몫이야. 남김없이." **새 색은 쓰지 않는다** |

### 움직임 (참고, 그림에는 멈춘 순간만)

1. 사선 띠가 왼쪽 위 밖에서 미끄러져 들어온다. 띠 안의 눈매는 반 박자 늦게 따라 들어온다.
2. 찢긴 먹색 띠가 좌우로 갈라지며 눈매가 드러나고, 붓 글자가 찍히듯 나타난다.
3. 약 1.2초 머문 뒤 같은 방향으로 빠진다.

## 4. 결과물

목업 3장 (1920×1080, 전투 화면 위):

1. `CompanionSkill_Order_Mockup.png`
   - 지시 버튼을 펼친 상태로 그린다. 줄 3개(준비됨+호버 / 턴 충전 / 전투 충전+인연 강화).
   - 화면 오른쪽 빈 곳에 **접힌 버튼 상태 3종**(준비 1 / 준비 없음 / 적 턴 회색)을 따로 늘어놓는다. 상태표처럼 그린다.
2. `CompanionSkill_CutIn_Mockup.png`: 치하라 쇼 기본 컷인이 들어와 멈춘 순간.
3. `CompanionSkill_CutIn_Enhanced_Mockup.png`: 같은 컷인의 인연 강화판.

그림 규칙:
- 배경은 `Reference_BattleHUD_v3.png`를 깔고 그 위에 그린다. 적과 캐릭터를 새로 그리지 않는다(컷인 눈매는 예외).
- 분절은 확정 뒤 따로 요청한다. 2배 해상도로 다시 그릴 예정이니 선 굵기는 1px 이상으로 잡는다.
- 눈매는 나중에 동료마다 따로 받는다. 이번에 쇼의 눈매를 그리면서 **크롭 비율(가로:세로 약 4:1)을 정해 주면** 다른 동료도 그 비율로 맞춘다.
