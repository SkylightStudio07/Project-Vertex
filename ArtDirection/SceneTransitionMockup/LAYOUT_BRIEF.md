# 씬 전환 막 v2 · 레이아웃 요청서

로비에서 **출정**·**훈련**을 누를 때, 그리고 전투에서 **귀환**할 때 화면을 덮었다가 다음 씬에서 다시 여는 전환 막이다.
지금 버전(`Reference_Current_*.png`)은 먹색 막 위주라 로비 아트와 결이 다르다. 저해상도라 2K 이상 화면에서 뭉개지는 문제도 있다.
이번에는 **로비 아트풍으로 다시 그리고, 조각을 2배 해상도로** 뽑는다.

- 스타일 기준:
  - `Reference_LobbyMain.png` (로비 — 종이 판, 먹색 띠, 헤어라인, 번호)
  - `Reference_ResultClear.png` (결과 화면 — 같은 가족의 최신 연출)
  - `Reference_TurnBanner_v3.png` (선 굵기, 영문 자간, 사선 각도 기준)
- 지금 모습: `Reference_Current_Closed.png` / `_Loading.png` / `_Opening.png`

## 0. 공통 스타일

- 화면은 1920×1080이다. 좌표는 왼쪽 위 원점, 픽셀 단위다.
- **로비 문법을 따른다.**
  - 종이 #EEF0F2 면이 주인공이다.
  - 먹색 #16181B는 띠·글자·굵은 선에 쓴다.
  - 청록 #0DB8F2는 가는 선, 작은 칸, 진행 막대에만 쓴다.
  - 헤어라인, 작은 영문 라벨, 번호, 눈금, 십자 표식을 쓴다.
- **빨강·노랑·금색 금지.** 반투명 판, 글로우, 별·꽃잎도 쓰지 않는다.
- 막은 **완전 불투명**이다. 막 뒤의 씬이 비치면 안 된다.
- 큰 글자(출정, 귀환, 훈련 / 영문 라벨 / 부제 / NOW LOADING)는 게임에서 TMP로 얹는다.
  - 목업에는 글자를 그려도 된다.
  - 단, 분절할 때 지울 수 있게 **평평한 단색 면 위에** 둔다.

## 1. 움직임 (참고 — 코드가 처리한다)

```
닫힘 0.45초   위 막: 오른쪽 → 가운데        아래 막: 왼쪽 → 가운데 (0.06초 늦게)
              가운데 이음새 선이 좌우로 그어짐 → 엠블럼·글자 등장 → 로딩 칩 등장
로딩 0.9초+   이음새 위 청록 진행 막대가 왼쪽부터 차오름, 선두 표식이 따라감
              엠블럼 천천히 회전, 로딩 칩 점 3개 깜빡임
열림 0.5초    글자 오른쪽으로 빠지며 사라짐
              위 막: 가운데 → 왼쪽          아래 막: 가운데 → 오른쪽, 흰 섬광 한 번
```

이 움직임은 바꾸지 않는다. 그래서 **막이 움직이는 동안 보이는 앞장서는 끝**이 제일 중요하다.
- 위 막: 들어올 때 **왼쪽 끝**이 앞장선다.
- 아래 막: 들어올 때 **오른쪽 끝**이 앞장선다.

## 2. 위 막 · 아래 막 — 가장 큰 변경

```
x=-200                                                          x=2120
┌──┬──────────────────────────────────────────────────────────────┐ y=0
│앞│  위 막 (2320 × 548)  — 종이 면                                    │
│장│  · 위쪽 가장자리: 먹색 얇은 띠 + 작은 영문 "VERTEX // TRANSIT"      │
│선│  · 옅은 격자 / 번호 / 십자 표식 (로비 판처럼)                       │
│끝│  · 큰 워터마크 1개 허용 (종이에서 명도 -4% 이내)                    │
└──┴────────────────────── 이음새 쪽 가장자리 ─────────────────────┘ y=548
     아래 막은 y=532~1080, 위아래·좌우를 뒤집은 짝. 가운데 16px 겹침
```

- **면:** 로비 판과 같은 **종이색 면**을 쓴다. 두 막이 닫히면 화면 전체가 "로비 종이 한 장"처럼 보여야 한다.
  - 먹색 면으로 칠하지 않는다. 먹색은 띠나 블록으로만 쓴다.
- **앞장서는 끝:**
  - 로비 버튼이나 턴 배너처럼 **사선으로 자른다** (각도는 턴 배너 v3와 같게).
  - 끝에서 안쪽으로 **먹색 띠 1개**(폭 60~90)를 두고, 청록 헤어라인 1~2줄과 흰 눈금을 넣는다.
  - 움직이는 동안 "작전 문서 한 장이 밀려 들어오는" 느낌이면 좋다.
- **반대쪽 끝:** 민짜(종이 면 그대로)로 둔다. 화면 밖에 있다가 열릴 때만 잠깐 보인다.
- **이음새 쪽 가장자리:**
  - 먹색 1px 헤어라인과 40px 간격의 짧은 눈금을 넣는다.
  - 둘 다 가장자리에서 **12px 안쪽**에 둔다.
- **위·아래 막 구분:** 서로 다른 그림이어도 되지만, 닫혔을 때는 한 장처럼 이어져야 한다.
  - 예: 위 막은 왼쪽 위에 작은 문서 번호 칸, 아래 막은 오른쪽 아래에 좌표 표기.
- **2배 해상도 대비 (중요):** 2320×2 = 4640px은 텍스처 한도(4096)를 넘는다. 그래서 막을 두 조각으로 나눌 예정이다.
  1. **몸통**: 가로로 늘려도 티가 안 나야 한다. 종이 면 + 가장자리 헤어라인/눈금 위주로 그린다.
  2. **앞장서는 끝**: 사선 + 먹색 띠 + 장식, 폭 약 400.

  그러니 **몸통에는 한 번만 나오는 큰 장식을 두지 않는다**. 워터마크나 번호 칸처럼 위치가 정해진 장식은 앞장서는 끝 조각 안에 넣는다. 워터마크는 따로 조각으로 빼도 된다.

## 3. 이음새 · 로딩 막대 (y=540)

| 조각 | 크기(1x) | 설명 |
|---|---|---|
| `Seam_Base` | 2320 × 24 | 종이 위에 놓이는 레일. 먹색 1px 위·아래선 + 가운데 연회색 홈(6px) + 200px마다 작은 마름모 눈금. 가로로 늘려도 되게 반복 무늬로 |
| `Seam_Fill` | 2320 × 6 | 진행 막대. 청록 단색, 오른쪽 끝(선두)에 흰 광택 40px. 왼쪽 기준으로 가로 스케일한다 |
| `Seam_Head` | 48 × 24 | 선두를 따라가는 표식. 먹색 마름모 + 청록 점, 또는 로비의 작은 화살표 칸 |

## 4. 가운데 제목 판

```
            x=360                                          x=1560
      y=390 ┌──────────────────────────────────────────────┐
            │ [엠블럼]  OPERATION  //  DEPLOY               │ ← 영문 22pt, 청록 (y≈448)
            │ (560,450)        출  정                        │ ← 96pt, 먹색 (y≈506)
            ═════════════════ 이음새 (y=540) ════════════════
            │           작전 지역으로 이동합니다              │ ← 22pt, 회색 (y≈580)
      y=690 └──────────────────────────────────────────────┘
```

- **`TitleFrame`** (1200 × 300, 투명 배경)
  - 로비 판처럼 네 모서리에 먹색 꺾쇠 + 청록 짧은 선을 넣는다.
  - 왼쪽 위에 작은 번호 칸("01" / "TRANSIT")을 둔다.
  - 글자 영역은 비운다.
  - 종이 위에 놓이므로 **선이 먹색 기준**이다. 지금 버전의 흰 선은 쓰지 않는다.
- **`Emblem`** (160 × 160, 투명)
  - 먹색 선화 + 청록 포인트로 그린다.
  - 로딩 중 계속 돌아가므로 **회전 대칭**에 가까운 모양으로 한다 (나침반·조준선·톱니 원).
  - 로비의 나침반 표식과 같은 가족이면 좋다.
- 큰 글자는 **먹색**이 된다 (종이 면이므로).
- 이음새 선이 큰 글자와 부제 사이를 지나간다. 부딪히지 않게 배치한다.
- **금지 구역:**
  - 큰 글자 영역(x 560~1360, y 460~560)에는 질감 외에 아무것도 넣지 않는다.
  - 이음새 y=540 ±12px에는 장식을 넣지 않는다.

## 6. 변형 3종 — 같은 조각, 글자와 작은 포인트만 다르게

| 변형 | 언제 | 영문 / 한글 / 부제 | 포인트 |
|---|---|---|---|
| **출정** | 로비 → 전투 | OPERATION // DEPLOY · 출정 · 작전 지역으로 이동합니다 | 청록 |
| **귀환** | 전투 → 로비 | RETURN // BASE · 귀환 · 기지로 복귀합니다 | 청록 |
| **훈련** | 로비 → 훈련 전투 | TRAINING // SIMULATION · 훈련 · 모의 전투를 시작합니다 | 청록 + "SIM" 작은 먹색 칸 (TitleFrame 번호 칸 자리) |

변형 때문에 조각을 따로 그릴 필요는 없다. 필요하면 `Tag_Sim`(작은 칸) 하나만 추가한다.

## 7. 결과물

목업 4장 (1920×1080):

1. `SceneTransition_v2_Closed.png`: 완전히 닫힌 상태, 출정, 진행 막대 0%
2. `SceneTransition_v2_Loading.png`: 로딩 중, 귀환, 진행 막대 약 60% + 선두 표식
3. `SceneTransition_v2_Moving.png`: **닫히는 중간 프레임**, 훈련. 위 막은 오른쪽에서, 아래 막은 왼쪽에서 반쯤 들어온 상태라 앞장서는 끝이 잘 보여야 한다. 막 뒤에는 `Reference_LobbyMain.png`를 깐다.
4. `SceneTransition_v2_Opening.png`: 열리는 중간 프레임. 막 뒤에 전투 HUD 화면을 깐다.

그림 규칙:
- 캐릭터·적 일러스트는 막에 넣지 않는다. 기호, 선, 글자만 쓴다.
- 모든 조각은 이후 분절에서 **2배 해상도(PPU 200)로** 뽑을 예정이다. 목업도 가능하면 3840×2160으로 그린다. 최소한 선이 1px 아래로 뭉개지지 않게 굵기를 정한다.
- 분절 요청은 목업을 확정한 뒤 따로 보낸다.
