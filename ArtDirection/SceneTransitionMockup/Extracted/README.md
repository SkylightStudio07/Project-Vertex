# 씬 전환 막 v2 — 2배 분절

수정된 `Split_Handoff/SPLIT_REQUEST.md`와 확정 미리보기를 기준으로 새로 그린 게임 조각 14개다. 글자·로비·전투 화면·HUD·캐릭터·섬광은 포함하지 않는다.

## 제작 방식

막은 각각 **5280×1096 작업 캔버스에 통째로** 그렸다. #EEF0F2 바탕의 약한 얼룩·섬유도 이 크기에서 새로 합성한 다음 원래 픽셀 그대로 Lead / Body / Tail로 잘랐다. 목업을 잘라 확대하지 않았다. 큰 작업 캔버스는 메모리에서만 사용하며, 출력 PNG는 모두 가로·세로 4096 이하이다.

위 막의 절단 X는 0 / 1840 / 4080 / 5280, 아래 막은 0 / 1200 / 3440 / 5280이다(2배 픽셀). 두 Body는 2240×1096이며 종이 질감만 포함한다. **Body를 가로로 늘리지 않는다.** 절단면에 패딩·중복·재샘플링이 없다.

## 사선 방향 및 이동 조립

사용자가 확인한 **왼쪽을 향하는 `<`** 형태를 적용했다. 위 막은 `/` 사선 오른쪽에 종이가 있고, 아래 막은 `\` 사선 왼쪽에 종이가 있다. 아래 띠의 먹색·청록 선·흰 눈금 순서는 위 띠의 상하 반사이며, 막 몸통이나 장식 전체를 뒤집은 것이 아니다.

사선 기울기는 화면 높이 548에서 X 310px이다. 먹색 띠의 수평 폭 80px까지 더하면 사선 장식의 전체 X 범위는 **390px**이다. 요청서의 ‘약 320’ 범위보다 넓지만, 기울기 310과 띠 폭을 함께 유지하기 위한 값이며 닫힌 위치에서는 모두 화면 밖에 숨는다. 920px Lead 안에 충분히 들어간다.

`Assembly_Moving.jpg`는 위 막 부모를 (600,0), 아래 막 부모를 (-1650,532)에 놓았다. 겹침 16px의 가운데 y=540에서 두 띠가 같은 X로 만나며, 띠의 왼쪽 경계는 약 x604.5이다. 시트는 화면 rect [-40,0,2240,1080]을 축소해 보여 준다. 체크무늬는 투명 영역 확인용이며 PNG에는 없다. 막은 가로 이동만 한다.

## 레일과 제목

레일 중심은 게임 기준 **y=540**, Base의 top은 528이다. 홈은 Base 내부 y=9부터 높이 6(2배 PNG에서는 y=18부터 높이 12)이며 기본적으로 투명하다. 마름모 눈금은 레일 장식으로 홈을 가로지른다.

그리기 순서는 Base → Fill → Head이다. Fill은 top 537, 높이 6으로 놓고 왼쪽 피벗에서 가로 스케일한다. Head 중심은 `(1920 × 진행률, 540)`이다. 0%에는 Fill과 Head를 숨긴다. 오른쪽 흰 광택은 원본 화면 폭 40px이며 전체 가로 스케일 시 함께 줄어든다(60%에서는 24px). 흰 광택은 RGB 변화이며 반투명 알파가 아니다.

목업 레일 중심 약 y=578에서 게임 y=540으로 옮기는 차이 **-38px**를 TitleFrame·Emblem·큰 제목 묶음에 적용했다. `text_slots.closed_mockup_rect`에 원래 글자 자리를, `game_rect`에 이동 후 자리를 기록했다. 제목 하단과 레일 중심 간격은 36px, 부제 상단과 레일 중심 간격은 34px이다. 글자 영역의 크기·정렬·대략 글자 크기·색도 포함한다.

Emblem은 PNG 중심 (180,180)에 회전 피벗을 둔다. 픽셀 격자 중심은 (179.5,179.5)이며 90도 회전 시 픽셀이 정확히 일치하도록 그렸다. Tag_Sim은 훈련 상태에서만 표시한다.

## 글자 및 로딩 칩

글자는 실제 PNG에 전혀 없다. `layout.json`의 `text_slots`에 영문 라벨, 큰 제목, 부제, VERTEX // TRANSIT, 01/02, EXPEDITION/SHELTER 3줄, NOW LOADING, SIM 자리 정보를 기록했다. 막에 붙는 작은 글자는 해당 `curtain_parent`와 `local_screen_rect`를 사용하면 막과 함께 움직인다.

LoadingChip에는 먹색 판과 왼쪽 청록 사선만 있다. 흰 점은 Chip_Dot을 별도로 세 번 복제해 중심을 **(1686,970), (1708,970), (1730,970)**에 놓는다. 각 점을 독립적으로 깜빡일 수 있다.

## Unity 적용 기준

Sprite / Single, PPU **200**, Full Rect, Mip Maps Off, Compression None, Max Size 4096, Wrap Clamp, Bilinear를 권장한다. Canvas Reference Pixels Per Unit은 100 기준이고 RectTransform 크기는 JSON의 1배 화면 크기를 쓴다. 조각별 스케일을 다르게 적용하지 말고 막 부모를 함께 이동한다. 좌상단 피벗에서는 anchoredPosition을 `(x,-y)`로 변환한다. Emblem 및 Head는 중심 피벗이다.

아트 인계 파일만 만들었으며 Unity 임포터·씬·프리팹은 수정하지 않았다. 런타임 렌더링의 경계선 여부는 적용 후 별도 확인해야 한다.
