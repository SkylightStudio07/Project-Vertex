# 씬 전환 분절 키트

기준: SceneTransition_ComponentStoryboard_v2.png. 이미지 모델로 만든 승인 시트의 실제 픽셀을 크롭·리사이즈하여 출력했다. 원본 시트 1448×1086, 조립 캔버스 1920×1080.

## 조각

- Curtain_Upper / Curtain_Lower: 2320×548. 면 내부 알파 255, 선두 사선 바깥만 알파 0. 위 막 왼쪽/아래 막 오른쪽 70px 사선 컷. 아래 막은 원본 조각을 상하 반전해 이음새 눈금을 위쪽으로 옮겼다.
- Seam_Base: 2320×24, Seam_Fill: 2320×6, Seam_Head: 48×24.
- TitleFrame: 1200×300. 네 모서리 장식만 추출하고 가운데와 원본 등록 십자는 투명 처리했다.
- Emblem: 160×160. 먹색 배경을 밝기 기반 알파로 제거했다.
- LoadingChip: 280×44. 불투명 먹색 면, 외부 사선 컷 투명. 점 3개는 이미지에 포함되어 있어 개별 점 애니메이션은 별도 구현이 필요하다.

## 배치와 예시

layout.json: PNG 크기, 시트 크롭 좌표, 실제 화면 배치, 귀환/출정 문구, 열림 방향.
상단 막 (-200,0), 하단 막 (-200,532), 이음새 (-200,528), 채움 (-200,537), 제목 틀 (360,390), 엠블럼 (480,370), 로딩 칩 (1600,1000).

- Assembly_*_Textless.png: 실제 출력 조각을 조립한 글자 없는 1920×1080 예시.
- Example_Closed / Loading / Opening / Return.png: 같은 조립에 별도 텍스트를 올린 4개 예시. 미리보기 텍스트는 시스템 폰트 렌더링이며 실제 게임에서는 TMP Pretendard를 사용한다.
- Reference_*: 승인 시트에 있던 예시의 원본 크롭. 실제 조각 조립과 구분한다.

이미지 시트의 표기 규격은 그림의 실제 비율과 다소 달라 일부 조각은 목표 크기로 비균등 확대됐다. 선 굵기·눈금 간격은 원본 그림을 확대한 결과이며 브리프의 1px/40px 규칙과 완전히 일치하지 않는다. 제목·진행 선은 실제 조립 예시에서 떨어뜨렸다. 열린 영역은 연회색 빈 화면 참고용이다.

막의 앞장서는 컷 형태 및 알파는 스크립트가 명시적으로 적용했다. 내부 색상은 원본 래스터 질감을 보존한다. Unity 임포트·씬 전환 코드·배선은 포함하지 않았다.
