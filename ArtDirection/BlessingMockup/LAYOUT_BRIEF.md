# 축복 노드 화면 · 레이아웃 요청서

축복 노드(마키나) 화면의 UI 겉모습을 **로비 메인과 같은 문법**으로 바꾼다. **배치·구성은 지금과 같게 둔다.**
- 현재 화면: `Reference_Current.png` (1563×869 캡처, 아래 좌표는 1920×1080 기준으로 환산)
- 스타일 기준: `Reference_LobbyStyle.png` (로비 메인), `Reference_Shop_v2.png` (같은 문법으로 만든 상점)
- **그대로 두는 것:** 배경(보름달·백피안화 들판), 꽃잎 연출, 마키나 스탠딩(리깅), 선택지 아이콘 4종(정화·연마·보급·교감, `Assets/Art/Blessing/UI`)
- 상단 HUD(아이템 칸·MAP·DECK)는 이 화면 위에도 떠 있으니 그 자리를 비워 둔다

## 0. 지금 화면의 문제

- 대사창·선택지·이름판이 **같은 모양의 흰 직사각 판**이다. 모서리 컷만 조금 있을 뿐 위계가 없어서 웹게임 메뉴처럼 보인다.
- 선택지 4개가 **똑같은 줄**로 늘어서 있다. 무엇을 고르는 화면인지, 어느 게 주인공인지 드러나지 않는다.
- 로비의 큰 한글 제목, 작은 번호·영문 라벨, 워터마크, 반전 먹색 판 같은 문법이 하나도 없다.

## 1. 축복 화면만의 결

축복은 전투·상점과 달리 **신비 쪽 화면**이다. 그래서 로비 문법을 가져오되, 상점과 구별되는 점이 있다.
- **✦ 별·꽃잎 모티프를 여기서는 쓴다** (전투·상점에서는 금지했던 축복 모티프). 다만 선화로 옅게, 장식 포인트로만.
- 종이 톤은 상점보다 **한 단계 차갑게**: 오프화이트 #EEF0F2 (밤 배경의 청색과 어울리게).
- 포인트 색은 청록 #0DB8F2를 그대로 쓰고, 마키나의 붉은색(#B3242B)은 **이름판의 가는 선 하나**에만 허용한다.
- 반전 먹색 판은 **마키나 이름판** 하나 (상점의 상점 주인 이름판과 같은 역할).

## 2. 배치 (1920×1080, 왼쪽 위 원점)

```
                                                       [아이템 칸 ×3]          [MAP][DECK]
                                                       (y 0~106 HUD 자리)
                              (마키나 스탠딩 — 가운데)

 ┌ 이름판 (먹색) ┐       ┌ 대사 판 (565,596) 1158×130 ──────────────────────────────┐
 │ ENTITY        │       │ VERTEX / ENCOUNTER LOG                  ✦ (옅은 워터마크)  │
 │ 마키나 ───(붉은 선) │  │ [초상] "재회를 축복할지, ..."                             │
 │ 재생과 죽음의  │       └──────────────────────────────────────────────────────────┘
 │ 경계에서      │       ┌ 01 ┐ 정화   PURIFY   덱에서 불필요한 카드 1장을 …        → │
 └───────────────┘       ├ 02 ┤ 연마   REFINE   기본 카드 2장을 선택하여 강화 …     → │
  (44,887) 339×138       ├ 03 ┤ 보급   SUPPLY   소모품 아이템 2개를 …               → │
                         └ 04 ┘ 교감   COMMUNE  마키나와 대화를 나누어 친밀도 …     → │
                          선택지 판 4장: (565,742)부터 1158×70, 간격 8
```

| 영역 | 위치 · 크기 | 형태 |
|---|---|---|
| **대사 판** | (565, 596) 1158 × 130 | 차가운 종이 판, 왼쪽 위 사선 컷. 위쪽 작은 라벨 "VERTEX / ENCOUNTER LOG", 왼쪽 초상 칸(48×64), 대사 2줄. 오른쪽 끝에 옅은 ✦ 선화 워터마크 |
| **선택지 판 ×4** | (565, 742 / 820 / 898 / 976) 각 1158 × 70 | 로비 하단 시설 버튼과 같은 문법: 왼쪽 **작은 번호 01~04 + 밑줄**, 아이콘 칸(기존 아이콘), **굵은 한글 제목 + 작은 영문 라벨**(PURIFY / REFINE / SUPPLY / COMMUNE), 세로 구분선, 설명 한 줄, 오른쪽 끝 **→** |
| 선택지 호버 | 같은 크기 | 청록 테두리 1px + 판이 왼쪽으로 8px 밀려나는 자리(게임에서 이동). 아이콘 칸 배경이 먹색으로 반전 |
| 선택지 비활성 | 같은 크기 | 조건 미달(예: 강화할 카드 없음). 판 회색 #D9DCDF, 글자 흐리게 |
| **마키나 이름판** | (44, 887) 339 × 138 | **먹색 반전 판.** "ENTITY / MACHINA" 작은 라벨, 이름 "마키나" 큰 글자, 이름 아래 **붉은 가는 선 1줄**(60px), 소개 한 줄. 모서리 "+" 등록 표시 |
| 장식 | 화면 가장자리 | 로비처럼 가는 모서리 선·"+"·마이크로 카피 두세 줄 ("BLESSING / BETWEEN REBIRTH AND DEATH" 류). 마키나 얼굴·손 주변은 피한다 |

- 선택지 4장은 **완전히 같은 판이 아니게**: 판마다 사선 컷 모서리 위치를 번갈아(01 오른쪽 위, 02 오른쪽 아래, …) 바꿔 로비 버튼판처럼 리듬을 준다.
- 판 바깥 그림자는 불투명 회색 띠(#9AA3AD, 오른쪽 아래 4px). 밤 배경이라 흰 판이 너무 튀지 않게 상점보다 한 톤 낮춘다.
