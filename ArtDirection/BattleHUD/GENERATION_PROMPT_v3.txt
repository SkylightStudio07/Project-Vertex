# 전투 화면 HUD · 조각 요청서 (v3 — 위계 · 여백 · 순간의 사선)

전투 화면에서 캐릭터·카드 위에 얹는 UI(HUD)를 다시 그린다.
- 배경, 캐릭터·적 스탠딩, 카드, 적 인텐트 아이콘, 가장자리 장식 글자는 **그대로 둔다**.
- **v2(먹색) 색 체계는 유지한다.** v3에서는 요소별 **무게를 다르게** 하고 서로 **떼어 놓는다**.
- 조립 기준 화면은 `Reference_Current.png`다.

## 0. v1 · v2에서 배운 것

| 버전 | 결과 | 문제 |
|---|---|---|
| v1 (`BattleHUD_Mockup_v1.png`) | 흰 종이 패널 | 흰 배경에 녹고, 청록을 면으로 칠해 청록이 주인공이 됨 |
| v2 (`BattleHUD_Mockup_v2_PlayerTurn.png`, `_EnemyTurn.png`) | 먹색 판 | 색은 맞음. 대신 **모든 요소가 같은 두께의 검은 상자**라 위계가 없고, 검은 면이 화면 네 귀퉁이를 둘러싸 장면이 액자에 갇힘. 빗금(///)이 모든 판에 반복돼 소음이 됨. 숫자가 작음 |

v3 원칙 — **명일방주식 정적 HUD + 페르소나식 순간 연출**
1. **두꺼운 판은 하나만:** END TURN(주 동작). 상단 바는 얇은 띠로 둔다. 나머지는 틀 없이 **글자·선·기호**로만 선다.
2. **숫자가 주인공:** 에너지·탄약은 큰 숫자, 라벨은 아주 작게.
3. **여백:** 요소끼리 붙이지 않는다. 묶음 사이 최소 24px.
4. **사선은 움직이는 순간에만:** 기울어진 판과 베어 들어오는 도형(페르소나식)은 **연출용 조각**으로 따로 받는다. 정적 HUD에는 END TURN 뒤 기울어진 판 하나와 에너지 숫자 뒤 사선 띠 하나만 허용한다.

  - `Example_TurnBanner`: 턴 시작 순간 (`Slash_Wide` + `Slash_Accent` + 배너 글자), 연출 조각이 어떻게 겹치는지 보여 주는 한 장면
- 좌표가 든 `layout.json`.

## 6. 하지 말 것

- 모든 요소를 같은 두께의 상자로 만드는 것 (v2)
- 빗금(///)을 판마다 반복하는 것
- 흰 종이 패널, 굵은 검은 외곽선 (v1)
- 청록 면 채움·글로우·그라데이션
- 정적 HUD 전체를 기울이는 것 (사선은 END TURN 뒤판, 에너지 띠, 연출 조각에만)
- 반투명 판, 흐린 그림자
- 별·꽃잎 등 축복 모티프
- 캐릭터·적 영역(x 360~1560, y 150~620)과 손패 영역(x 330~1560, y 820~1080)을 가리는 것
- 가장자리 장식("THE WHITE VERTEX" 등)을 새로 그리는 것
