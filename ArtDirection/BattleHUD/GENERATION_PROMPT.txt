# 전투 화면 HUD · 조각 요청서

전투 화면에서 캐릭터·카드 위에 얹는 UI(HUD)를 **로비 키트와 같은 계열**로 다시 그린다.
- 배경, 캐릭터·적 스탠딩, 카드, 적 인텐트 아이콘은 **그대로 둔다**. 이번 범위가 아니다.
- 배치는 지금 위치를 기준으로 하고, 겉모습만 바꾼다.

참고 이미지 (이 폴더):
- `Reference_Current.png`: 현재 전투 화면. 바꿀 대상이다.
- `Reference_TopBar_Original.png`: 처음 기획한 상단 바. 여기에 아이템 칸을 붙였던 것이 지금의 검은 패널이다.
- 스타일 기준: `../LobbyKit_v2/Extracted/Lobby_Full_Reference.png`, `../QuestBoardMockup`, `../SceneTransition`.

## 0. 공통

- 기준 화면은 **1920×1080**이다. 좌표는 모두 왼쪽 위 원점, 픽셀 단위다.
- 스타일 방향:
  - **흰 종이 패널**(로비 키트 질감) + **흑연 선** + **청록 #0DB8F2**.
  - 청록은 테두리, 수치, 활성 상태에만 쓴다.
  - 빨강·노랑은 쓰지 않는다. 체력이 줄어드는 표시는 게임에서 따로 처리한다.
- 전투 배경이 밝은 흰 대리석이라, 종이 패널이 배경에 묻히지 않도록 해야 한다.
  - 패널 가장자리에 흑연 테두리 1~2px과 아주 옅은 그림자(불투명 회색 띠)를 둔다.
  - **반투명 검정은 금지다.** 프로젝트가 Linear 색공간이라 알파를 낮춘 검정이 회색으로 뜬다.
- **글자는 전부 게임에서 TMP(Pretendard)로 얹는다.** END TURN, MAP, DECK 같은 버튼 글자도 그림에 넣지 않는다. 목업 글자는 참고용이니 지울 수 있게 단색 면 위에 둔다.
- 결과물:
  - 각 조각의 PNG(투명 배경). 버튼은 Normal / Hover / Pressed / Disabled.
  - 조립 예시 1장: `Reference_Current.png` 위에 새 HUD를 얹은 것.
  - 좌표가 든 `layout.json`.

## 하지 말 것

- 가장자리 장식("THE WHITE VERTEX", "OBSERVE. ANALYZE. PROCEED.", 왼쪽 세로 장식)은 이미 로비와 맞으니 **새로 그리지 않는다**. 겹치지만 않게 한다.
- 화면 가운데(x 360~1560, y 150~620)는 캐릭터와 적이 서는 자리다. 어떤 HUD도 이 영역에 들어오지 않게 한다.
- 손패 영역(가운데 아래 x 330~1560, y 820~1080)을 가리지 않는다. END TURN과 자원 칸은 오른쪽으로, HP는 왼쪽으로 붙인다.
- 별·꽃잎 같은 축복 모티프를 쓰지 않는다. 기호는 작전 단말기 계열(격자, 눈금, 마름모, 사선)만 쓴다.
