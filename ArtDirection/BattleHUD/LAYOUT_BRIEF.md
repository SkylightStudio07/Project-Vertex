# 전투 화면 HUD · 조각 요청서 (v3 — 명일방주 구조 · 아스트라에 오라티오의 절제)

전투 화면에서 캐릭터·카드 위에 얹는 UI(HUD)를 다시 그린다.
- 배경, 캐릭터·적 스탠딩, 카드, 적 인텐트 아이콘, 가장자리 장식 글자는 **그대로 둔다**.
- **v2(먹색) 색 체계는 유지한다.** v3에서는 요소별 **무게를 다르게** 하고 서로 **떼어 놓는다**.
- 조립 기준 화면은 `Reference_Current.png`다.

## ★ v3 정본 — 분절 기준

**`BattleHUD_Mockup_v3_Canonical.png`를 정본으로 분절한다.** 다른 v3 목업(`_Oratio_*`, `_PlayerTurn`, `_EnemyTurn`, `_TurnBanner`)은 아래 표에 적힌 부분만 참고한다.

| 요소 | 기준 | 분절 전 수정 |
|---|---|---|
| 상단 작전 바 | 정본 (FLOOR / TURN / BATTLE FIELD + 막 이름 / 아이템 3칸) | 없음 |
| MAP 버튼 | **선 지도 기호** (`_Oratio_TurnBanner`의 MAP 버튼) | 정본의 **✦ 별 기호는 쓰지 않는다** (축복 모티프) |
| DECK 버튼 | 정본 | 없음 |
| 오른쪽 자원 모듈 | 정본 (먹색 판 하나에 WEAPON 줄 · ENERGY 큰 숫자 · AMMO) | 작은 "3" 위의 **청록 짧은 선을 뺀다** |
| END TURN | 정본 | 없음 |
| 플레이어 HP · 방어도 · 상태 칸 | 정본 | 없음 |
| 적 HP · 방어도 · 이름 띠 | 정본 | "29 / 40" 글자는 게임에서 먹색으로 넣으니, 채움·트랙만 분리 |
| 적 턴 상태 | `_Oratio_EnemyTurn`의 표현 (END TURN 흐림, 에너지 0) | **정본 구조에 맞춰** 다시 그린다 (자원 모듈은 정본의 먹색 판 형태 유지) |
| 턴 배너 | `_Oratio_TurnBanner`의 "PLAYER / TURN" (헤어라인 사선 + 줄표 + 청록 마름모) | 없음 |

분절 규칙:
- **글자는 전부 뺀다.** 층·턴 숫자, 막 이름, 버튼 글자, 무기 이름, 수치, "WEAPON / ENERGY / AMMO" 라벨, "PLAYER TURN"까지 전부 게임에서 TMP로 넣는다.
- **기호(번개·탄환·지도·카드 묶음·방어도 방패)는 판과 따로** 32×32(방패는 배지 크기) 투명 PNG로.
- 자원 모듈은 **판 한 장 + 구분선 + 헤어라인 "/"**로 나눠서, 게임에서 줄을 늘리거나 줄일 수 있게 한다.
- 버튼 상태: MAP·DECK는 Normal / Hover / Pressed, END TURN은 Normal / Hover / Pressed / Disabled.
- 결과물 이름·크기는 아래 3절 조각 목록을 따르되, **자원 모듈은 3절 대신 정본 형태**(판 하나)로 한다: `Res_Panel`(판), `Res_Divider`(가로 구분선), `Res_Slash`(에너지 사선).
- 좌표가 든 `layout.json`, 조립 예시(평상시·적 턴) 2장.

## 0. 방향

| 버전 | 결과 | 문제 |
|---|---|---|
| v1 (`BattleHUD_Mockup_v1.png`) | 흰 종이 패널 | 흰 배경에 녹고, 청록을 면으로 칠해 청록이 주인공이 됨 |
| v2 (`BattleHUD_Mockup_v2_PlayerTurn.png`, `_EnemyTurn.png`) | 먹색 판 | 색은 맞음. 대신 **모든 요소가 같은 두께의 검은 상자**라 위계가 없고, 검은 면이 화면 네 귀퉁이를 둘러싸 장면이 액자에 갇힘. 빗금(///)이 모든 판에 반복돼 소음이 됨. 숫자가 작음 |

**v3 = 명일방주의 구조 + 아스트라에 오라티오(Astrae Oratio) 키비주얼의 절제**
- **명일방주에서:**
  - 정보 위계: 두꺼운 판은 주 동작 하나뿐이고, 나머지는 글자와 선으로 선다.
  - 큰 숫자와 작은 영문 라벨.
  - 화면 가장자리에 붙는 배치.
- **아스오라에서:**
  - 넓은 여백과 거의 흑백인 절제. 강조색은 하나만.
  - **머리카락 굵기의 긴 사선 "/"**: 로고를 가르는 그 선이다. 구분선이자 이 HUD의 서명 모티프로 쓴다.
  - 가는 줄표(——)와 작은 라벨.
- **쓰지 않는 것:** 두꺼운 사선 판, 튀어나오는 도형 같은 과한 연출. 움직임도 선이 그어지고 글자가 나타나는 정도로 조용하게 한다.

원칙
1. **두꺼운 판은 하나만:** END TURN(주 동작). 상단 바는 얇은 띠. 나머지는 틀 없이 **글자·선·기호**로만 선다.
2. **숫자가 주인공:** 에너지·탄약은 큰 숫자, 라벨은 아주 작게.
3. **여백:** 요소끼리 붙이지 않는다. 묶음 사이 최소 24px.
4. **사선은 선으로만:** 기울어진 면(판)은 쓰지 않는다. 사선은 1~2px 헤어라인 "/" 한 가지다.

## 5. 결과물

- 조각 PNG (투명 배경, 판은 알파 255). 버튼은 상태별 파일.
- 조립 예시 3장 (`Reference_Current.png` 위에):
  - `Example_PlayerTurn`: 평상시
  - `Example_EnemyTurn`: END TURN 비활성, 에너지 0
  - `Example_TurnBanner`: 턴 시작 순간. 가운데에 `Line_Sweep` + `Slash_Long` + 배너 글자 "PLAYER TURN / 아군 턴"(가는 영문 대문자 + 작은 한글, 아스오라 로고처럼 사선이 두 줄을 가름)
- 좌표가 든 `layout.json`.

## 6. 하지 말 것

- 모든 요소를 같은 두께의 상자로 만드는 것 (v2)
- 빗금(///) 장식 반복
- 흰 종이 패널, 굵은 검은 외곽선 (v1)
- 청록 면 채움·글로우·그라데이션
- 기울어진 판·튀는 도형 같은 과한 연출 (사선은 1~2px 헤어라인만)
- 반짝이(✦)·별·꽃잎: 축복·성소 쪽 모티프라 전투 HUD에는 쓰지 않는다 (아스오라 키비주얼의 반짝임도 제외)
- 반투명 판, 흐린 그림자
- 캐릭터·적 영역(x 360~1560, y 150~620)과 손패 영역(x 330~1560, y 820~1080)을 가리는 것
- 가장자리 장식("THE WHITE VERTEX" 등)을 새로 그리는 것
