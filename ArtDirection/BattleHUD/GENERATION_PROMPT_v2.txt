# 전투 화면 HUD · 조각 요청서 (v2 — 먹색 HUD)

전투 화면에서 캐릭터·카드 위에 얹는 UI(HUD)를 다시 그린다.
- 배경, 캐릭터·적 스탠딩, 카드, 적 인텐트 아이콘, 가장자리 장식 글자는 **그대로 둔다**.
- **v1(`BattleHUD_Mockup_v1.png`)의 배치와 구성은 유지하고, 색 체계를 처음부터 다시 잡는다.**

## 0. v1이 안 된 이유 (반복하지 말 것)

`BattleHUD_Mockup_v1.png`:
- **흰 패널이 흰 배경에 녹았다.** 전투 배경이 하늘색 도는 흰 대리석이라, 흰 종이 패널이 배경과 명도가 같다. 굵은 검은 외곽선으로 억지로 떼어 놓아 스티커처럼 보인다.
- **청록을 면으로 칠했다.** 기호 칸, HP 채움, END TURN 테두리 글로우, 선택 칸 글로우가 전부 청록이다. 청록이 포인트가 아니라 주인공이 됐다.
- **하늘색 배경 위의 진한 청록**은 같은 색 계열끼리 부딪쳐 탁해 보인다.

→ v2는 **밝은 배경 위에 어두운 판**을 얹는다. 원래 상단 바 기획(`Reference_TopBar_Original.png`)과 씬 전환 막(`../SceneTransition`)이 이미 이 방향이고, 둘 다 통과했다.

## 1. 색 체계 (이 표를 최우선으로 따른다)

| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| 판 바탕 | **먹색 #16181B**, 불투명 | 모든 HUD 판 |
| 판 안쪽 선 | #3A3E44 (1px, 가장자리에서 3px 안쪽) | 판 윤곽. **바깥 굵은 외곽선 금지** |
| 판 질감 | #1B1E22 정도의 아주 옅은 격자·사선 | 씬 전환 막과 같은 질감을 더 약하게 |
| 주 글자 | 흰색 #F2F3F4 | 이름, 버튼 글자, 수치 |
| 보조 글자 | 회색 #8A9099 | FLOOR/TURN 라벨, "/ 16" 같은 보조 수치, ITEMS 라벨 |
| 기호(선화) | 흰색 선 | 무기·번개·탄환·지도·카드 기호 |
| **청록 #0DB8F2** | **선과 점으로만** | 아래 목록뿐 |
| 비활성 | 판 #202328 + 글자 #5A6069 | END TURN 비활성, 에너지·탄약 0 |

**청록을 쓰는 곳 (이것 외에는 쓰지 않는다)**
- "BATTLE FIELD" 작은 영문 라벨
- 현재 수치의 강조 숫자 하나 (에너지 "3", 층 "04" 등 주 숫자만)
- HP 바 채움의 **오른쪽 끝선 3px**
- 호버·선택 상태의 **테두리 1px** (글로우 없음)
- 판 모서리의 작은 눈금·마름모 장식 몇 개

**청록 면적은 HUD 전체 픽셀의 5% 이하**로 한다. 청록으로 채운 사각형, 청록 글로우, 청록 그라데이션은 전부 금지다.

**기타 규칙**
- 반투명 금지. 모든 판은 알파 255. (프로젝트가 Linear 색공간이라 반투명 어둠은 회색으로 뜬다.)
- 판 밑 그림자가 필요하면 불투명 #0B0C0E 띠를 오른쪽 아래로 3px 어긋나게 둔다. 흐린 그림자 금지.
- 빨강·노랑 금지. 적 인텐트 아이콘(붉은 공격 표시)은 기존 그림이라 예외.
- 글자는 전부 게임에서 TMP(Pretendard)로 얹는다. 버튼 글자(END TURN, MAP, DECK)도 그림에 넣지 않는다.
