# 대화 선택지 v1 · 분절

- SVG 10종과 대응 2배 PNG 10종. 모든 그림은 0°이고 글자·번호·태그·꼬리·배경을 포함하지 않는다.
- 원본 크기: 판/그림자/잔상736×96, 선택띠736×6. PNG는 각각2배. 실제 행 폭은 layout의724/724/736px.
- 요청서 명시대로 왼쪽 아래/오른쪽 위 사선 컷28px. 생성 목업의 일부 모서리 편차는 이 규칙으로 통일했다.
- layout.json: 1920×1080 좌상단 좌표, 회전 전 rect와 회전값 별도, 자식은 판 기준 로컬좌표. TMP 크기/색/굵기/정렬/자간 포함.
- 화면좌표 회전은 시계방향 양수. -4/+2/-2도를 Unity Z에 넣을 때는 +4/-2/+2도로 변환한다.

## 9-slice와 배율

판/그림자/잔상은 논리 L/B/R/T=34/34/34/34, 2배PNG Sprite border=68/68/68/68.
선택띠는 논리8/0/8/0, PNG16/0/16/0. 높이는6px 고정. 나머지는 Simple.
PNG PPU100, Canvas referencePPU100이면 Image.pixelsPerUnitMultiplier=2를 사용한다. 또는 PNG PPU200과 multiplier1 조합. 두 방식을 겹쳐 적용하지 않는다.
Contact_Sheet의 확장판은 실제9-slice로 그렸다. 기본폭→960px 확대 시 네 모서리 픽셀 일치 검사 통과.

## 배치와 글자

1개/2개는3개 배치의 위쪽 행부터 사용. RESPONSE 개수 변경, 남은 행 숨김. 가운데 재정렬하지 않는다.
번호16px, 문구28px Bold, 태그13px. 모든 글자는 TMP로 분리. 22자까지 허용.
문구 길이에 따라 최대폭960px까지 확장하며 오른쪽 끝을 고정하고 왼쪽으로 늘린다. 태그가 없으면 그 공간을 문구가 사용한다.
22자 초과는21문자+…로 축약. 측정상 아직 넘치면 TMP Ellipsis, 한 줄 고정, 자동 글자 축소 없음. 원문은 데이터에 보존.
번호 밑줄/칸막이/화살표/머리글 선은 흰 원본. 상태별 의도 tint는 layout에 명시.

## 상태와 그림자

Normal: 종이/먹색, 그림자10px. Hover: 먹색/흰색/청록2px선, 오른쪽18px, 그림자14px.
Selected: 청록3px선,1.2배, 오른쪽50/위35px, 그림자18px 및 아래6px띠. 확대되므로 화면상의 띠는7.2px가 된다.
나머지 행: Normal 유지, 왼쪽95/145px와 아래12/24px 이동, alpha .30/.25.
모든 상태 이동은 Normal 기준이다. Hover18px에 Selected50px를 더하지 않는다.
Choice_Shadow는 알파1 먹색 원본이며 runtime tint alpha .35. 별도 Unity Shadow를 중복하지 않는다.
그림자 오프셋은 화면 우하단 기준. 같은 회전부모 아래 넣으면 inverse rotation/scale로 변환한다. layout에 공식 포함.
Ghost는 속이 빈 윤곽1px, 등장 중01행에만 두 겹(.22/.12). 기본 정착 이후는 숨김.
선택띠는 가로를 clip/reveal하여 등장. 끝 모서리를 보존하도록9-slice 사용.
연출 시간은 MOTION_SPEC을 layout.motion에 옮겼다. 구현은 별도 작업이다.
