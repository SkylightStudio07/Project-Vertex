# 대화 선택지 v1 · 조각 다시 요청 (이미지 모델 생성본)

지난 조각(`Extracted_Draft/`)은 SVG로 다시 그린 단색 도형이라 목업의 종이 질감 · 인쇄 느낌이 빠졌다. 이번에는 **이미지 모델로 그린 그림**으로 같은 조각을 다시 만든다.
**모양 · 크기 · 파일 이름은 지난 조각 그대로**, 표면만 그림으로 바꾼다. 게임은 이미 지난 조각으로 붙어 있으니, 파일만 바꿔 끼우면 그대로 들어가야 한다.

## 꼭 지킬 것 (안 지키면 게임에서 깨진다)

1. **외곽선(알파)은 지난 PNG와 같게.** 사선 컷 위치 · 판 높이가 1px이라도 달라지면 그림자 · 띠 · 글자 자리가 어긋난다. 생성 후 지난 PNG 알파로 잘라 내는 방식 권장.
2. **가로로 늘어나도 되게.** 판은 문구 길이에 따라 736 → 960px까지 늘어난다. 9-slice 경계(사방 68px, 2배 기준) **안쪽 가운데 띠와 위 · 아래 변은 가로로 이어 붙여도 이음새가 안 보이게** (좌우 반복 가능한 질감). 큰 얼룩 · 긁힘 · 글자 같은 눈에 띄는 무늬는 네 모서리 칸(68×68) 안에만.
3. **글자 · 번호 · 기울기 · 그림자를 그림에 넣지 않는다.** (지난번과 같음)
4. 질감은 **약하게.** 판 위에 28pt 먹색 / 흰 글자가 얹혀서 바로 읽혀야 한다. 대비를 깎는 진한 얼룩 금지.
