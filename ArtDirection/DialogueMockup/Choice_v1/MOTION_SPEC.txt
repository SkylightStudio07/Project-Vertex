대화 선택지 v1 / 구현 참고용 연출 설명

등장
- 줄별 시작 시각 0.00 / 0.06 / 0.12초.
- 각 줄은 왼쪽 화면 밖에서 최종 위치보다 살짝 위의 사선 경로로 진입.
- 약0.18초에 최종 위치를 오른쪽12px 지나치고, 약0.08초에 돌아오며 정착.
- 각 줄 최종 각도 예시 -4 / +2 / -2도. 텍스트·번호·태그·화살표도 같은 루트와 함께 기울임.
- 그림자는 우하단, 흐림0. 한 줄의 가는 윤곽 잔상은 등장 순간에만 2개, 정착 후 제거.

Hover
- 현재 줄만 먹색 바탕/흰 글자로 반전, 청록 1.5~2px 테두리.
- 오른쪽18px, 그림자10px→14px. 약0.09초에 전환.
- Hover 해제 시 원위치. 글로우·모션블러 없음.

선택
- 고른 줄을 약0.10초 동안1.2배, 오른쪽50px/위35px 이동.
- 고른 줄 아래 청록6px 띠를 짧게 가로로 드러냄. 화면 전체 섬광/블룸은 사용하지 않음.
- 나머지 줄은 왼쪽으로95~145px 이동하며 opacity .25~.30까지 내려감.
- 클릭 후0.25초부터 전체 그룹 퇴장. 선택 줄도0.10초 내 사라지고 다음 대사로 전환.
- 확정 뒤 중복 클릭을 받지 않음. 선택 문구/태그는 TMP 데이터로 유지.

위 수치는 요청서의 동작을 구체화한 제안값이며 구현하지 않았다.
생성 목업의 각도/확대량은 디자인 예시다. 코드의 정확한 수치 검증본은 아니다.
