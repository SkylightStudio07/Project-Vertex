# 대화 선택지 v2 · 목업 요청 (NPC 대화 — 토냐 · 마키나 등)

v1(`../Choice_v1/`)은 카리나 합류 장면용으로 끝났고 게임에 들어가 있다. v2는 **일반 NPC 대화의 선택지**다: 상점 토냐, 축복 마키나, 로비 시설 담당처럼 하단 대사창으로 말을 거는 모든 장면.

## 구도 (블루 아카이브식 대화 + 페르소나식 선택 순간)

우리 대화는 블루 아카이브처럼 **상대 NPC가 화면에 서 있고, 아래 대사창으로 말한다** (`Reference_Shop.png` — 토냐가 왼쪽에 서 있다). 선택지가 뜨는 순간만 아래처럼 바뀐다.

| 요소 | 선택지가 뜨는 순간 |
|---|---|
| **주인공** | 화면 오른쪽에 **고심하는 스탠딩**(`Reference_PlayerPose.png`, 턱을 괸 포즈)이 미끄러져 들어온다. 화면에서 가장 밝다 |
| **상대 NPC 스탠딩** | **자리 · 크기 그대로 서 있다** (옮기거나 확대하지 않음). 밝기도 그대로 — 누구와 이야기 중인지 보이게 |
| **그 밖 전부** (배경, 상점 판 · 전투 HUD 등) | **어둡게 눌러 깐다** (먹색 막 .6~.7). 선택 중이라는 느낌 |
| **하단 대사창** | 그대로 남는다 (마지막 NPC 대사). 살짝만 어둡게 |
| **선택지** | 주인공과 NPC 사이(화면 가운데)에 최대 3줄, 계단식 · 줄마다 다른 기울기(-4° ~ +3°) |

## 선택지 판

- **v1 판을 그대로 쓴다**: `../Choice_v1/Extracted_v2/` (흰 종이 판 · 먹색 반전 Hover · 청록 테두리 · 하드 섀도우). 새 판을 그리지 않는다.
- v1과 다른 점은 하나: 줄마다 **주인공 쪽(오른쪽)을 가리키는 짧은 꼬리** (`Reference_Persona5.png`의 말풍선 꼬리). "이 말을 주인공이 한다"는 표시. 꼬리는 사선 컷 판의 일부처럼 **각지게**, 판과 분리된 조각으로 붙일 수 있게.
- 줄끼리 살짝 겹치며 서로 다른 각도로 쌓이는 리듬 (페르소나 참고).

## 톤

- 명일방주 + 영원한 7일의 도시 + 아스오라. 흰 종이 · 먹색 · 청록 포인트(#0DB8F2) · 사선 컷 · 하드 섀도우(흐림 0) · 잔글씨.
- 페르소나에서는 **구도와 움직임만**. 빨강 · 검정 띠 · 흰 손글씨체 · 지그재그 말풍선 · 할프톤 · 만화 처리 금지.
- 주인공 그림은 원본 색 그대로. 뒤에 얇은 청록 사선 띠 1~2개와 잔글씨(`RESPONSE`, `VERTEX / EXPLORER`)만 깐다 (그림 위에 효과 금지).

## 상태 (목업 3장, 1920×1080)

1. **등장 직후** — 배경이 어두워지고, 주인공이 오른쪽에 들어와 있고, 토냐는 왼쪽에 그대로, 선택지 3개가 박힌 상태.
2. **마우스 올림** — 올린 줄 먹색 반전 + 주인공 쪽으로 살짝 당겨짐.
3. **선택 직후** — 고른 줄 1.2배 + 청록 띠, 나머지는 빠짐. 주인공 스탠딩은 오른쪽으로 빠지기 시작.

## 연출 (설명만 — 코드로 구현)

- 어둡게 깔림(0.15초) → 주인공 오른쪽 밖에서 0.2초 미끄러져 들어옴 → 선택지 0.06초 간격으로 "촤자작".
- 선택: 고른 줄 확대 · 청록 섬광 → 0.25초 뒤 선택지와 주인공이 함께 빠지고, 어둠이 걷히며 대사가 이어진다.
