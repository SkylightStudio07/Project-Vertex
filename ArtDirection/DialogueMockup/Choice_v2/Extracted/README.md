# Choice v2 tail delivery

PNG 4개, layout.json, Contact_Sheet.jpg. 화면 크기 56×32px / PNG 112×64px / 0도 / RGBA 투명 배경.

Normal·Hover·Selected는 각각 내장 이미지 모델로 생성했다. 모델의 투명 배경 옵션이 지원되지 않아 마젠타 배경에서 생성 후 제거했다. Normal 생성본에서 추출한 외곽 알파를 세 상태와 그림자에 공통으로 적용했다. 각 상태의 생성 질감을 추출해 v1 판 색과 대비에 맞추고, 외곽 마스크를 기준으로 테두리를 2/4/6 소스 픽셀(화면 1/2/3px)로 정규화했다. 새 벡터 도형이나 SVG 렌더링은 사용하지 않았다. 그림자는 같은 추출 알파에 먹색 단색을 적용했다.

판 오른쪽 위 기준 (-6,+30) 화면 픽셀에 꼬리 좌측 상단을 배치한다. 왼쪽 6px는 테두리가 없는 겹침 영역으로 판 위에 그린다. 꼬리는 고정 크기이며 판 폭 736→960 변경 시 오른쪽 앵커만 따라간다. Hover/Selected의 이동·회전·확대는 판과 함께 적용한다. 세부 좌표와 Unity 앵커 환산은 layout.json 참조.

그림자 꼬리는 판 그림자와 동일한 오프셋·알파 규칙을 적용한다. 그림자 오프셋을 PNG에 굽지 않았다. 기존 v1 판 파일은 변경하지 않았다.

검증: 4개 RGBA 파일 모두 112×64, 알파 채널 동일. 확인 시트에 단독 조각 및 세 상태 각각 736/960px 판 조립을 포함했다. 게임 에디터 적용은 수행하지 않았다.
