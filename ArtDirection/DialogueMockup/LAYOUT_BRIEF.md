# 대화 화면 · 레이아웃 요청서 (블루아카식 구조 + 버텍스 겉옷)

게임 안의 대화 화면 두 종류를 **하나의 문법**으로 다시 그린다. 이번에는 **겉모습만** 바꾼다. AUTO·SKIP·LOG 같은 기능 버튼은 데모 빌드 범위 밖이니 그리지 않는다.

| 화면 | 쓰는 곳 | 지금 |
|---|---|---|
| **스토리 대화** (`DialogueView`) | 합류·호감도 랭크업 대화, 캐릭터 스탠딩이 크게 나옴, 선택지 있음 | 왼쪽에 스탠딩 760×1000, 하단 띠, 선택지는 오른쪽 위 세로 목록 |
| **하단 대사창** (`NpcDialogueOverlay`) | 상점 입장 인사·휴식 캠프 대사 등, 배경 화면 위에 띠만 올라옴, 답변 버튼 1개 | 하단 띠 + 오른쪽 "NEXT" 글자 |

- 지금 하단 띠: `Reference_CurrentBand.png` (반투명 먹색 띠 + 헤어라인 + ✦ 장식)
- 스타일 기준: `Reference_LobbyStyle.png`, `Reference_Shop_v2.png`, `Reference_Blessing_v1.png`
- **그대로 두는 것:** 캐릭터 스탠딩·초상 그림, 배경 그림

## 0. 방향

**블루아카이브 대화 화면의 구조를 빌리고, 겉모습은 버텍스 문법으로 입힌다.**

| 블루아카에서 가져올 것 | 버텍스에서 바꿀 것 |
|---|---|
| 화면 아래 넓고 밝은 대화창, 위쪽으로 갈수록 배경에 녹아드는 그라데이션 | 둥근 모서리 → **사선 컷**. 반투명 그라데이션 → **불투명 그라데이션 그림으로 굽기** (Linear 색공간이라 반투명이 옅게 뜬다) |
| 이름 + 옆에 작은 소속 글자 ("치하라 쇼  VERTEX / 협력자") | 이름 색 = 먹색 하나. 소속 글자는 청록. **캐릭터 고유색은 이름 아래 가는 선 하나**에만 (축복 이름판의 붉은 선과 같은 방식) |
| 오른쪽 아래 ▼ 깜빡이는 넘기기 표시 | ▼ 대신 **청록 마름모 + 짧은 헤어라인** |
| 스탠딩이 화면 가운데에 크게, 말하는 사람만 밝고 나머지는 어둡게 | 스탠딩 처리는 게임에서 한다. 목업은 1인·2인 배치를 보여 주기만 |
| 선택지가 화면 **가운데**에 버튼으로 세로 정렬 | 버튼은 축복 선택지 판과 같은 문법(사선 컷 종이 판, 왼쪽 작은 번호, 오른쪽 →) |

## 1. 색

| 역할 | 값 |
|---|---|
| 대화창 바탕 | 오프화이트 #F1F2F4, 위쪽 가장자리 120px에서 투명으로 사라지는 **불투명 그라데이션**(알파를 그림에 굽는다 — 계단 없이 부드럽게, 맨 위 0 → 120px 지점 255) |
| 대화창 위 가장자리 | 흑연 헤어라인 1px (그라데이션이 끝나는 곳) + 왼쪽 끝 작은 마름모 |
| 대사 글자 | 먹색 #16181B |
| 이름 | 먹색 굵게 |
| 소속 글자 | 청록 #0DB8F2 작게 |
| 넘기기 표시 | 청록 마름모 |
| 선택지 판 | 축복 선택지와 같은 종이 판 |

## 2. 배치 (1920×1080, 왼쪽 위 원점)

### 2.1 스토리 대화

```
                    (스탠딩: 1인이면 가운데 x 580~1340, 2인이면 왼쪽·오른쪽)

                         ┌ 선택지 (가운데) 760×72 ×3, 간격 12 ┐
                         │ 01  같이 가자.                   → │  y 420~
                         │ 02  ……조금만 더 생각해 볼게.      → │
                         └────────────────────────────────────┘
 ─────────────────────────────────────────────────── (그라데이션 위 끝 y 780)
 ┌ 대화창 (0,780) 1920×300 ─────────────────────────────────────────────┐
 │   치하라 쇼   VERTEX / 협력자                                          │ ← 이름 줄 (200, 820)
 │   ───── (캐릭터 고유색 가는 선 120px)                                  │
 │   "…가자. 우리 둘, 따라갈게."                                          │ ← 대사 (200, 890) 1420×120, 34pt
 │                                                              ◆ ──     │ ← 넘기기 (1700, 1010)
 └──────────────────────────────────────────────────────────────────────┘
```

| 영역 | 위치 · 크기 | 형태 |
|---|---|---|
| **대화창** | (0, 780) 1920 × 300 | 종이 그라데이션 판. 위 120px는 투명→불투명. 왼쪽 위와 오른쪽 아래 모서리 사선 컷(화면 끝이라 컷은 판 안쪽 장식선으로 표현해도 됨). 오른쪽 끝에 옅은 나침반 워터마크(축복 대사 판과 같은 것) |
| 이름 줄 | (200, 820) | 이름 40pt 굵게 + 옆 소속 16pt 청록 + 아래 고유색 선 120×3 |
| 대사 | (200, 890) 1420 × 120 | 34pt, 두 줄까지 |
| 넘기기 표시 | (1700, 1010) | 청록 마름모 14px + 헤어라인 48px (게임에서 깜빡임) |
| **선택지** | 가운데, 첫 칸 (580, 420) 760 × 72, 간격 12 | 축복 선택지 판 문법. 번호 01~03 + 대사 + →. 호버·비활성 상태 |
| 스탠딩 | 1인: 가운데 760×1000 / 2인: 왼쪽 (160,80)·오른쪽 (1000,80) | 그림 없음 — 자리만 |

### 2.2 하단 대사창 (상점·휴식 등)

스토리 대화와 **같은 대화창 판**을 쓴다. 다른 점만:
- 스탠딩 없음 (배경 화면 위에 대화창만)
- 이름 줄 왼쪽에 **초상 칸** 96×96 (축복 대사 판의 초상 칸 문법) — 이름은 초상 오른쪽으로 밀림
- 답변 버튼 1개: 대화창 오른쪽 위에 걸치는 작은 판 (1180, 712) 640 × 60 — 선택지 판의 작은 버전
