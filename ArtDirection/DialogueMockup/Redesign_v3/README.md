# Dialogue Redesign v3

방향 확인용 완성 화면 3장. 분절 및 게임 적용은 포함하지 않는다.

- Story_v3.png: 밤 도시와 협력자. 중앙 선택지를 지우고 하단 대화로 정리.
- Overlay_v3.png: 상점과 토냐. 중복 검은 말풍선 제거, 하단 초상과 이름으로 통합.
- Choice_v3.png: 배경 상점만 어둡게 누르고 두 캐릭터 및 하단 대화는 밝게 유지. 선택지 3장의 사선·꼬리 형태 유지.

## 판 높이와 모서리

1920×1080 기준 하단 약 270~290px. 잘린 모서리와 먹색 받침, 딱딱한 그림자 방향을 선택했다. 밤 도시·밝은 상점·어두운 선택 장면 모두에서 판의 경계가 읽히고 Victory/Result_Clear의 편집 디자인과 연결되기 때문이다. 회청색 면과 크게 잘린 저농도 나침반은 주로 양 끝에 배치하고, 대사 중앙은 세 줄을 배치할 여유로 남겼다. 이름 밑줄은 런타임에서 캐릭터색으로 교체할 자리다.

## 제작

세 장 모두 내장 이미지 모델로 완성 화면을 생성했다. SVG·도형 조립·에셋 시트 미사용. 실제 프롬프트는 PROMPTS.txt. 생성 원본은 1672×941이며 납품 PNG는 1920×1080으로 리샘플링했다. 별도 그림/글자를 덧그리는 후처리는 하지 않았다. 참조 장면과 캐릭터를 바탕으로 재생성했으므로 픽셀 단위 보존은 아니다. 상점의 작은 카드 설명 등은 방향 확인용이며 실제 게임 텍스트로 사용하지 않는다.
