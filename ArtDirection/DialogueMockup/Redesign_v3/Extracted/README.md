# Choice v3 분절

선택지 전용 2배 RGBA PNG 12개. 하단 대화창, 스탠딩, 화면 덮개는 포함하지 않는다. Assets 파일은 수정하지 않았다.

## 제작 및 확인

SVG 미사용. 내장 image_gen으로 정본을 참조한 흰 종이 및 먹색 잉크 표면을 생성하고 래스터 마스크로 외곽을 잘랐다. 실제 프롬프트는 PROMPTS.txt, 생성 표면 원본은 Generated/에 보관했다. 단색 후처리는 외곽 알파, 상태 테두리, 그림자, 화살표, 짧은 선에 한정했다. Selected 오른쪽 면은 생성 잉크 표면을 부드럽게 밝힌 것이다. 글자·번호는 PNG에 들어 있지 않다.

판 1440×208 PNG = 화면 720×104px. 가로 720~960px, 높이는 고정. 9-slice 경계는 PNG 기준 왼320 / 아래12 / 오른640 / 위12. 양 끝의 모서리·사선 면·십자는 고정하고 조용한 가운데 종이 부분을 늘린다. 세 상태와 그림자의 경계가 같다. 미리보기의 720/960 조립은 실제 PNG를 이 경계로 늘린 결과다.

꼬리는 화면 56×32px, 판 오른쪽 위 기준 (-6,+38)에 배치한다. 판 뒤 그림자 → 판 → 꼬리 → 장식 → 런타임 글자 순서. 꼬리 접합부는 6px 겹치며 Hover/Selected 판 오른쪽 테두리의 해당 구간을 열어 이중 선을 피했다. 그림자는 판·꼬리 모두 (+8,+10), 불투명도 0.65. Choice_Arrow는 흰 원본이며 Normal에서 #11191E, 나머지 상태에서 흰색으로 tint한다.

회전은 PNG에 굽지 않았다. layout.json의 세 줄 위치·각도는 정본을 측정한 참고값이다. 정본 판 폭은 약670~690px지만 납품은 요청한 최소720px로 정규화했다. 부모를 회전하여 판·꼬리·그림자·글자를 함께 돌린다. 화면 시계방향 각도와 Unity Z 회전 부호는 반대다.

상위 폴더 Choice_v3_Hover.png / Choice_v3_Selected.png는 이미지 모델로 생성한 상태 방향 확인용 목업이다. 정확한 조각 조립·늘림 검토는 Contact_Sheet.jpg를 사용한다. 재생성 특성상 정본과 종이결·미세 사선 배치는 다르다. 납품은 ArtDirection에만 저장했으며 게임 적용은 하지 않았다.

검증: PNG 12개 크기 및 전부 이진 알파(0/255), Normal/Hover/Selected 판과 꼬리 각각 동일 알파 확인. 720/960px 조립 시각 확인 완료.
