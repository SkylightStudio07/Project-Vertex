# 작전 상황 화면 · 분절 요청

`OpStatus_Mockup.png`(평상), `OpStatus_Hover.png`(반응 상태)를 **디자인 정본으로 확정**한다. 이 디자인 그대로 게임용 조각을 만들어 달라.
작업 방식은 `../UI_Mockup_Split_Workflow.md` 4단계를 따른다.

## 게임이 직접 그리는 것 (조각에 넣지 않는다)

글자 · 숫자 전부, 배경, 작전 담당 캐릭터, 무기 그림, 카드 종류 아이콘, 작전 종류 아이콘, 진행 막대 · 덱 막대 · 비용 막대그래프, 얇은 구분선, 무기 창 꺾쇠, 화면 모서리 `+` 십자, 판독문.

## 핵심 규칙

1. 표면은 **이미지 모델로 그린 그림**이다. 목업의 종이 질감 · 먹색 판 질감 · 사선 해칭 · 잘린 모서리를 살린다. SVG · 도형 조립 금지. 1~2px 단색 테두리선 · 점선 · 꺾쇠만 단색으로 그려도 된다.
2. 조각마다 **글자 없이 단독으로 다시 그린다**(목업에 글자가 구워져 있어 그대로 자를 수 없다). 목업과 같은 모양 · 비율 · 질감.
3. **평평한 순마젠타 #FF00FF 바탕** 위에 그린 뒤 알파를 뽑는다. 그림 안에 마젠타 계열을 쓰지 않는다.
4. **2배 PNG**(화면 1px = PNG 2px), RGBA 8비트, 회전 0°, 캔버스 바깥 4px 알파 0.
5. 먹색 판은 **불투명하게** 그린다(게임이 투명도를 준다). 외곽은 이진 알파, 빛 번짐(시안 글로)만 soft.
6. 늘어나야 하는 조각은 **9-slice**: 눈에 띄는 무늬(잘린 모서리 · 해칭 · 꺾쇠)는 모서리 칸에만, 가운데는 반복 가능한 질감만. `layout.json`에 테두리 px(L,B,R,T, PNG px)를 적는다.

## 알파 뽑기 (마젠타 바탕 제거)

- `d = max(|R−255|, G, |B−255|)`.
- 이진: `d ≥ 96`이면 255, 아니면 0. 외곽 1px의 마젠타 섞임은 안쪽 이웃 평균 RGB로 바꾼다.
- soft(시안 글로): `alpha = clamp((d − 40) / 120, 0, 1)`, RGB는 마젠타를 빼서 되돌린다(straight alpha).
- 확인: #0B111A 위에 합성했을 때 분홍 · 보라 테두리가 한 픽셀도 없어야 한다.
