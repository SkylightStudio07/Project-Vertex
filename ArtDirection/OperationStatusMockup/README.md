## 제작 방식

- 그림과 UI 표면, 문양, 아이콘, 무기, 글자를 모두 기본 제공 imagegen 도구로 생성했습니다. SVG, 코드로 그린 도형, HTML 캡처, 에셋 시트를 사용하지 않았습니다.
- 기본 화면은 Reference의 확정 격납고 배경과 작전 담당을 기준으로 생성했습니다. 로비의 종이/먹색 판과 작전 개시의 해칭·눈금·꺾쇠 문법을 함께 참조했습니다.
- 참조 6장을 모두 확인했습니다. 도구 입력은 5장 제한이 있어 배경·캐릭터·출정 준비·로비·작전 개시를 직접 첨부했고, 의뢰 게시판의 카드 정보는 프롬프트에 명시했습니다.
- 호버 화면은 기본 화면 한 장을 편집 대상으로 사용했습니다.
- 도구가 두 번 모두 1672×941로 반환하여, 각 완성 이미지를 동일한 고품질 Bicubic 보간으로 1920×1080 PNG로 내보냈습니다. 이 크기 변환에서 도형이나 텍스트를 추가하지 않았습니다.
- Unity 파일, 원본 참조 이미지, 요청서 및 기존 로그는 수정하지 않았습니다. git을 사용하지 않았습니다.

## 화면 좌표 실측

기준은 납품 PNG의 **1920×1080**, 원점은 **왼쪽 위**, 단위는 화면 px입니다. 표의 값은 요청 프롬프트의 희망 좌표가 아니라 납품 이미지에서 확인한 외곽 바운딩 박스 `[x,y,w,h]`입니다. 잘린 모서리도 사각 바운딩 박스에 포함하며 외부 그림자는 제외합니다. 회색 외곽선과 반투명 그림자의 경계는 약 ±2px 측정 오차가 있습니다.

## 확인 결과와 한계

- PNG 두 장 모두 1920×1080이며 실제 파일을 열어 전체 구성과 한국어 내용을 확인했습니다.
- 장비 3 / +0 / 0 / 2, 덱 총 11장 및 공격 5·스킬 6·파워 0, 비용 분포 0·5·5·1, 사격 ×5·방어 ×5·재장전 ×1, 블랙박스 회수의 목표 2줄과 30 EXP, 구역 안내와 대사문을 확인했습니다.
- 호버 화면에 요청한 네 가지 반응 상태가 모두 표시됩니다.
- **원본 배경 픽셀의 완전 보존 및 상태 영역 외 픽셀의 완전 일치는 달성하지 못했습니다.** 두 화면은 같은 구도와 같은 판 배치이지만, imagegen이 배경과 캐릭터·텍스트 가장자리 등을 미세하게 재합성했습니다. 원본 PNG를 그대로 깔고 UI만 얹은 무손실 합성 파일은 아닙니다.
- 비상태 영역을 8px 간격으로 표본 비교한 결과, 28,325개 표본의 RGB 채널 평균 절대 차이는 255 기준 4.579였습니다. 표본 98.13%에 작은 차이가 있어 두 화면을 픽셀 단위로 동일하다고 볼 수 없습니다.
- 호버 카드와 출격 버튼 외곽도 강조 과정에서 약 2~4px 커졌습니다. 엄격히 같은 외곽 형태가 필요한 상태 교체용 제작 정본으로는 추가 검수가 필요합니다.
- 이번 파일은 검토용 완성 목업입니다. 투명 분절 PNG, layout.json 및 Unity 적용 작업은 요청 범위에 따라 만들지 않았습니다.
