# 거점 · 방향 목업 요청

로비의 **베이스캠프(모닥불) 화면을 대신할 "거점"**을 새로 디자인한다. 페르소나 아지트처럼 구역을 골라 들어가면, 합류한 동료가 정해진 자리에 서 있고 누르면 말을 건다.
이번에는 **방향 목업만** 받는다. 분절은 목업이 확정된 뒤 따로 요청한다. 작업 방식은 `../UI_Mockup_Split_Workflow.md`를 따른다.
기획: `Docs/기획/거점.md`

## 바꾸는 것 / 그대로 두는 것

- **새로:** 거점 화면 전체(구역 배경 4종, 구역 탭, 동료 이름표, 시설 지점 표시).
- **그대로:** 로비 메인 메뉴(`Reference/Current_Lobby.png`)의 디자인 언어. `02 베이스캠프` 카드는 `02 거점`으로 이름만 바뀐다(이번 목업 대상 아님).

## 구역 4개

| 구역 | 영문 | 배경 방향 | 시설 지점 |
|---|---|---|---|
| 거주구 | QUARTERS | 침상 · 휴게 테이블 · 커피 머신, 큰 창밖으로 설원과 폐허 철탑 | 없음 (동료 대화 중심, 동료 자리가 가장 많다) |
| 연구소 | LABORATORY | 자료 서가 · 분석 단말 · 시뮬레이션 부스 | 아카이브, 훈련장 |
| 격납고 | HANGAR | 차량 · 정비 리프트 · 무기 거치대 · 큰 셔터 | 무기고 |
| 전진기지 | FORWARD BASE | 작전 지도 테이블 · 보급 상자 · 출입 게이트 | 탐색 개시, 의뢰, 상점 |

- 같은 기지 안의 방들로 보여야 한다. 로비 메인 창밖과 같은 **설원 · 회청 철골 · 뼈흰 패널** 세계.
- 배경은 **사람 없는 빈 방**으로 그린다. 동료는 게임이 따로 세운다(아래 동료 자리).
- 화면 가운데~아래 1/3에 동료가 설 **바닥 공간**을 비워 둔다. 앞쪽 소품(난간, 상자) 한두 개는 동료보다 앞에 오는 레이어로 나눌 수 있게.

## 동료 자리 (목업에 세울 캐릭터)

거주구 목업에는 동료 3명을 세운다. 그림은 아래 파일을 그대로 쓰고 다시 그리지 않는다(크기 · 위치만 맞춤).

| 동료 | 그림 |
|---|---|
| 치하라 쇼 | `Assets/Art/Characters/Joining Characters/CP_01/CP_01_Chihara_Portrait.png` |
| 알레시아 | `Assets/Art/Characters/Joining Characters/CP_02/알레시아_Standing_V2.png` |
| 카리나 빈터발트 | `Assets/Art/Characters/Joining Characters/Chara1/Chara1.png` |

- 동료는 서 있거나 기대 있다. 발밑에 옅은 접지 그림자.
- 한 명은 **마우스 올림 상태**: 발밑 가까이 이름표(이름 + 작은 영문 + "하는 일" 한 줄, 예: `장비 정비 중`). 테두리 약한 하이라이트, 글로 없음.
- 한 명은 **대화 이벤트 있음** 표시: 머리 위 작은 `!` 마커(청록 작은 강조).

## 화면 UI

- **구역 탭**(화면 아래 가운데): `01 거주구 / 02 연구소 / 03 격납고 / 04 전진기지`. 작은 번호 + 굵은 한글 + 넓게 띄운 영문. 선택 탭은 짧은 청록 막대.
- **왼쪽 위**: `거점 / BASE` 제목 + 현재 구역 이름. **오른쪽 위**: 재화 줄(로비와 같음) + 뒤로(`← 로비`).
- **시설 지점**: 배경 속 문 · 단말기 앞에 작은 표지(번호 + 시설 이름 + 화살표). 마우스 올림 상태 1개 포함. 담당 캐릭터는 이번 목업에 그리지 않는다.
