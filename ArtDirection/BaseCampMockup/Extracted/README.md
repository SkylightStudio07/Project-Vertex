# 거점 UI 분절

`../SPLIT_REQUEST.md` 기준. 확정 v2 목업에서 UI만 추출한 29종 RGBA PNG와 `layout.json`이다. 배경·캐릭터·소품·재화 아이콘은 납품 조각에 포함하지 않았다. 기존 v2 및 Unity Assets는 수정하지 않았다.

## 제작 방식

- **SVG 미사용.** 내장 image_gen으로 Hover 상태 확인 화면을 먼저 생성하고, 그 상태와 v2를 참조해 글자 없는 투명 UI 판을 생성했다.
- 상단 바, 탭 바, 버튼, 시설 표지, 이름표, 잠김 판 표면은 `Sources/`의 이미지 모델 출력에서 잘라 사용했다. 무광 먹색 표면·얇은 테두리·잘린 모서리를 유지했다.
- 상단 바의 버튼은 별도 조각으로 추출하고, 원래 버튼 자리는 같은 생성 이미지의 인접 무문자 표면으로 메웠다. 판을 코드 도형으로 다시 그리지 않았다.
- 별·화살표·자물쇠·느낌표는 정본에서 밝기 매트로 추출했다. 허용된 단순 선·막대·작은 다이아 외곽선은 래스터로 처리했다. 다이아 안쪽은 생성 이름표의 무문자 표면이다.
- 어둠/비네트와 상태 띠는 soft alpha 오버레이다. 탭 Hover는 생성된 밝은 면을 낮은 알파로 변환했다.
- 실제 프롬프트 전체는 `PROMPTS.txt`. 원본 생성 결과는 `Sources/`. 이미지 모델 원본을 크롭·리샘플링해 요청된 화면 대비 2배 해상도로 납품했다. 전 조각이 네이티브 2배 생성 해상도라는 뜻은 아니다.

## 파일과 좌표

- 루트 PNG 29종: 게임용 조각. 모두 RGBA, 회전 0도, `PNG 크기 = screen_rect 크기 × 2`.
- `layout.json`: 1920×1080, 좌상단 원점, 화면 좌표 `[x,y,w,h]`. `nine_slice_px`는 **PNG px, [Left, Bottom, Right, Top]**. 텍스트 크기·패딩·자간은 화면 px.
- `text_slots`: 런타임 글자 위치, 정렬, 크기, 굵기, 색, 자간. 글자는 판에 굽지 않았다. 예외 글리프인 `!`, 자물쇠, 별, 화살표는 별도 PNG.
- `NameTag.png`: 218×70 화면 px / 436×140 PNG. 정본은 273×88 화면 px. 정본 좌표와 크기는 `canonical_screen_rect`에 별도 기록했다.
- `Marker_Event.png`: 39×39 화면 px / 78×78 PNG. 정본 49×49의 약 80%. `Glyph_Event.png`를 별도로 올린다.
- `NameTag_Divider`, `NameTag_Leader`, `Sign_Hover_Accent`, `TopBar_ResourceRule`는 독립 제어를 위해 추가했다. Hover 표지는 `Sign_Hover + Sign_Hover_Accent`로 조립한다.
- `LockedPanel`은 요청대로 중앙 구분선을 포함한다. 자물쇠·하단 상태 띠·텍스트는 별도다.
- 상단 바와 하단 탭 바, 표지, 이름표는 가로 9-slice. 지시선은 세로 길이 조정용이다. 고정 크기 판은 border가 모두 0이다.
- 구역 배경이 보이는 범위: **y=110~962**, 높이 852px. 탭 셀 너비 366px, 간격 0px, 첫 셀 x=69. 6칸 예시의 셀 너비는 305px.
- 이름표의 캐릭터 쪽 지시선 끝점 기준 오프셋은 `name_tag_anchor`에 기록했다. 작은 동료에 붙일 때 해당 끝점을 이동시킨다.
- 옥상 탭은 잠금 상태에서 영문 대신 조건을 표시한다. 영문 슬롯은 `visible:false`로 보존했다.

## 검수 자료

- `Contact_Sheet.jpg`: 조각 단독, 거주구·전진기지·옥상 정본/재조립 나란히 비교, 표지 짧게/길게 늘림, 6칸 탭, 상단 바 너비 축소, 80% 이름표·이벤트 마커.
- `QA/Hover_States.png`: 이미지 모델이 생성한 동일 전진기지 장면의 표지·탭·뒤로 버튼 Hover 확인 목업.
- `QA/Reassembled_*.png`: 정본을 배경으로 두고 패널과 글자를 납품 조각/텍스트 슬롯으로 교체한 확인 화면. 원래 이름표를 남기지 않도록 이 비교에서는 정본 크기를 사용했다. 실제 80% 크기는 `QA/NineSlice_Examples.png`에서 확인한다.
- `QA/Assets_Only.jpg`: 투명 조각 전체 목록.
- QA에는 비교용 배경·동료·글자가 들어가므로 **게임 조각으로 임포트하지 않는다**. `Sources/`도 제작 이력용이다.
- 이미 어두워진 옥상 정본에 `LockedDim`을 중복 적용하지 않았다. 새 배경 적용 시에는 배경 다음, 모든 UI 이전에 한 번만 올린다.

## 검증 결과 및 한계

29종의 RGBA 모드, 2배 크기, 이진 알파 조각의 0/255 값, 9-slice 경계 범위 검사를 통과했다. 결과는 `validation.json`. 조각 단독의 글자 잔류와 재조립 배치, 9-slice 예시를 시각 검수했고 옥상 탭 글자/자물쇠 간격과 이벤트 마커 잔여 픽셀을 수정했다.

표면은 요청서가 권장한 무문자 재생성 방식이므로 원본과 질감·테두리의 미세 차이가 있다. QA 텍스트는 맑은 고딕으로 렌더링했으며 정본 생성 글꼴과 동일하지 않다. 정본 좌표 비교는 외관 검토용이며 원본과 픽셀 동일성 테스트가 아니다. Unity 적용 및 실제 게임 폰트 검증은 이번 범위에 포함하지 않았다.
