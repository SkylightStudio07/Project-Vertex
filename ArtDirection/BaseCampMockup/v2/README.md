# 거점 v2 방향 목업

REQUEST_v2.md 기준 완성 화면 5장. 내장 image_gen 이미지 모델로 배경·UI·거점 전용 캐릭터 포즈를 함께 생성했다. SVG 및 코드 도형 조립 미사용.

- Base_Quarters.png: 낮은 천장 거주구, 팔짱 낀 치하라, 난로 옆 산탄총 정비 중인 카리나와 hover 이름표, Lv.6 확장 문.
- Base_Laboratory.png: 실험 중인 알케미스트와 대화 이벤트 !, 아카이브·훈련장.
- Base_Hangar.png: 높은 셔터 정비 공간, 앉아서 창을 닦는 알레시아, 무기고.
- Base_ForwardBase.png: 작전 테이블, 탐색 개시·의뢰·상점, 동료 없음.
- Base_Rooftop_Locked.png: 눈보라 속 옥상과 용접공 구출 의뢰 해금 조건.

모든 최종 PNG는 1920×1080. 이미지 모델 출력 원본은 Generated에 보존하고 크기만 리샘플링했다. 실제 생성 프롬프트는 PROMPTS.txt에 기록했다.

캐릭터 원본은 생김새·의상 참고로 사용했으며, 포즈는 이번 요청에 따라 이미지 모델이 새로 그린 방향안이다. 최종 캐릭터 에셋이 아니다. 기존 v1 및 Assets는 수정하지 않았다. 분절·Unity 적용은 수행하지 않았다.

검수: 캐릭터 인원, 시설 수, 밤 조명, 흰 외곽선 제거, 공통 먹색 UI 구성을 시각 확인했다. 생성 이미지 특성상 세부 글자와 판 좌표는 픽셀 단위 동일성을 보장하지 않는다. 하단 옥상 탭은 공간상 영문 대신 해금 조건을 표시하며, 옥상 화면 제목에는 ROOFTOP이 있다.
