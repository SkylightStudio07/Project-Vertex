## 제작

imagegen 스킬의 내장 이미지 모델로 배경과 UI를 포함한 빈 방 화면4장 및 배경 비교판을 생성했다. SVG·도형 조립으로 UI를 만들지 않았다. 실제 프롬프트는 PROMPTS.txt, 동료 합성 전 생성 원화는 Generated/에 보존했다. 생성 원본1672×941을1920×1080으로 리샘플링했다.

요청대로 캐릭터는 지정된 CP_01_Chihara_Portrait.png, 알레시아_Standing_V2.png, Chara1.png를 다시 그리지 않고 원본 RGBA를 크기·위치만 바꿔 합성했다. 세 파일 모두 이미 투명 배경이며 바탕 제거·재채색하지 않았다. 접지 그림자를 추가하고 치하라 앞에는 생성 원화의 카운터 부분을 다시 겹쳤다. 원본 캐릭터의 외곽 흰 선은 그대로 보존했다.

공통으로 뼈흰 상하 UI, 회청 철골, 설원과 폐허 철탑, 중간~하단 빈 바닥을 사용했다. UI는 첫 장을 참조하여 후속 방을 생성했으므로 배치·규격은 비슷하지만 글자·외곽이 픽셀 단위로 동일하지는 않다. 배경2×2 역시 별도 생성한 비교판이라 화면별 미세 소품 위치에는 차이가 있다. 공통 UI의 정확한 공유와 전경 레이어 분리는 승인 후 분절 단계에서 고정한다.

검토: 동료 수3/1/1/1, 지정 원본 사용, 시설0/2/1/3, 네 구역 탭 및 선택 표시, 재화·로비 버튼, 배경 비교판 확인. 캐릭터 원본·로비·게임 Assets는 변경하지 않았다.
