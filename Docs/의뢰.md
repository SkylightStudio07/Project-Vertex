# 의뢰 시스템 기획 (초안)

로비 **의뢰 게시판**(04, "경험치 수급처")에서 의뢰를 받고, 런 중에 조건을 채워 로비 경험치를 얻는 시스템.
의뢰를 받으면 그 의뢰의 **퀘스트 아이템**이 런 안에서 등장하기 시작하고, 그것을 들고 돌아오거나 조건을 채우면 완료된다.

> 상태: 핵심 시스템 구현됨(데이터·진행·정산). 게시판 UI·런 중 알림은 아직. 수치는 예시다.
> 코드: `Assets/Scripts/Quest/` · 데이터: `Assets/Data/Quests/`, `Assets/Resources/QuestDatabase.asset`

---

## 1. 핵심 규칙

| 항목 | 규칙 |
|---|---|
| 수주 위치 | 로비 → 의뢰 게시판 |
| 동시 진행 | 최대 **2개** (시설 Lv. 2에서 3개) |
| 진행 범위 | 런 1회. 런이 끝나면(클리어·사망 무관) 결과를 정산하고 진행 중 목록에서 빠진다 |
| 보상 | 로비 경험치(무기고 강화 재화). 일부 의뢰는 스토리 플래그·호감도 추가 |
| 실패 | 패널티 없음. 수주 비용도 없다 (부담 없이 받게) |
| 갱신 | 런을 마치고 로비로 돌아올 때마다 게시판 목록 일부 교체 |

## 2. 퀘스트 아이템

의뢰를 받으면 그 의뢰의 퀘스트 아이템을 **런 중 특정 계기로 얻는다**. 효과는 없고 들고 있는 것 자체가 목적이다.

| 항목 | 규칙 |
|---|---|
| 데이터 | 기존 `ItemData` 그대로. `isQuestItem`만 켜고 효과는 비워 둔다 |
| 슬롯 | **일반 아이템 칸을 차지한다** (소모품과 칸을 두고 고민하게) |
| 사용 | 불가. 전투·전투 밖 사용 모두 막혀 있다 |
| 획득 계기 | **특정 층 노드 도달**(막·층 지정) 또는 **특정 적 처치** |
| 칸이 가득 찼을 때 | 획득 보류 → 다음 노드에 들어설 때 다시 시도 (칸을 비우면 들어옴) |
| 표시 | 툴팁 설명 끝에 "의뢰 물품 · 사용 불가" |

## 3. 의뢰 종류와 태그

### 태그 (게시판 카드 오른쪽)

| 태그 | 의미 | 완료 시 |
|---|---|---|
| **Story** | 스토리 진행에 필요한 의뢰 | `rewardFlags`의 스토리 플래그를 켠다 → 다음 의뢰·보스 대사·이벤트 조건으로 쓰인다 |
| **구출** (Rescue) | 합류 캐릭터 해금 의뢰 | `coop_rescued_{캐릭터ID}` 플래그를 켠다 → 성소 후보 해금 조건으로 쓴다 |
| (없음) | 일반 의뢰 | 경험치만 |

### 완료 조건 (구현됨)

| 조건 | 설명 | 예시 (샘플 데이터) |
|---|---|---|
| **회수** `HoldItemAtRunEnd` | 런이 끝날 때(클리어·사망 무관) 퀘스트 아이템을 들고 있음 | 블랙박스 회수 [Story] — 스카웃 유닛 처치 시 획득 |
| **배달** `DeliverToNode` | 퀘스트 아이템을 들고 지정 노드(상점 등) 방문. 아이템은 소모 | 봉인된 서류 — 4층 도달 시 획득, 상점에서 배달 |
| **토벌** `DefeatCount` | 특정 적 N회 처치. 퀘스트 아이템 없음 | 들개 토벌 — 게회언터 훈트 3마리 |

구출 샘플: **구조 신호** [구출] — 10층 도달 시 구조 신호기 획득, 들고 귀환하면 Cp_02 구출 플래그. 블랙박스 회수를 완료해야 게시판에 뜬다(스토리 연계 예시).

조사(이벤트 선택지)·도전(제약 달성)은 같은 틀에 조건만 추가하면 된다. 아직 미구현.

## 4. 흐름

```
[로비 · 의뢰 게시판]
   의뢰 수주 (최대 2개)
        │
[출정 준비] ── 진행 중 의뢰가 요약 표시됨
        │
[런]  층 도달·적 처치로 퀘스트 아이템 획득 → 일반 아이템 칸에 들어감
      조건 진행도 갱신 (전투 승리·노드 방문·이벤트 선택 시)
      달성 시 짧은 알림 "의뢰 달성 — 귀환 시 보상"
        │
[런 종료] 클리어/사망 무관 정산
        │
[로비 복귀] 게시판에 완료 도장 연출 → 보상 수령 버튼 → 경험치 게이지 상승
```

- 달성은 런 중에, **보상 수령은 로비에서**. 수령 연출이 경험치 게이지 상승과 이어지게 한다.
- 사망해도 이미 달성한 조건은 인정한다(회수형은 사망 시점에 들고 있으면 인정). 로그라이트라 실패가 잦으므로 진행이 헛되지 않게.
- 완료한 의뢰는 다시 게시되지 않는다(1회성). 반복 의뢰가 필요하면 별도 옵션을 추가한다.

## 5. 구현 구조

| 파일 | 역할 |
|---|---|
| `Quest/QuestData.cs` | 의뢰 한 건 (SO). 표시·태그·퀘스트 아이템·획득 계기·완료 조건·보상·게시 조건 |
| `Quest/QuestDatabase.cs` | 전체 의뢰 목록. `Resources/QuestDatabase.asset` 하나 — 새 의뢰는 여기 등록해야 인식된다 |
| `Quest/QuestManager.cs` | 로비·런 공용 싱글톤(씬 유지). 수주·진행·정산·저장 |

**흐름과 연결 지점**

| 시점 | 호출 | 하는 일 |
|---|---|---|
| 로비 게시판 | `Available()`, `Accept()`, `Abandon()` | 게시 조건(플래그) 거르기, 최대 2개 수주 |
| 런 시작 | `GameManager.InitializeRun` → `BeginRun()` | 런 진행 초기화, 노드·적 처치·패배 이벤트 구독 |
| 노드 이동 | `MapManager.NodeEntered` | 층 도달 획득, 배달 판정, 보류된 아이템 재시도 |
| 적 처치 | `BattleManager.EnemyDefeated` | 처치 획득, 토벌 카운트 |
| 런 종료 | 패배(`OnBattleDefeat`), 클리어(`RunClearView.Open`) → `SettleRun()` | 완료 판정, 보상 적립, 플래그, 수주 목록 비우기 |
| 로비 복귀 | `LobbyManager.Start` → `ClaimRewards()` | 적립 경험치를 로비 경험치로 |

- 저장: PlayerPrefs(`VERTEX_QUEST_STATE`)에 수주 목록·완료 목록·미수령 경험치·완료 연출 대기 목록.
- UI용 이벤트: `OnQuestProgress(의뢰, 문구)` — 런 중 토스트에 그대로 쓰면 된다. `OnStateChanged` — 게시판 갱신.
- 테스트: `[QuestManager]` 오브젝트 우클릭 → Test/Reset Quest Save.

## 6. UI 레이아웃

로비·출정 준비·무기고와 같은 흰 종이 패널, 청록 포인트, Pretendard 기준.

### 6.1 의뢰 게시판 (로비 04)

```
┌ 04 의뢰 게시판 ───────────────────── 로비 경험치 50/100 ─ [← 로비] ┐
│ QUEST BOARD                                                          │
│ [게시 중]  [진행 중 (1/2)]  [완료 기록]        ← 탭                  │
├──────────────────────────────────┬───────────────────────────────────┤
│ 의뢰 목록 (2열 카드, 스크롤)      │ 의뢰 상세                          │
│ ┌──────────────┐┌──────────────┐ │  [의뢰인 초상/세력 문장]           │
│ │▣ 회수        ││◆ 배달        │ │  R&C 컴퍼니 · 회수                 │
│ │블랙박스 회수  ││봉인된 서류    │ │  정찰 드론의 블랙박스를 회수하라   │
│ │R&C 컴퍼니    ││상점 주인 토냐 │ │  ── 목표 ──                        │
│ │보상 30 EXP   ││보상 20 EXP   │ │  ☐ 스카웃 유닛 조우에서 획득       │
│ └──────────────┘└──────────────┘ │  ☐ 런 종료 시 보유                 │
│ ┌──────────────┐┌──────────────┐ │  ── 의뢰 물품 ──                   │
│ │⚔ 토벌   [수주]││★ 도전   🔒   │ │  [아이콘] 손상된 블랙박스          │
│ │훈트 3마리     ││휴식 없이 보스 │ │   효과 없음 · 아이템 칸 차지       │
│ │독일 특무국    ││1막 클리어 필요│ │  ── 보상 ──                        │
│ └──────────────┘└──────────────┘ │  30 EXP  +  스토리 단서            │
│                                  │                                    │
│  [수주됨] 표시는 우상단 청록 도장 │  [ 의뢰 수주 → ]  (진행 중 2/2면 비활성) │
└──────────────────────────────────┴───────────────────────────────────┘
```

- 카드 좌상단에 유형 기호(회수 ▣, 배달 ◆, 토벌 ⚔, 조사 ?, 도전 ★)와 유형명, **오른쪽에 태그**(Story·구출).
- 잠긴 의뢰는 회색 + 자물쇠 + 해금 조건 한 줄 (무기고 카드 목록의 잠금 카드와 같은 문법).
- 수주한 의뢰 카드는 우상단에 청록 "수주" 도장.
- 로비 복귀 후 완료된 의뢰는 **진행 중 탭에서 "완료" 도장이 찍히는 연출** → [보상 수령] → 상단 경험치 게이지가 차오른다.

### 6.2 출정 준비 (추가 요소)

특전 카드 칸 아래에 한 줄 요약만 둔다.

```
│ 진행 중 의뢰                     │
│ ▣ 블랙박스 회수   ◆ 봉인된 서류  │   ← 누르면 목표 툴팁
```

### 6.3 런 중

- **아이템 바:** 퀘스트 아이템은 일반 칸에 들어간다. 청록 테두리로 구분하고 툴팁에 의뢰명과 목표를 보여 준다.
- **진행 알림:** 조건이 진행될 때 화면 오른쪽 위에 짧은 토스트 "블랙박스 회수 1/1 — 귀환 시 보상" (2초, 입력 막지 않음).
- **맵:** 의뢰 목표와 관련된 노드(배달 목적지인 상점 등)에 작은 청록 표식. 경로 선택에 이유를 준다.

## 8. 열린 질문

- 사망 시 회수형 의뢰를 **인정할지** (현재: 인정)
- 칸이 가득 차서 못 받은 퀘스트 아이템을 **보류할지 그냥 놓칠지** (현재: 보류 후 재시도)
- 의뢰 목록 **갱신 주기**와 게시 수 (초안: 4개 게시, 복귀 때 2개 교체)
- 시설 레벨로 여는 것: 동시 진행 수 증가, 고급 의뢰(보상 큼) 등장
- 보상을 경험치 외에 **카드 해금**(무기고 카드 목록의 "???" 칸)으로도 줄지
