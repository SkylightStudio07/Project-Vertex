# 무기 시스템

전투에서 플레이어가 드는 총기, 탄약, 재장전, 초탄·막탄, 무기고 강화를 정리한다.
기준 코드: `WeaponData`, `BattleState`, `CardContext`, `AmmoCardBehaviors`, `WeaponUpgrades`, `PlayerRecord` (브랜치 `feature/weapon-ammo-system`).

## 1. 한눈에 보기

| 개념 | 한 줄 정의 |
|---|---|
| 총기 | 플레이어가 지금 들고 있는 무기. 전투마다 기본 무기(권총)로 시작한다 |
| 사격 카드 | 덱의 "무기 사격 카드"는 지금 든 총기의 사격 카드로 바뀌어 보인다 |
| 탄약 | 탄약을 쓰는 카드의 비용. **최대 탄약을 넘지 않는다(하드캡)** |
| 최대 탄약 | 총기 기본값 + 무기고 강화 + 이번 전투 탄창 확장 |
| 재장전 | 탄약을 최대 탄약까지 채우고 초탄·막탄을 다시 쓸 수 있게 한다 |
| 초탄 / 막탄 | 재장전 후 처음 쏜 카드 / 탄창을 비운 카드. **지정한 총기에서만** 성립한다 |
| 무기고 강화 | 로비에서 총기별로 영구 강화. 연사형은 탄창, 한방형은 한 발의 피해 |

## 2. 총기

| 총기 | 분류 | 최대 탄약 | 사격 카드 | 초탄·막탄 | 무기고 강화 | 비고 |
|---|---|---|---|---|---|---|
| 권총 | 연사형 | 3 | 권총 사격 — 에너지 1 · 탄약 1 · 피해 6 | 적용 | 최대 탄약 +1 / +2 | 전투 시작 기본 무기 |
| 스나이퍼 | 한방형 | 1 | 스나이퍼 사격 — 에너지 1 · 탄약 1 · 피해 9 | 미적용 | 사격 피해 +3 / +6 | |
| 레일건 | 이벤트 | 1 | 레일건 사격 — 에너지 1 · 탄약 0 · 피해 6 | 미적용 | 없음 | 이벤트 카드로만 전환 |
| 산탄총 | 한방형 (예정) | — | — | 미적용 (예정) | 사격 피해 (예정) | 미구현 |

- 분류 기준: **연사형** = 탄약이 많고 초탄·막탄으로 리듬을 만든다. **한방형** = 탄약이 적고 한 발 한 발이 강하다.
- 총기 데이터는 `Assets/Data/Weapons/*.asset`의 인스펙터에서 정한다.

| WeaponData 항목 | 의미 |
|---|---|
| 사격 카드 (`shootingCard`) | 이 총기를 들면 덱의 무기 사격 카드가 이 카드의 사본으로 바뀐다 |
| 최대 탄약 (`maxAmmo`) | 재장전·총기 전환 때 채우는 탄약 수 |
| 초탄 · 막탄 (`usesAmmoBoundary`) | 켜면 이 총기에서 초탄·막탄 판정이 성립한다 |
| 강화 종류 (`upgradeType`) | 없음 / 최대 탄약 / 사격 피해 |
| 단계별 수치 (`upgradeValues`) | 단계별 **누적** 값. `[1, 2]` = 1단계 +1, 2단계 +2. 배열 길이가 최대 단계 |
| 단계별 비용 (`upgradeCosts`) | 각 단계로 올리는 비용. 재화 미정이라 임시 값 |

## 3. 탄약 규칙

| 상황 | 규칙 |
|---|---|
| 전투 시작 | 기본 무기를 장착하면서 재장전 → **시작 탄약 = 최대 탄약** |
| 카드 사용 | 탄약 비용만큼 차감. 모자라면 낼 수 없다 |
| 탄약 획득 (재장전 아님) | 총기를 들고 있으면 **최대 탄약까지만** 오른다. 넘친 만큼은 버린다 |
| 총기 없음 | 상한 없이 그대로 더한다 (예외 상황) |
| 탄창 확장 (이번 전투) | 해당 총기의 최대 탄약을 이번 전투 동안 올린다. 그 총기를 들고 있으면 바로 재장전 |
| 탄약 전량 소모 카드 | 남은 탄약을 모두 쓰고 그만큼 피해. 카드 자체 탄약 비용은 0이어야 한다 |
| 비용 전환 상태 | 일부 상태는 탄약 비용을 HP 비용으로 바꾼다 (`CardBloodCostStatusBehavior`) |

## 4. 재장전과 총기 전환

| 동작 | 탄약 | 초탄·막탄 | 사격 카드 교체 | 재장전 이벤트 |
|---|---|---|---|---|
| 재장전 효과 | 최대 탄약까지 | 다시 사용 가능 | — | 발생 |
| **다른** 총기로 전환 | 새 총기의 최대 탄약까지 | 다시 사용 가능 | 손패·뽑을·버린·소멸 더미 전부 | 발생 |
| **같은** 총기로 전환 | 변화 없음 | 변화 없음 | 없음 | 없음 |

- 같은 총기로 전환하면 **아무 일도 일어나지 않는다**. "권총으로 전환" 카드를 권총 상태에서 내면 방어도·드로우 같은 나머지 효과만 적용된다.
- 재장전 이벤트를 받는 상태: "장전의 여유"(재장전마다 방어도) 등.

## 5. 초탄 · 막탄

| 판정 | 조건 | 횟수 |
|---|---|---|
| 초탄 | 재장전 후 **처음으로** 탄약을 쓴 카드 | 탄창당 1번 |
| 막탄 | 탄약을 써서 남은 탄약이 **정확히 0**이 된 카드 | 탄창당 1번 |

- **총기 한정**: `초탄 · 막탄`이 켜진 총기(현재 권총)에서만 성립한다.
- 플레이어가 **직접 낸 카드**만 해당한다. 패시브가 발동시킨 효과는 제외.
- 탄약 2 이상을 쓰는 카드는 한 장으로 초탄이면서 막탄일 수 있다.
- 카드의 피해 숫자 미리보기는 "지금 내면 초탄·막탄인지"를 미리 계산해 보여 준다(실제 탄약은 건드리지 않는 복사본).

예시 — 권총(최대 탄약 3), 탄약 1 카드 3장:

| 순서 | 사용 전 탄약 | 사용 후 | 판정 |
|---|---|---|---|
| 1 | 3 | 2 | 초탄 |
| 2 | 2 | 1 | — |
| 3 | 1 | 0 | 막탄 |
| 재장전 | — | 3 | 초탄·막탄 다시 가능 |

## 6. 무기고 강화 (로비, 영구)

| 분류 | 강화 | 효과 | 권총 | 스나이퍼 |
|---|---|---|---|---|
| 연사형 | 최대 탄약 | 최대 탄약 + N (시작·재장전 탄약도 같이 오름) | 1단계 +1 (4발) · 2단계 +2 (5발) | — |
| 한방형 | 사격 피해 | 탄약을 쓴 공격의 **타격마다** 피해 + N | — | 1단계 +3 · 2단계 +6 |

- 강화 단계는 플레이어 영구 기록(`PlayerRecord`)에 총기별로 저장된다. 전투 시작 때 장착 전에 반영된다.
- 사격 피해 강화는 그 총기를 들고 **탄약을 쓴 공격**에만 붙는다. 탄약을 쓰지 않는 카드에는 없다.
- 최대 단계를 넘는 값은 마지막 단계로 취급한다.
- **미정**: 강화 재화와 비용(지금은 임시 값, 차감하지 않음), 무기고 강화 화면(아트 요청 예정).

## 7. 탄약 관련 카드 요소

| 종류 | 이름 | 설명 |
|---|---|---|
| 조건 | 초탄 (`FirstAmmoUseCondition`) | 이 카드가 초탄이면 |
| 조건 | 막탄 (`LastAmmoUseCondition`) | 이 카드가 막탄이면 |
| 조건 | 탄약 비교 (`PlayerAmmoCondition`) | 현재 탄약이 N 이하/이상 등 |
| 조건 | 총기 (`PlayerWeaponCondition`) | 지정한 총기를 들고 있으면 |
| 조건 | 방어도 획득 (`PlayerGainedBlockCondition`) | 이번 턴에 방어도를 얻었으면 |
| 효과 | 탄약 획득 (`AddAmmoEffect`) | 탄약 + N (최대 탄약까지) |
| 효과 | 재장전 (`ReloadAmmoEffect`) | 최대 탄약까지. 직전 탄약이 0이면 추가 효과 가능 |
| 효과 | 총기 전환 (`ChangeWeaponEffect`) | 다른 총기면 전환 + 재장전, 같은 총기면 없음 |
| 효과 | 탄창 확장 (`IncreaseMagazineEffect`) | 이번 전투 동안 해당 총기 최대 탄약 + N |
| 효과 | 탄약 전량 소모 (`AmmoConsumeAllDamageEffect`) | 남은 탄약 × 피해 (또는 탄약당 1타) |
| 피해 확장 | 조건부 추가 피해 (`conditionalBonuses`) | 예: "초탄이면 피해 +4" |
| 피해 확장 | 처치 시 효과 (`onKillEffects`) | 예: "처치하면 재장전" |

| 상태 | 효과 |
|---|---|
| 탄창 숙련 | 초탄·막탄인 카드의 피해 + N (둘 다면 2배) |
| 발포 준비 | 다음 탄약을 쓰는 카드의 피해 + N |
| 권총 속사 준비 | 이번 턴 다음 탄약을 쓰는 카드의 에너지 − N |
| 사선 이탈 | 이번 턴 쓴 탄약 1발당 방어도 + N |
| 사격 후 이동 | 초탄 카드 사용 시 방어도 + N |
| 장전의 여유 | 재장전할 때마다 방어도 + N |
