# 로비 상점

로비 메뉴 05. 탈린으로 산다. 상점 주인은 **보급 담당**(스토리 중 합류하는 비전투 캐릭터, 전투 동행 없음). 합류 시점은 스토리를 쓰면서 정하고, 그 전까지 상점은 **처음부터 열어 둔다.**

## 1. 상품

| 탭 | 받는 것 | 재고 | 비고 |
|---|---|---|---|
| 강화 재료 | 파츠 | 스토리 진행마다 **3개**로 채움, 파츠 상품끼리 공유 | `MetaProgress.ShopPartsStock` (막 보스 첫 격파·스토리 의뢰 완료 때 채움) |
| 선물 | 선물 1개 | 제한 없음 | 산 선물은 쌓아 두고 **동료 화면에서 준다** (상점은 사기만) |
| 무색 카드 | 무색 카드 해금 | 한 번 | 해금 기록은 `MetaProgress` 이정표 `shop:unlock:<itemId>` |

- 지금 진열(`Assets/Data/Shop/ShopCatalog.asset`): 파츠 묶음(파츠 10, 120) · 보급 패키지(파츠 20, 220) · 따뜻한 커피(선물, 60) · 기록 노트(선물, 90)
- 무색 카드: 아직 무색 카드 풀이 없다(무색은 상태이상·저주 카드뿐). 무색 카드를 만들면 상품을 추가하고, 해금된 카드만 런 보상 풀에 넣는 연결을 한다.

## 2. 구매

- 수량 `− 1 +`. 최대 = 재고 · 탈린 · 99 중 작은 값. 무색 카드는 1개.
- 판정(`LobbyShop.Check`): 이미 해금 → 품절 → 탈린 부족 순.
- 구매 바: `보유 1,240 → 구매 후 1,120`, 합계 가격, `구매하기`.
- 대사: 입장 / 구매 / 탈린 부족 / 품절 때 바뀐다.

## 3. 화면

- 왼쪽 상점 주인(크게) + 왼쪽 아래 대사창, 오른쪽 탭 4개(전체·강화 재료·선물·무색 카드) + 3열 상품 칸 + 구매 바.
- 제목·`← 로비`·탭은 무기고와 같은 모양·자리.
- 재화 표시는 로비 재화 바 아이콘을 그대로 쓴다.
- 아트 요청: `ArtDirection/LobbyShopMockup/LAYOUT_BRIEF.md`
