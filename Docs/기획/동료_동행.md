# 동료 동행 규칙 (런)

## 1. 인원

- 런에서 같이 다니는 동료는 **최대 3명**(플레이어 포함 4인)이다. 전투 화면 동료 자리도 3칸이다.
- 상한은 `CooperationManager.MaxCompanionsInRun`이다.

## 2. 성소 — 가득 차면 합류 불가

- 동료가 3명이면 성소 후보는 보이지만 고를 수 없다.
  - 띠가 잠기고 그림은 어둡게 칠해진다.
  - 띠 아래에 "동행 인원 가득 참"이 뜬다.
- 안내 문구는 "동행 인원이 가득 찼습니다. 휴식 지점에서 동료를 거점으로 돌려보내면 합류할 수 있습니다."로 바뀐다.
- "후보 확인" 버튼은 "돌아가기"가 되어 맵으로 나간다.
- 구현: `SelectCoopCharUI`(`partyFull`, `partyFullHint`, `partyFullGuide`), `SelectCoopCharBtn.SetCandidate(…, unavailableHint)`

## 3. 휴식 — 동료 귀환 (거점으로 돌려보내기)

- 휴식 메뉴의 세 번째 선택지다(휴식 · 강화 · **동료 귀환**). 고르면 휴식 한 번을 쓴 것으로 치고 맵으로 돌아간다.
- 흐름:
  1. "동료 귀환"을 누른다.
  2. "거점으로 돌려보낼 동료를 고르십시오" 안내가 뜬다.
  3. 캠프의 동료를 누른다.
  4. 확인 창("○○을(를) 거점으로 돌려보냅니다. 덱에서 ○○의 카드 n장이 빠집니다.")에서 돌려보내기 / 취소를 고른다.
- 귀환하면 동료가 런에서 빠지고, 그 동료 몫의 카드가 정리된다.
  - **합류 카드:** 합류할 때 덱에 넣은 그 한 장만 뺀다. 시작 덱에 같은 카드가 있으면 그건 남는다(예: 치하라 쇼의 재장전).
  - **보상 풀·호감도 해금 카드:** 덱에서 모두 빼고 보상 풀에서도 뺀다. 단, 플레이어 기본 카드(시작 덱·기본 보상 풀)와 겹치는 카드는 남긴다.
- 호감도는 그대로 유지된다(영구 기록).
- 구현: `CooperationManager.DismissFromRun / CardsLeavingWith`, `RestView`(동료 귀환 부분), `CoopCharData.OwnedCards()`
- 휴식 화면은 나중에 전부 다시 만든다. 지금은 기존 휴식 조각을 복제한 단순 uGUI다.

## 4. 훈련장

- 같은 상한(3명)이다.
- 동료 고르기는 별도 "동료 편성" 페이지(격자)에서 한다. 동료가 3막까지 9명에 이벤트 동료까지 더해지므로 목록으로는 감당이 안 된다.
- 아트 요청서: `ArtDirection/TrainingMockup/LAYOUT_BRIEF_Companion.md`

## 5. 소속 막

- `CoopCharData.actNumber`(1~3)로 합류하는 막을 적는다. 이벤트 동료는 `isEventCompanion`으로 따로 묶인다.
- 훈련장 동료 편성의 "소속: 1막 / 2막 / 3막 / 이벤트" 필터에 쓴다.
- 지금 기본값은 1막이다. 동료마다 따로 설정해야 한다.
