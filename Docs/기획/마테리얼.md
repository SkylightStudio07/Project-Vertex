# 마테리얼 (작전 기록 / 도감)

로비 시설 05. FGO 인연 자료처럼 기록이 쌓일수록 대상마다 글이 한 편씩 열린다. 대상은 **적**과 **동료**이고, 대상마다 **5편**이다.

## 1. 해금 규칙

| 대상 | 한 편이 열리는 기준 | 1 · 2 · 3 · 4 · 5편 |
|---|---|---|
| 일반 적 | 격퇴 3회마다 | 3 · 6 · 9 · 12 · 15회 |
| 엘리트 | 격퇴 2회마다 | 2 · 4 · 6 · 8 · 10회 |
| 보스 | 격퇴 1회마다 | 1 · 2 · 3 · 4 · 5회 |
| 동료 | 호감도 레벨마다 | Lv.1 · 2 · 3 · 4 · 5 |

- 격퇴 수는 **실전 기록**만 센다. 훈련장 전투는 세지 않는다(`PlayerRecord`).
- 다인 보스(빅 쓰리)는 **한 명씩 따로** 센다. 마테리얼도 세 명 각각이다.
- 적 등급은 `EnemyData.rank`다. 조우 데이터에서 자동으로 매겼고, 보스 조우에 나오는 적은 보스, 엘리트 조우는 엘리트다.
- **훈련장 연동:** 첫 편이 열리면 그 적은 훈련장 상대로도 열린다. 조우 안의 모든 적이 첫 편을 열어야 한다. 훈련장 상대 줄의 점 개수도 이 기준(일반 3 · 엘리트 2 · 보스 1)을 따른다.
- 동료 호감도는 최대 Lv.5로 늘렸다.
  - 치하라 쇼: `maxCoopLevel` 5, 랭크업 이벤트 Lv.3·4 추가(필요 포인트 2, 대사 미지정)
  - 레벨업 판정이 최대 레벨 하나 전에서 멈추던 문제도 고쳤다(`CooperationManager.TryGetNextRankEvent`).

## 2. 화면 표시

- 아직 만나지 않은 대상(적 격퇴 0회, 동료 호감도 Lv.0)은 실루엣 + "???"로 나온다.
- 대상을 고르면 가장 최근에 열린 편부터 보여 준다.
- 잠긴 편은 조건을 보여 준다: "격퇴 6회에 열립니다 (현재 4회)" / "호감도 Lv.3에 열립니다".

## 3. 글 작성 (JSON)

대화 JSON처럼 대상마다 파일 하나를 쓰고, `EnemyData` / `CoopCharData`의 **`materialJson`** 칸에 연결한다. 해금 조건은 파일에 적지 않는다(위 규칙으로 계산).

- 위치: `Assets/Data/Materials/enemy/`, `Assets/Data/Materials/companion/`
- 형식:

```json
{
  "id": "dimensional_horror",
  "entries": [
    { "title": "관측 기록 1", "body": "본문. 줄바꿈은 \\n, 강조는 <b>굵게</b> 같은 TMP 서식을 쓸 수 있다." },
    { "title": "관측 기록 2", "body": "…" },
    { "title": "관측 기록 3", "body": "…" },
    { "title": "관측 기록 4", "body": "…" },
    { "title": "관측 기록 5", "body": "…" }
  ]
}
```

- `entries` 순서가 1~5편이다. 5편보다 적으면 빈 편은 "아직 기록이 작성되지 않았습니다."로 나온다.
- 지금 연결된 파일은 둘 다 형식 확인용이고, 본문은 "(작성 예정)"이다.
  - `enemy/dimensional_horror.json` (차원의 공포)
  - `companion/cp_01.json` (치하라 쇼)

## 4. 구현

- 규칙·파서: `MaterialArchive` (`Assets/Scripts/Material/`)
- 화면: `MaterialView`, `MaterialSubjectCell` (로비 `MainCanvas/MaterialView`)
  - 로비 "마테리얼" 버튼이 연다.
  - 데모 테스트용으로 시설은 기본 해금이다(`InformationBroker.asset`).
- 아트: `Assets/Art/Lobby/Material` (원본 `ArtDirection/MaterialMockup/Extracted`, 좌표는 그 layout.json)
  - 분류 탭(적/동료), 탭에 따라 바뀌는 필터(등급 / 소속), 4열 격자(기록 점 5개)
  - 대상 머리(그림·등급 또는 소속 배지·진행 칸 5개), 01~05 색인 탭(`MaterialEntryTab`), 클립 달린 서류 판(문서 번호·제목·괘선·본문 스크롤·출처)
  - 뒤로 버튼·체크박스·등급 배지·기록 점·스크롤 막대는 무기고·훈련장 조각을 재사용한다.
- 동료 초상 크롭은 캐릭터마다 다르다. `CoopCharData.faceFocus / faceZoom`으로 맞추고, 마테리얼과 훈련장 초상 칸이 같이 쓴다. 이카루스 군: (0.45, 0.72) × 1.6

## 5. 인연 시작 · 이벤트 동료

- **처음 합류하면 인연이 생긴다:** 호감도 Lv.0 → Lv.1.
  - 성소든 이벤트든 같다(`CooperationManager.SelectChar`).
  - 예전에는 Lv.0 → 1로 올리는 코드가 디버그 함수에만 있어서, 정상 플레이로는 호감도가 오르지 않았다.
- 이벤트 동료(이카루스 군)도 같은 인연 체계를 쓴다.
  - `maxCoopLevel` 5, 랭크업 이벤트 Lv.1~4(필요 포인트 2, 대사 미지정)
  - 마테리얼 `companion/cp_event_01.json` (본문 작성 예정)
- 화면 아트 요청서: `ArtDirection/MaterialMockup/LAYOUT_BRIEF.md`
