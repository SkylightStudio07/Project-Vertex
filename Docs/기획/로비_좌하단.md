# 로비 좌하단 — 대사 · 스토리 · 아카이브 (초안)

명일방주 로비 좌하단(비서 대사 / 배너 / 친구·파일) 자리를 우리 식으로 채운다. 가챠가 없으니 배너 자리에는 **지금 진행 중인 스토리**를 띄운다.

```
┌──────────────────────────────────────┐
│ 치하라 쇼                              │  ① 대사 박스
│ 비 오는 날엔 총기 손질이 두 배야. …     │
└──────────────────────────────────────┘
┌──────────────────────────┐ ┌─────────┐
│ STORY   CH.2-1            │ │ 아카이브 │  ③
│ 영원하지 않기에            │ ├─────────┤
│ 빛나는 것들   [썸네일]     │ │ 동료     │  ④
│ ▸ 다음: 1막 보스 격파      │ └─────────┘
└──────────────────────────┘
  ② 스토리 카드
```

## ① 대사 박스

- 로비에 서 있는 캐릭터(= **비서**)의 대사. 이름 + 1~3줄.
- 비서는 플레이어 또는 **합류한 동료** 중 하나. ④에서 바꾼다.
- 대사가 나오는 때:

| 때 | 예 |
|---|---|
| 로비 입장 | 시간대 인사(아침·낮·저녁·심야) |
| 캐릭터를 누름 | 잡담 풀에서 하나 (같은 줄 연속 금지) |
| 런에서 돌아옴 | 클리어 / 전멸 / 중도 포기 반응 |
| 스토리 진행 | 막 보스 첫 격파, 새 동료 합류 직후 한 번 |
| 호감도 | 레벨이 오를수록 잡담 풀이 열림 |

- 글은 마테리얼처럼 캐릭터마다 JSON 한 파일 (`Assets/Data/Dialogue/lobby/<id>.json`). 조건은 파일 태그(`greet_morning`, `idle`, `run_clear`, `bond3` …)로 단다.
- 글자는 한 글자씩 찍히고, 누르면 끝까지 바로 보인다.

## ② 스토리 카드 (배너 자리)

- **지금 진행 중인 챕터** 하나를 보여 준다. 블루 아카이브식 번호 + 시적 제목.
  - 예: `CH.1-1 아직 이름 없는 내일에게` / `CH.1-2 빗속에서 건넨 손` / `CH.2-1 영원하지 않기에 빛나는 것들`
- 카드 구성: `STORY` 라벨, 챕터 번호, 제목(2줄까지), 챕터 썸네일, **다음 목표 한 줄**.
- 다음 목표는 진행 조건에서 뽑는다: "1막 보스 격파" / "스토리 의뢰 「블랙박스 회수」 완료" / "치하라 쇼 합류".
- 누르면: 목표가 의뢰면 **의뢰 게시판**(해당 의뢰 선택), 아니면 **탐색 개시**로.
- 챕터를 다 끝냈을 때: 카드가 한 번 "CLEAR" 연출 후 다음 챕터로 넘어간다.

### 데이터 (`StoryChapterData` SO, 새로 만듦)

| 칸 | 설명 |
|---|---|
| `chapterId` | "2-1". 막 번호-편 번호 |
| `title` | 제목 |
| `thumbnail` | 카드 오른쪽 그림 |
| `objectives` | 목표 목록. 종류(막 보스 격파 / 의뢰 완료 / 동료 합류) + 대상. 순서대로 하나씩 보여 줌 |

- 진행 판정은 이미 있는 이정표를 그대로 쓴다: `MetaProgress` 이정표(`boss:act1` 등), `QuestManager` 완료 기록, `CooperationManager` 합류. **새 저장값이 필요 없다.**
- 현재 챕터 = 목표가 하나라도 남은 첫 챕터.

## ③ 아카이브 = 지금의 마테리얼

- 지금 메뉴 05번 **마테리얼** 화면을 그대로 옮긴다. 이름만 "아카이브 / ARCHIVES".
- 메뉴 05번 자리는 **상점**이 된다 (탈린으로 파츠·선물·무색 카드). 재화 바 탈린 (+)도 상점으로.

## ④ 동료

- 명방 "친구" 자리. **합류한 동료** 목록 → 비서 지정, 호감도·선물. 블루 아카이브처럼 시설(베이스캠프)과는 별개 탭이다.
- 화면은 나중에 만든다. 로비 좌하단을 먼저 끝내고, 그동안 버튼은 자리만 둔다.

## 배치 · 연출

- 캔버스 1920×1080 기준 대략: 대사 박스 x 40–760 / y 760–880, 스토리 카드 x 40–560 / y 900–1050, 작은 버튼 x 575–760 (두 칸).
- 지금 좌하단의 `DialogBox` · `Txt_BaseCampLabel` · `Txt_Dialog`를 대체한다. `Frame_BottomLeft` 장식은 겹치면 뺀다.
- 오른쪽 메뉴처럼 **기울기**를 준다. 좌우를 뒤집어 왼쪽 바깥이 가깝게 (Base Angle Y 약 -10).
- 색: 회백 판 + 먹색 글자 + 청록 포인트. 스토리 카드만 썸네일이 들어가 조금 무겁게.
- 그림자 오른쪽 아래 (메뉴 버튼과 같게).

## 아트 요청 (아스트라)

- 목업 1장: 지금 로비 캡처 위에 좌하단만.
- 조각: 대사 박스 판, 스토리 카드 판(썸네일 마스크 포함), 작은 버튼 판 2종(아카이브·④), 아이콘 2개, 챕터 썸네일 견본 1장.

## 순서

1. 아스트라 브리프
2. `StoryChapterData` + 진행 판정 + 카드 표시 (그림 없이 먼저)
3. 대사 JSON 형식 + 비서 대사 박스
4. 마테리얼 → 아카이브 이동, 메뉴 05 → 상점 자리만
5. 아트 조각 받으면 조립
