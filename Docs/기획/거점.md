# 거점

로비의 **베이스캠프(모닥불)** 자리를 대신하는 기지 화면. 페르소나 3 포터블처럼 구역을 골라 들어가면, 합류한 동료들이 **작게 각자 정해진 자리에서** 하던 일을 하고 있다. 누르면 말을 건다. 동료는 **돌아다니지 않는다.**
가구 배치 · 쾌적도 · 자유 꾸미기는 **하지 않는다**.

**분위기:** 쇼룸이 아니라 **버려진 시설을 고쳐 쓰는 생존자 전초기지.** 밤 · 눈보라, 실내는 어둡고 군데군데 따뜻한 작업등. 낡고 수리한 흔적, 사람이 사는 잡동사니.

**화면 구도:** 페르소나 3 포터블의 기숙사(반쯤 내려다보는 쿼터뷰)를 **정면뷰**로 바꾼 것. 방 한 칸을 정면에서 넓게 보여 주고, 동료는 그 안에 **작게(전신 키 약 220~300px)** 여러 명이 선다.
합류 동료가 많다(1막만 5명). v2 목업처럼 한두 명을 크게 세우는 구도는 쓰지 않는다. v2에서는 **UI만** 가져온다. 그림체는 SD가 아니라 지금 캐릭터 비율 그대로 줄인 전신.

## 1. 한눈에

| 항목 | 규칙 |
|---|---|
| 들어가기 | 로비 메인의 `02 베이스캠프` 카드 → `02 거점`으로 이름을 바꾸고 이 화면을 연다. 모닥불 디오라마는 쓰지 않는다 |
| 이동 | 플레이어는 걷지 않는다. 화면 아래 **구역 탭**으로 바로 넘어간다(페르소나 빠른 이동). 동료도 자리에서 움직이지 않는다(가벼운 숨쉬기 · 흔들림만) |
| 구역 | 처음엔 거주구 · 연구소 · 격납고 · 전진기지. 기지 개발 레벨 · 의뢰 완료로 **구역이 더 열린다**(아래 2-1). 구역마다 2D 배경 한 장 + 앞뒤 시차 레이어 |
| 동료 | 합류한 적 있는 동료(호감도 Lv.1 이상)만 나온다. 구역마다 정해진 **자리(Spot)**에서 **거점 전용 스탠딩**으로 각자 하던 일을 하고 있다 |
| 누르면 | 한 줄 잡담 + 호감도 소량(하루 1회 제한은 런 1회 기준). 조건이 맞는 대화 이벤트가 있으면 말풍선 `!` → 대화 씬 |
| 시설 | 구역 안 **시설 지점**(문 · 단말기 · 담당자)을 누르면 기존 시설 화면을 연다. 로비 메인 메뉴 버튼도 그대로 남긴다(바로 가기) |

## 2. 구역

| 구역 | 시설 지점 → 여는 화면 | 담당 | 배경 방향 |
|---|---|---|---|
| 거주구 | — (동료 대화 중심) | — | 침상 · 휴게 테이블 · 창밖 설원. 가장 많은 동료 자리 |
| 연구소 | 아카이브(적 기록 · 동료 기록), 훈련장 | 기록관 담당 | 자료 서가 · 분석 단말 · 시뮬레이션 부스 |
| 격납고 | 무기고(강화 · 카드) | 정비 담당 | 차량 · 정비 리프트 · 무기 거치대 |
| 전진기지 | 탐색 개시(출격 준비), 의뢰, 상점(보급) | 보급 담당 | 작전 지도 테이블 · 보급 상자 · 출입 게이트 |

### 2-1. 구역 해금

| 조건 | 예 |
|---|---|
| 기지 개발 레벨(`BASE DEV Lv`) | Lv.n에서 구역 추가 · 기존 구역 확장(새 자리 · 새 시설 지점) |
| 의뢰 완료(`questId`) | 용접공 구출 → **옥상** 해금 |

- 잠긴 구역은 탭에 자물쇠 + 조건 한 줄(`의뢰 「…」 완료 시 개방`)로 보인다. 처음 열릴 때 짧은 개방 연출.
- 동료 자리도 구역과 같이 열린다(옥상이 열려야 옥상 자리가 생긴다).

동료 탭(`CompanionView`)은 거주구에서도 열 수 있게 한다(동료를 누른 상태에서 "기록 보기").

## 3. 동료 자리

- 동료마다 **갈 수 있는 자리 목록**을 데이터로 둔다(구역 + 자리 id + 포즈 스프라이트 + 하는 일 문구).
- 로비에 돌아올 때(런 종료) 자리 목록에서 하나를 뽑는다. 같은 자리에 둘이 겹치지 않게 한다.
- 구역 하나에 자리 **5~8개**(거주구는 더 많이). 동료 수가 자리보다 많으면 다른 구역으로 넘긴다.
- 동료 그림이 작으므로 **마우스 올림 이름표**가 이름 확인의 주 수단이다. 평소에는 이름을 띄우지 않는다.
- 자리 하나에는 **기준점(발밑) + 크기 + 앞/뒤 레이어**만 정한다. 배경이 바뀌어도 자리 좌표만 고치면 된다.
- 포즈는 **거점 전용 스탠딩**(자리마다 하나). 아직 없으면 휴식 캠프 데이터로 대신한다: `CoopCharData.campSprite`(없으면 `standingSprite` → `charImage`), `campActivity`, `campLines`.

| 동료 | 거점 모습 (안) |
|---|---|
| 알레시아 | 창을 닦고 있다 |
| 치하라 쇼 | 조용히 벽에 등을 기대고 있다 |
| 알케미스트 | 실험 도구를 잔뜩 늘어놓고 복작복작 |
| 카리나 · 이카루스 | 미정 |

- 이벤트 동료(이카루스 · 카리나)도 합류 기록이 있으면 나온다.

## 4. 구현

| 무엇 | 어디 |
|---|---|
| 화면 | `BaseCampView` (`Assets/Scripts/Lobby/Base/`) — Lobby 씬 `MainCanvas/BaseCampView`. 로비 `02 거점` 카드가 `Open()` |
| 구역 | `BaseZoneData` 에셋 5개 (`Assets/Data/BaseCamp/Zone_0n_*.asset`): 이름 · 배경 · 해금(개발 레벨 / 의뢰 id) · 동료 자리 · 시설 표지 · 확장 잠김 |
| 동료 자리 | `CoopCharData.baseSpots` (구역 id + 자리 id + 포즈 + 하는 일). 비우면 빈 자리 아무 데나, 포즈는 `campSprite` → `standingSprite` → `charImage` |
| UI 조각 | `Assets/Resources/BaseCamp/` (ArtDirection/BaseCampMockup/Extracted) |
| 배경 (초안) | `Assets/Art/Lobby/BaseCamp/BG_*.png` — NAI. 프롬프트 `아트 프롬프트/아트/[Background][Base] *.txt` |
| 동료 포즈 · 소품 (초안) | `Assets/Art/Lobby/BaseCamp/Companions/BP_*.png`, `Props/Prop_*.png` — 프롬프트 `[Base] 11_Companion_Poses.txt`, `[Props][Base] 12_Base_Props.txt` |
| 소품 · 조명 | `BaseZoneData.props`(발밑 · 높이), `lightX`(주 광원 x), `characterTint` · `propTint`. 동료와 소품은 발밑 y로 함께 앞뒤 정렬 |
| 그림자 | `BaseCampView.BuildShadow`: 닿는 곳의 진한 타원 + 광원 반대쪽으로 늘어진 옅은 타원 (`Resources/BaseCamp/Shadow_Soft`) |
| 움직이는 효과 | `BaseZoneData.snow` · `lights` · `faultyRoomDim` → `BaseZoneFx.cs`. 거주구: 창밖 눈, 연구소: 부스 조명 깜빡임 · 석유등 일렁임, 격납고: 셔터 틈 눈 + 안으로 불어 드는 눈, 전진기지: 문틈 눈바람 · 경고등 · 무전기 표시등. 눈 가림은 `Art/Lobby/BaseCamp/Masks` (배경을 바꾸면 다시 그린다) |
| 환경음 | `BaseZoneData.ambience` · `ambienceVolume` · `ambienceCutoff`. `Resources/Audio/Ambience/`: 거주구 난로 (`amb_stove_quarters`), 연구소 형광등 (`amb_lab_hum`), 격납고 바람 (`amb_wind_hangar`), 전진기지는 바람을 먹먹하게 줄여서. 시설 화면이 위를 덮거나 거점을 닫으면 줄어든다 |

- 좌표는 전부 1920×1080 · 왼쪽 위 원점. 배경이 보이는 띠는 y 110~962.
- 자리: `feet`(발밑) · `height`(전신 키, 초안 배경에서는 가구에 맞춰 375~440px) · `mirror`. 앉은 포즈는 `BaseSpotPose.heightScale`, 떠 있는 드론은 `hover`. 뒷줄은 발밑이 위(작은 y) · 키를 작게. 앞줄(큰 y)이 앞에 그려진다.
- 자리는 `LobbyManager.CompletedRunCount`가 바뀔 때만 다시 뽑는다(같은 로비 방문 동안 고정).
- 옥상 해금 의뢰 id는 임시로 `rescue_welder` (의뢰 데이터가 생기면 맞춘다).

## 5. 화면 흐름

```
로비 메인 → 02 거점
   ├ 구역 탭: 거주구 | 연구소 | 격납고 | 전진기지   (마지막 구역 기억)
   ├ 동료 누름 → 이름표 + 하는 일 + 잡담 (LobbyKeeperTalk 방식) / '!'면 대화 이벤트
   ├ 시설 지점 누름 → 기존 화면 (닫으면 거점으로 복귀)
   └ 뒤로 → 로비 메인
```

## 6. 범위 밖 (지금 안 함)

- 플레이어 · 동료가 걸어 다니기(동료는 런이 끝날 때 자리만 바뀐다)
- 가구 배치 · 쾌적도 · 선물
- 시간대(낮 / 밤) 변화 — 배경 2벌이 필요해서 나중에 검토. 기본은 밤

## 7. 확인 필요

- 호감도 소량 상승 수치와 제한(런 1회당 동료별 1회 안)
- 대화 이벤트(`!`) 조건: 호감도 레벨 도달 시 1회씩
- 개발 레벨별로 열리는 구역 · 확장 목록, 옥상 외 의뢰 해금 구역
- 동료별 거점 스탠딩 제작(자리 수만큼). 화면 키 220~300px로 줄여 써도 읽히는 실루엣 · 포즈
- 로비 메인 메뉴의 무기고 · 의뢰 · 상점 · 훈련장 버튼을 남길지(지금은 남김 — 바로 가기)
