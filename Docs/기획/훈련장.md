# 훈련장

로비 시설 06. 지금까지 쌓은 기록(격퇴한 적, 얻은 카드, 동료 호감도)으로 원하는 조합을 꾸려 원하는 적과 싸워 보는 곳이다. 성장은 없고 연습과 실험만 한다.

## 1. 한눈에

| 항목 | 규칙 |
|---|---|
| 상대 | **첫 마테리얼이 열린 적**만 고를 수 있다(일반 3 · 엘리트 2 · 보스 1회 격퇴). 조우 안의 모든 적이 열려야 한다. 일반·엘리트·**보스 포함**. 자세한 규칙은 [마테리얼](마테리얼.md) |
| 덱 | 런에서 **한 번이라도 얻은 카드**와 시작 덱 카드로 자유 구성. 장수와 같은 카드 수 **제한 없음**(슬더스 사서덱처럼). 최소 1장 |
| 동료 | 동료마다 정한 **호감도 레벨 이상**(`CoopCharData.trainingRequiredLevel`)이어야 데려갈 수 있다. **최대 3명**(플레이어 포함 4인) |
| 시작 상태 | 체력 가득, 아이템·축복 없음, 골드 무관 |
| 보상 | 없음. 경험치, 골드, 카드, 호감도 모두 안 준다. 노가다로 하는 성장은 일반 런에만 둔다 |
| 기록 | 훈련장 전투의 격퇴는 **격퇴 기록에 넣지 않는다**(실전 기록만 센다) |
| 종료 | 이기든 지든 결과 화면 → "기지로 귀환" → 로비 |

## 2. 흐름

```
로비 → 훈련장
   ├ 상대 고르기   (조우 목록: 잠긴 조우는 "격퇴 n / 필요 수"로 표시)
   ├ 동료 고르기   (호감도 조건 미달은 잠김 + "호감도 Lv.n 필요")
   ├ 덱 구성       (기본값 = 시작 덱. 해금 카드 목록에서 +/− )
   └ 출격 → 씬 전환 막 → 전투 씬
           → (보스면 등장 배너·대사) → 전투
           → 결과 화면 "훈련 완료 / 훈련 종료" → 기지로 귀환
```

## 3. 기록 (영구 저장)

훈련장 조건에 쓰는 값들은 지금까지 런이 끝나면 사라졌다. `PlayerRecord` 하나에 모아 저장한다(PlayerPrefs JSON).

| 기록 | 쌓이는 시점 | 키 |
|---|---|---|
| 적 격퇴 수 | 실전 전투에서 적이 쓰러질 때 | EnemyData 에셋 이름 |
| 얻은 카드 | 런 중 플레이어 덱에 카드가 들어올 때(보상, 상점, 합류, 이벤트) | CardData 에셋 이름 |
| 동료 호감도 | 레벨·포인트가 바뀔 때 | charID |

- 시작 덱 카드는 기록과 상관없이 항상 해금이다.
- 동료 호감도는 이전에는 게임을 끄면 0으로 돌아갔다. 이번에 같이 저장한다.

## 4. 마테리얼과의 연동 (다음 단계)

마테리얼(시설 05)은 이 기록을 보여 주는 **작전 기록 / 도감**으로 만든다.

- 적: 격퇴 수에 따라 정보가 열린다.
  - 1회: 이름·그림
  - 2회: 행동 패턴
  - 3회: "분석 완료", 훈련장 상대로 등록
- 동료: 호감도와 훈련장 동행 가능 여부.
- 훈련장 최단 턴 기록 표시(선택).

마테리얼은 구현됐다 → [마테리얼](마테리얼.md).

## 5. 구현 메모

- `TrainingSession` (static): 고른 조우, 덱, 동료. 로비에서 채우고 전투 씬이 읽는다. 귀환할 때 비운다.
- `GameManager.InitializeRun`: 훈련 중이면 맵·축복·의뢰를 건너뛴다. 덱과 동료(합류 카드·보상 풀 없이 자리만)를 세팅하고 바로 전투한다. 보스면 등장 연출을 그대로 쓴다.
- 결과: `RewardsView`는 훈련 중이면 열리지 않는다. `RunClearView`가 승리·패배 모두 받는다.
- 로비 화면: `TrainingView` (로비 `MainCanvas/TrainingView`). 무기고처럼 훈련장 버튼이 `SetActive(true)`로 연다. 1672×941 판을 1.15배로 놓는다.
  - **메인:**
    - 상대 목록(`TrainingTargetRow`: 썸네일 크롭, 잠김이면 실루엣, 종류 배지, 격퇴 점 3개)
    - 선택한 상대 그림 + "분석 완료 · 격퇴 n회"
    - 동료 초상 카드(`TrainingCompanionCard`, 가로 스크롤)
    - 덱 요약(`TrainingDeckRow`), 덱 편집, 시작 덱으로 되돌리기, 출격
  - **덱 편집:**
    - 필터: 종류·코스트·소속(`TrainingToggle`)
    - 해금 카드 격자: 무기고 `CardCatalogEntry` 재사용 + ×n 배지. 미획득은 "???" 칸
    - 현재 덱 −/+: 마지막 1장은 못 뺀다
  - **동료 편성:**
    - 메인 동행 3칸 고정(빈 칸 = 점선 + "동료 편성", 구역 오른쪽 위 "편성 →")
    - 편성 페이지: 6열 초상 격자(`TrainingPortraitCell`, 마우스를 올리면 오른쪽 상세), 필터(동행 가능만 / 소속 1~3막·이벤트)
    - 선택한 동료: 큰 초상, 소속·고유색 선, 호감도 칸, 합류 카드
    - 동행 큰 칸 3개(`TrainingPartySlot`, × 빼기)
  - 아트: `Assets/Art/Lobby/Training` (v2 조각은 `/v2`, 원본 `Extracted_v2`) (원본 `ArtDirection/TrainingMockup/Extracted`). 뒤로 버튼·체크박스·카드 칸은 무기고 조각을 재사용한다.

## 6. 미정 / 나중에

- **시설 해금:** 데모는 테스트를 위해 기본 해금이다(`TrainingGround.asset` defaultActive 1). 원래 조건인 런 완료 횟수(`LobbyManager.completedRunCount`)는 아직 저장되지 않고 올라가지도 않는다. 정식 해금 조건을 쓰려면 이것부터 고쳐야 한다.
- **동료별 조건:** `trainingRequiredLevel`은 캐릭터마다 따로 정한다(기본 Lv.2). 이카루스 군은 호감도 체계가 없어 0으로 해 뒀다.
- 훈련장 레벨(Lv.1) 업그레이드로 무엇이 늘어나는지. 예: 시작 체력 조절, 적 강화 옵션, 덱 프리셋 저장 칸.
- 덱 프리셋 저장.
- 훈련 기록(최단 턴, 최대 피해) 보관 위치.
