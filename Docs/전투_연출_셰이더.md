# 전투 연출 · 셰이더 정리

전투 화면의 "그림체 통일"과 분위기 연출이 어떻게 짜여 있는지, 어디서 값을 바꾸는지 정리한 문서.
새 적 · 동료 · 배경을 넣을 때 이 순서대로 보면 된다.

```
배경 그림 (BattleStageView)
 └ 분위기 층 (BattleAmbienceFx) ── 빛줄기 · 안개 · 빛 알갱이 · 꽃잎 · 점멸등 · 자리 빛 · 비네트
    └ 유닛 그림 (Image + UI/BattleUnit 셰이더) ── 외곽선 · 림 · 색 보정 · 위 조명
       └ 발밑 그림자 (BattleUnitLook)
          └ 공격 연출 (땅 파임 GroundImpactFx · 총구 섬광 등)
```

---

## 1. 유닛 셰이더 `UI/BattleUnit`

파일 `Assets/Shaders/UI-BattleUnit.shader`. 주인공 · 동료 · 적 그림 전부에 같은 처리를 입혀서, 출처(생성 모델 · 작가)가 다른 그림들의 화풍 차이를 줄인다.
uGUI `Image`용 셰이더라 스텐실 · RectMask2D · 알파 클립을 그대로 지원한다.

### 처리 순서 (fragment)

| 단계 | 하는 일 | 속성 |
|---|---|---|
| 1. 안쪽 외곽선 | 주변 8방향 중 가장 투명한 값과의 차로 가장자리를 찾아 먹색을 칠한다. **화면 픽셀 기준 두께**(`fwidth`)라 그림 해상도 · 크기와 상관없이 모두 같은 굵기 | `_OutlineColor`(a = 진하기) · `_OutlinePx` |
| 2. 림라이트 | 빛이 오는 쪽으로 조금 옮긴 자리가 투명하면 그 가장자리가 빛을 받는 것으로 본다 | `_RimColor`(a = 세기) · `_RimPx` · `_RimDir`(화면 기준 빛 방향, x 오른쪽 · y 위) |
| 3. 색 보정 | 채도 → 색 곱하기 → 밝기 순. 배경 팔레트 쪽으로 당긴다 | `_Saturation` · `_Grade` · `_Brightness` |
| 3-1. 발광 보존 | 밝고 채도 높은 픽셀(총구 섬광 · 불꽃 · 발광 눈)은 3의 보정에서 뺀다. 이게 없으면 적 채도를 낮출 때 섬광까지 회색이 됐다 | `_KeepGlow` |
| 4. 위 조명 | 그림의 **보이는** 아래 끝(0) → 위 끝(1) 기준으로 위는 더하고 아래는 어둡게. 2.5D 무대 조명 느낌 | `_TopLight`(a = 세기) · `_TopFalloff` · `_BottomShade` · `_VRange` |

- `_VRange`는 그림마다 투명 여백이 달라서 **유닛마다 따로** 넣어야 한다 → `BattleUnitLook`이 유닛별 머티리얼 복사본을 만들고, 시트 프레임이 바뀔 때마다 갱신한다.
- 노멀맵 조명은 쓰지 않는다 (생성 그림에 노멀맵이 없어서). 림 + 위 조명으로 대신한다.

### 기본 머티리얼 `Assets/Resources/BattleUnit/`

| | 아군 `BattleUnit_Ally` | 적 `BattleUnit_Enemy` |
|---|---|---|
| 외곽선 | 1.5px · 먹색 0.7 | 1.5px · 먹색 0.7 |
| 림 | 3.5px · 0.6 | 3.5px · 0.6 |
| 채도 | 0.95 | **0.55** (적은 배경 쪽으로 가라앉힌다) |
| 밝기 | 1.0 | 1.04 |

이 값은 **배경이 없을 때의 기본값**이다. 실제 전투에서는 배경(2절)이 자기 값으로 덮어쓴 복사본을 쓴다. 원본 머티리얼 에셋은 런타임에 바뀌지 않는다.

## 2. 배경 · 조명 `BattleStageData` / `BattleStageView`

- 데이터: `Assets/Data/BattleStages/*.asset` (배경 한 장 = 에셋 하나)
- 붙는 곳: 전투 씬 `Canvas/Background`의 `BattleStageView` (`stages` 목록)
- 전투가 시작될 때(`OnBattleStarted`) 배경을 하나 고르고 → 배경 그림 교체 → 유닛 머티리얼 값 덮어쓰기 → 분위기 층 갱신.

### 어떤 배경이 고르는가

1. **전용 배경**: 이번 전투 적 중 하나라도 `featuredEnemies`에 있으면 그 배경 (엘리트 · 보스용, 훈련장 포함)
2. **일반 배경**: 전용 배경이 아닌 것 중 `minFloor`~`maxFloor`(화면 기준 층)에 맞는 것. 여러 개면 층 · 노드 번호로 고정 선택 (같은 노드 다시 들어가면 같은 배경)
3. 층에 맞는 게 없으면 일반 배경 아무거나

### 현재 배경

| 에셋 | 쓰는 곳 | 테마 |
|---|---|---|
| `Act1_Stage01_SpiderLilyGarden` | 일반 1~5층 | 흐린 밤 · 차가운 달빛 · 붉은 점멸등 |
| `Act1_Stage02_Dusk` | 일반 6~10층 | 더 어두운 잿빛 밤 · 달무리 약한 빛줄기 · 안개 3겹 |
| `Act1_Stage03_MoonField` | 일반 11~15층 | 보름달 · 강한 달빛 줄기 · 빛 알갱이 · 꽃잎 많이 |
| `Act1_Elite_HunterKiller_Bunker` | 헌터킬러 | 무너진 벙커 · 천장 틈 빛줄기 · 먼지 · 양쪽 경고등 |
| `Act1_Boss_DimensionalHorror_Rift` | 차원의 공포 | 보랏빛 균열 · 마젠타 림 · 파편. **적 보정은 거의 중립** (보스 몸이 배경색에 묻혀서) |
| `Act1_Boss_BigThree_MoonCamp` | 빅 쓰리 | 보름달 캠프 · 달빛 림 · 랜턴 |

### 배경 에셋 항목

| 묶음 | 항목 | 설명 |
|---|---|---|
| 유닛 조명 | `lightFrom` · `rimColor` | 배경의 주광 방향 · 색 → 셰이더 `_RimDir` · `_RimColor` |
| | `allyGrade` · `allyBrightness` | 아군 색 곱하기 · 밝기 |
| | `enemyGrade` · `enemySaturation` · `enemyBrightness` | 적 (채도는 적만) |
| 위 조명 | `topLight` · `topFalloff` · `bottomShade` | → 셰이더 4단계 |
| | `spotlightColor` | 유닛 머리 위 은은한 스포트라이트 |
| 분위기 | `moteCount` · `moteColor` · `moteArea` | 떠다니는 빛 알갱이 |
| | `petalCount` · `petalColor` | 꽃잎 |
| | `lightShaft` · `shaftOrigin` · `shaftAngle` · `shaftSize` · `shaftColor` | 빛줄기 (위 끝 위치 · 기울기 · 크기) |
| | `fogColor` · `fogBands` | 낮은 안개 띠 (세로 위치 목록) |
| | `blinkLights` | 깜빡이는 작은 광원 (경고등 · 랜턴) |
| 무대 | `standPools` · `standPoolColor` | 유닛이 서는 바닥의 은은한 빛 |
| | `screenBottomShade` · `vignette` | 손패 뒤 아래쪽 어둡게 · 가장자리 어둡게 |
| | `hudDecorTint` | 밝은 배경용 HUD 흰 장식판을 어두운 배경에 맞춰 누른다 |
| 배치 | `partyOffset` | 아군 진형 중심 보정 (1920×1080 px). 바닥 높이가 다른 배경용 |

좌표는 전부 **화면 비율(0~1, 좌하단 원점)** 이라 해상도와 무관하다.

### 분위기 층 `BattleAmbienceFx`

- 파일 `Assets/Scripts/UI/BattleAmbienceFx.cs`, 씬 `Canvas/BattleAmbience` (배경 바로 위 · 유닛 아래).
- 그림은 전부 코드로 만든다 (추가 아트 없음). 가산 블렌드가 필요한 빛은 `Assets/Art/Backgrounds/BattleAmbience_Additive.mat` (`UI/Additive` 셰이더).
- **절제가 핵심.** 알갱이 · 꽃잎이 많아지면 바로 싸구려가 된다. 기본값은 적게 두고, 밝은 배경(보름달)에서만 늘린다.

## 3. 유닛 룩 `BattleUnitLook`

파일 `Assets/Scripts/UI/BattleUnitLook.cs`. `PartyView`(아군) · `EnemyView`(적)가 그림을 정할 때 `Apply(image, side)`로 붙인다.

- 유닛마다 머티리얼 복사본 (위 조명 `_VRange`가 그림마다 달라서)
- **발밑 그림자**: 보이는 그림(스프라이트 메시)의 아래 끝에 납작한 타원. 폭 = max(그림 폭, 그림 높이×0.55)×0.95, 먹색 0.8 (Linear 색 공간이라 눈에는 더 옅게 보인다). 시트 애니메이션 · 돌진 중에도 발을 따라간다
- `TryVisibleFeetWorld` — 그림마다 다른 투명 여백을 무시한 실제 발끝 위치. 진형 배치 · 적 체력바 정렬에 쓴다

## 4. 배치

| 대상 | 방식 | 값 |
|---|---|---|
| 아군 진형 | 인원수별 자리(1 가운데 · 2 위아래 · 3 삼각 · 4 마름모), 발끝 기준 정렬, 아래쪽이 앞에 그려짐 | `PartyView` `formationSpread` · `formationCenterOffset` |
| 아군 높이 | 적이 서 있는 바닥선 평균에 맞춘다 + 배경 `partyOffset` | `PartyView.matchEnemyGround` · `enemyGroundOffsetY` |
| 적 자리 | 마리 수별 슬롯 + 적별 보정 | `EnemyZoneView` 프리셋 · `EnemyData.slotOffset` |
| 적 크기 | 그림 여백이 제각각이라 적마다 | `EnemyData.spriteScale` |
| 적 체력바 | 보이는 몸 가운데로 가로 정렬 후 보정 | `EnemyData.hpBarOffset` |
| 화면 끝 보스 | 슬롯 대신 화면 좌표, 인텐트 · 체력바는 그림 안 기준점 | `useScreenRect` · `screenRect` · `intentAnchor` · `hpBarAnchor` |

## 5. 공격 연출

### 피격 타이밍 · 순서 (`BattleManager`)

- 공격 시트가 있는 적은 전진(0.2초) 뒤 **0.45초 더** 기다렸다가 피해를 준다 — 휘두르거나 쏘는 순간에 맞추려고. `_animatedAttackHitDelay`
- 공격 모션(프레임 수 ÷ fps, 보통 약 2초)이 **끝나야** 다음 적이 행동한다. `_waitForAttackMotion`
- ⚠ 씬(`DevelopScene - Phase 3`)에 저장된 값이 코드 기본값보다 우선한다. 바꿀 때는 인스펙터에서.

### 땅 파임 `GroundImpactFx`

- 파일 `Assets/Scripts/UI/GroundImpactFx.cs`, 그림 `Assets/Resources/GroundImpact/` (구덩이 1종 · 먼지 8프레임 · 돌 조각 6종). 그림이 없으면 코드 도형으로 대체.
- 적 데이터 `groundFxShots` = (공격 프레임 번호, 탄착점) 쌍 목록. **총구마다** 자기 탄착점을 준다. 탄착점은 그려진 그림 기준 0~1 (좌하단 원점).
- 한 번에: 구덩이(0.7초 유지 후 사라짐) · 먼지 3덩이(배경 안개색 + 흙색) · 돌 조각 3개. 크기 `groundFxScale` (현재 0.4).
- 충격 고리는 지저분해서 뺐다.
- 현재: 헌터킬러(오른 포구 21/33/45 · 왼 포구 24/36/48), 스카웃 유닛(21/33/45에 두 총 연달아).
- 새 적에 넣을 때: 공격 시트에서 총구 섬광이 크게 터지는 프레임을 찾고 → 탄도 방향의 바닥을 탄착점으로.

### 그 밖

- 공격 시트 재생 `PoseSequencePlayer`: 공격 프레임 높이를 쉬는 그림의 **그려진 높이**에 맞춘다 (시트마다 여백 · 비율이 달라도 크기가 튀지 않게). 늘림 앵커 그림은 재생 중에만 가운데 앵커로 바꿨다 되돌린다.
- 적 시트는 **여백 0**으로 다시 잘라서 쓴다 (`idleSheetPadding` · `attackSheetPadding` = 0). idle · attack을 같은 영역으로 잘라야 공격 중 위치가 어긋나지 않는다.

## 6. 새 캐릭터 · 배경 넣을 때 체크

- [ ] 시트: idle · attack을 **같은 영역**으로 잘라 9열 시트, 4096 이하. 24fps(attack은 1.5배속 36fps)
- [ ] `spriteScale` / `battleScale`로 다른 유닛과 키 맞추기 (스크린샷 F12로 비교)
- [ ] 체력바 · 인텐트가 HUD(오른쪽 WEAPON · ENERGY)나 다른 적과 겹치지 않는지 → `hpBarOffset` · `slotOffset`
- [ ] 배경: 전용이면 `featuredEnemies`, 일반이면 층 범위. 아군 발이 바닥에 닿는지 → `partyOffset`
- [ ] 어두운 배경에서 적이 묻히면 `enemyBrightness` ↑ · `enemySaturation` ↑, 보스는 보정을 약하게
- [ ] 총을 쏘는 적이면 `groundFxShots` 고려
- [ ] 확인은 디버그 창(`Tools ▸ Vertex ▸ 디버그 패널`) "적 · 전투" 탭에서 그 조우로 바로 전투 시작
