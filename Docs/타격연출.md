# 타격 연출

전투에서 때리고 맞는 순간의 연출(타격감)을 모은다. 배너·컷인 같은 화면 연출은 [연출_목록.md](연출_목록.md)에 있다.

- 담당 스크립트: [`BattleImpactFx`](../Assets/Scripts/UI/BattleImpactFx.cs) (Phase 3 씬 `Canvas/BattleImpactFx`, 정렬 95)
- 입력은 막지 않는다. 모든 그래픽은 `raycastTarget` off.
- 세기·길이·색은 전부 인스펙터에서 조절한다.

## 1. 한눈에 보기

| 연출 | 언제 | 동작 |
|---|---|---|
| 피해 숫자 | 적·플레이어의 체력이 줄 때 | 맞은 쪽 위로 숫자가 커졌다 줄며 튀어 오르고, 위로 떠오르며 사라진다 |
| 막음 숫자 | 플레이어 방어도가 피해를 흡수할 때 | 플레이어 숫자 옆에 작은 "막음 N" |
| 히트스톱 | 체력이 줄 때 | 시간을 아주 잠깐 거의 멈춘다(`timeScale` 0.04) |
| 화면 흔들림 | 피해 8 이상 · 처치 · 플레이어 피격 | 전장만 흔든다. HUD·손패는 그대로 |
| 피격 비네트 | 플레이어가 맞을 때 | 화면 가장자리가 잠깐 붉어진다 |
| 효과음 | 위 상황마다 | 클립을 넣으면 재생 (지금은 비어 있음) |

기존 연출도 그대로 함께 나온다: 피격 파티클, 붉은 점멸(`HitFlash`), 방어도 방패 팝업, 적 사망 디졸브.

## 2. 피해 숫자

| 구분 | 크기 | 색 |
|---|---|---|
| 적 피해 | 46 | 먹색 #16181B |
| 큰 피해 (15 이상, `bigDamage`) | 64 | 청록 #0DB8F2 |
| 플레이어 피해 | 46 / 64 | 붉은색 (HP 계열) |
| 막음 | 29 | 회색 |

- 위치: 적은 그림(`EnemyView.SpriteRect`) 가운데와 윗변 사이, 플레이어는 `PlayerDraft` 위.
- 연타(0.35초 안에 연달아)는 좌우로 번갈아 비끼며 40씩 위로 쌓인다.
- 밝은 전장 위라 흰 글자 + 외곽선은 쓰지 않는다. Pretendard SDF 여백이 작아 TMP 외곽선이 제대로 그려지지 않는다.
- 적 방어도에 전부 막혀 체력이 안 줄면 숫자는 나오지 않는다(적은 흡수량 이벤트가 없음).

## 3. 히트스톱

```
길이 = min(0.11, 0.035 + 피해 × 0.003) 초 (실제 시간)
처치하면 + 0.05
```

- **마지막 적을 쓰러뜨리는 타격은 히트스톱을 걸지 않는다.** "작전 종료" 슬로모션(`BattleOperationFx.victorySlowScale`)이 대신한다.
- 다른 연출이 `timeScale`을 바꿔 둔 상태(슬로모션 중)면 걸지 않는다. 끝날 때도 자기가 건 값일 때만 1로 되돌린다.
- DOTween `SetUpdate(true)` 트윈(배너·숫자·흔들림)은 히트스톱 중에도 움직인다.

## 4. 화면 흔들림

| 항목 | 값 |
|---|---|
| 흔들림 대상 | `Background`, `EnemyArea`, `PlayerDraft`, `CoopDraft`, `PlayerShadow`, `PartyViewer`, `CoopTransform1~3` (`shakeTargetNames`) |
| 세기 | 기준 9px × (피해 ÷ 8), 최대 26px, 처치 ×1.3 |
| 길이 | 0.22초, 점점 약해짐 |

- 흔들림은 대상 위치에 **오프셋을 더했다 빼는** 방식이다. 대상의 다른 트윈(적 돌진·등장 연출)을 끄거나 위치를 덮어쓰지 않는다. 같은 대상에 새로 걸리면 이전 오프셋을 먼저 뺀다.

## 5. 피격 비네트

- 런타임에 만든 가장자리 그라디언트(가운데 투명)를 화면 전체에 깔고 색을 바꾼다.
- 색 #C71F24, 최대 알파 0.38 (피해가 작으면 0.6배). 0.06초에 켜지고 0.45초에 사라진다.

## 6. 효과음 (자리만)

| 칸 | 재생 |
|---|---|
| `hitClip` | 적 피격 |
| `heavyHitClip` | 큰 피해 (15 이상). 처치 클립이 없으면 처치에도 |
| `killClip` | 적 처치 |
| `playerHitClip` | 플레이어 피격 |
| `playerBlockClip` | 플레이어 방어도로 막음 |

- 재생할 때마다 음높이를 ±5% 흔든다.
- 카드별 사용 효과음은 `CardData.useSFX`(별도).
