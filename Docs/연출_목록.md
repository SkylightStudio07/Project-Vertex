# 연출 목록

게임에 들어간 연출(애니메이션·이펙트·UI 전환)을 어디서, 어떤 스크립트로 처리하는지 정리한 문서.
연출을 새로 넣거나 고치면 **이 문서도 같이 갱신**한다 (맨 아래 "추가 규칙" 참고).

## 0. 사용 패키지와 공용 도구

| 이름 | 용도 | 비고 |
|---|---|---|
| **DOTween** (`DG.Tweening`) | 거의 모든 트윈(이동·크기·페이드·시퀀스) | 트윈에는 `SetLink(gameObject)`를 붙여 오브젝트 파괴 시 같이 정리되게 한다 |
| **UIEffect** (`com.coffee.ui-effect` 5.11.7, [mob-sakai/UIEffect](https://github.com/mob-sakai/UIEffect)) | uGUI 셰이더 효과: 디졸브·불타기·빛 쓸기·색 필터 | 붙은 Graphic **하나에만** 적용되고 자식에는 번지지 않는다. 쓰는 셰이더 변형은 `Assets/ProjectSettings/UIEffectProjectSettings.asset`에 등록돼 있어야 빌드에서도 나온다 |
| 노이즈 텍스처 `Packages/com.coffee.ui-effect/UIEffectPresets/Textures/Transition-Noise01.png` | 디졸브/불타기 모양 | 비워 두면 디졸브가 "통째로 테두리 색"이 되므로 코드가 페이드로 대체한다 |
| [`UIDissolve`](../Assets/Scripts/UI/UIDissolve.cs) (정적 헬퍼) | 디졸브로 나타나기(`In`) / 여러 요소를 한꺼번에 디졸브·불타 사라지기(`Out`) | 글자(TMP)는 디졸브 대신 페이드. 테두리 기본색은 옅은 시안(`DefaultEdge`) |
| [`UIPanelTransition`](../Assets/Scripts/UI/UIPanelTransition.cs) (컴포넌트) | 패널이 켜질 때(OnEnable) 자동 등장 연출: Fade / 방향별 Slide / Scale / Dissolve | 여는 코드는 `SetActive(true)`만 하면 된다. 닫힘 연출(`Hide`)은 맵에서만 사용 |
| [`HoverScaleEffect`](../Assets/Scripts/UI/HoverScaleEffect.cs) (컴포넌트) | 마우스 올리면 확대. 옵션: `bringToFront`(앞으로 그리기), `keepInsideScreen`(화면 밖이면 안쪽으로) | 카드 목록·상점·상태 칩 등 공용 |
| [`SpeechBubble`](../Assets/Scripts/UI/SpeechBubble.cs) (컴포넌트) | 잠깐 떴다 사라지는 말풍선 | NPC 한마디용 |
| [`HitEffectSpawner`](../Assets/Scripts/Gameplay/HitEffectSpawner.cs) (정적 헬퍼) | 파티클 프리팹을 UI 앞(카메라 쪽)에 스폰 | 스프라이트 피벗이 발밑이어도 그림 중앙에 스폰 |
| [`ArtSource/`](../ArtSource) | SVG로 그린 이펙트/아이콘 원본과 생성 스크립트(Node + `@resvg/resvg-js`) | 결과 PNG는 `Assets/Art/...`에 넣는다 |

## 추가 규칙

- 연출을 추가·수정하면 해당 섹션 표에 한 줄 추가한다: **연출 이름 / 눈에 보이는 동작 / 스크립트(링크)와 조절용 인스펙터 값**.
- 여러 곳에서 쓸 연출은 공용 도구(0번 표)로 만들고, 새 공용 도구는 0번 표에 등록한다.
- UIEffect 필터를 새로 쓰면 빌드용 셰이더 변형이 `UIEffectProjectSettings.asset`에 추가됐는지 확인한다(에디터에서 한 번 재생하면 자동 등록).
- 연출 중에는 클릭 연타로 상태가 꼬이지 않게 입력을 막는다(`CanvasGroup.blocksRaycasts`/`interactable`). 단, 막는 범위는 연출 대상만 — 패널 전체를 막으면 뒤의 버튼이 눌린다.
- **반투명 어두운 색 주의:** 프로젝트가 Linear 색공간 + HDR 카메라라서 UI의 반투명 검정이 훨씬 옅게 섞인다(알파 0.8 검정 ≈ 40% 회색으로 보임). 어둡게 깔아야 하는 판·그림자는 가운데 알파를 1에 가깝게 잡는다.
- 색은 [`ArtDirection/ArtDirection.md`](../ArtDirection/ArtDirection.md) 기준: 오프화이트/검정 바탕, 시안은 테두리 포인트로만, 빨강은 HP·위험·강화 변경점에만.
