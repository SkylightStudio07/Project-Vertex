# 프로젝트 버텍스 (VERTEX) - 축복 시스템 & 마키나 친밀도 기획서

## 1. 기획 방향 및 내러티브 컨셉

> [!IMPORTANT]
> **핵심 내러티브 방향**: 외부의 정치/열강/역사적 설정은 배제하고, **버텍스 내부의 기묘한 시공간**, **끝없이 죽음을 반복하며 나아가는 주인공(방랑자)**, 그리고 **함께 걷는 동료들과의 관계성 및 내면의 상처**에 온전히 집중합니다. 1막 축복은 오직 **마키나(Machina)** 단독으로 구성됩니다.

### 1.1 마키나 (Machina) — '백색 피안화의 사신'
- **역할**: 버텍스 경계선, 소실과 재생의 틈새에서 피어난 백색 피안화의 정령이자 사신.
- **성격/톤앤매너**:
  - 차분하고 정적이며 초연하지만, 방랑자와 동료들이 짊어진 아픔을 조용히 지켜보고 보듬는 다정함.
  - "피어난 것은 언젠가 지고, 흩어진 것은 다시 모이기 마련... 그대들이 흘린 피는 헛되지 않단다."
- **내러티브 테마**:
  - **버텍스의 생리**: 시간이 왜곡되고 기억이 흩어지는 버텍스 내부의 고독과 침묵.
  - **주인공의 굴레**: 몇 번을 쓰러져도 붉은 피안화처럼 다시 눈을 뜨는 주인공의 영혼과 기억의 마모.
  - **동료들과의 유대**: 혼자였던 방랑자가 곁에 동료를 두고 함께 걸어올 때, 그 동료들이 품은 칼날과 상처를 마키나가 알아채는 순간들.
  - **진엔딩 복선**: 버텍스 가장 깊은 곳, 이 모든 왜곡이 시작된 근원에 닿기 위한 영혼의 자격.

## 2. 인카운터 및 다이얼로그 진행 플로우 (UI/UX)

```mermaid
flowchart TD
    A[성소/축복 노드 진입] --> B[조우 즉시: 마키나 친밀도 +0.5 적립]
    B --> C{이벤트 플래그 체크}
    C -- 동료 보유 / 특수 상태 -- D[플래그 우선 다이얼로그 선택]
    C -- 일반 상황 -- E[현재 친밀도 티어 조우 다이얼로그 선택]
    
    D --> F[말풍선에 마키나 대사 1줄 출력]
    E --> F
    
    F --> G[말풍선 하단에 플레이어 답변 캡슐 버튼 등장]
    G -->|플레이어 클릭| H{다음 대사 단계 있음?}
    H -- 있음 --> F
    H -- 대화 완료 --> I[답변 버튼 페이드아웃 & ChoicePillList 4개 슬라이드업]
    
    I --> J[1번: 덱 정화 - 카드 1장 제거]
    I --> K[2번: 기본 카드 연마 - 카드 2장 강화]
    I --> L[3번: 보급 지원 - 소모품 아이템 획득]
    I --> M[4번: 교감 - 마키나와 대화하기]
    
    J -->|선택| N[은총 적용 → 짧은 배웅 대사 → 맵 복귀]
    K -->|선택| N
    L -->|선택| N
    
    M -->|선택| O[친밀도 +1.0 적립 & 심화 스토리 대사 시퀀스 재생]
    O --> P[대화 종료 후 맵 복귀]
```

### 2.1 UI 연출 상세 (레퍼런스 이미지 스타일 반영)
1. **진입 시 대사 핑퐁**:
   - `DialogueBubble`에 마키나의 대사가 한 줄 출력됩니다.
   - 말풍선 바로 아래에 **플레이어 답변 캡슐 버튼**이 나타납니다 (예: `[방랑자 / 침묵] ...` 또는 `[대답] 여긴... 조용하네요.`).
   - 플레이어가 답변 버튼을 누르면, 마키나의 다음 대사로 이어집니다 (1~2회 핑퐁 후 마무리).
2. **선택지 전환**:
   - 다이얼로그가 끝나면 답변 버튼이 부드럽게 사라지고, 하단에 **4개의 가로형 알약(Choice Pill)**이 올라옵니다.
   - **1~3번**: 게임플레이에 도움을 주는 기존 축복 은총.
   - **4번 ([교감] 마키나와 대화하기)**: 신비로운 보라빛 테두리의 전용 선택지.
3. **4번 선택 시 심화 대화**:
   - 4번을 고르면 선택지 바가 닫히고, 말풍선에서 **현재 친밀도 티어에 따른 심화 대사(버텍스의 비밀, 주인공의 잃어버린 기억, 진엔딩 단서)**가 재생됩니다.
   - 완료 시 친밀도가 **+1.0 추가 적립**되고 축복 화면이 닫힙니다.

## 3. 마키나 친밀도(Affinity) 단계 및 대화 내러티브

친밀도는 런을 거듭해도 누적 저장되는 영구 메타 데이터(0.0부터 시작)입니다.

| 친밀도 구간 | 등급 | 관계 상태 | 대화 주제 및 내러티브 (버텍스 내부 & 주인공) |
| :---: | :---: | :--- | :--- |
| **0.0 ~ 1.5** | **Tier 0** | 낯선 발걸음 | **버텍스 경계의 안내자**<br>- 왜곡된 시공간에 발을 들인 주인공을 향한 담담한 관찰.<br>- *"눈을 떠라, 방랑자여. 이 꽃밭은 생과 사의 경계... 아직 그대의 발걸음이 완전히 멎지는 않았구나."* |
| **2.0 ~ 3.5** | **Tier 1** | 반복되는 호흡 | **기억의 마모와 피안화**<br>- 수없이 쓰러지고도 다시 일어나는 주인공의 지친 영혼을 걱정.<br>- *"몇 번을 흩어져도 다시 모이는구나. 하지만 조심하렴. 버텍스는 잊으려 하는 자의 기억부터 삼켜버린단다."* |
| **4.0 ~ 5.5** | **Tier 2** | 스며드는 신뢰 | **마키나의 존재와 버텍스의 침묵**<br>- 마키나가 왜 이 꽃밭에서 사신으로 남아 길을 안내하는지에 대한 고백.<br>- *"나 역시 한때는 무언가를 찾으려 안쪽으로 향했었지... 결국 남은 건 이 백색 꽃잎들뿐이었지만."* |
| **6.0 ~ 7.5** | **Tier 3** | 왜곡의 심층 | **버텍스 중심부의 진실**<br>- 버텍스가 단순한 공간이 아니라, 누군가의 멈춰버린 간절한 바람이 굳어버린 세계라는 암시.<br>- *"네가 나아가려는 중심부에는... 구원이 아닌, 가장 지독한 후회가 똬리를 틀고 있단다."* |
| **8.0 +** | **Tier 4** | 영혼의 맹약 | **진엔딩(True Ending) 루트의 열쇠**<br>- 주인공에게 버텍스의 닫힌 문을 부수고 영원한 굴레를 끊을 수 있는 단서/맹약 부여.<br>- *"이제야 네 눈에서 망설임이 사라졌구나. 끝까지 가보렴. 내가 마지막 순간까지 너의 뒤를 비춰줄 테니."* |

## 4. 동료(Companion) 및 이벤트 플래그 반응 대사

조우 시 파티 구성이나 특정 조건이 충족되면, 일반 친밀도 대사보다 **동료/상황 반응 대사가 우선 출력**됩니다.

### 4.1 동료 캐릭터 보유 반응 (레퍼런스 이미지 스타일)
파티에 특정 협력자(CooperationManager의 합류 캐릭터)가 있을 때, 마키나가 그들의 기운과 상처를 느끼고 건네는 대화:

#### ① 치하라 쇼 (Cp_01 - 피를 매개로 베어내는 협력자) 합류 시
> **마키나**: *"그대의 곁에 선 자... 칼날에 너무나 짙은 피와 후회의 냄새가 배어있구나."*  
> **답변 버튼**: `[치하라 쇼 / 침묵] ...내 피는 내가 알아서 다룬다.`  
> **마키나**: *"후후... 날을 너무 바짝 세우지 마렴, 아이야. 피안화 앞에서는 그 어떤 원망도 결국 고요해지는 법이란다."*

#### ② 2인 이상 동료와 함께 방문했을 때
> **마키나**: *"혼자서 비틀거리며 오던 방랑자가... 이제는 등을 맞댈 이들을 데려왔구나."*  
> **답변 버튼**: `[방랑자 / 끄덕임] ...혼자서는 갈 수 없는 길이니까요.`  
> **마키나**: *"참으로 다행스러운 일이지. 차가운 버텍스 속에서도 서로의 체온이 남아있다면, 영혼이 완전히 얼어붙지는 않을 테니."*

### 4.2 플레이어 상태 반응
- **빈사 상태 (HP 30% 이하로 진입 시)**:
  > **마키나**: *"금방이라도 쓰러질 것 같은 숨결이구나... 잠시 이곳에 무기를 내려놓으렴."*  
  > **답변 버튼**: `[방랑자 / 거친 숨] ...아직, 쓰러질 수 없습니다.`  
  > **마키나**: *"그 완고함이 안쓰러우면서도 눈부시구나. 내 숨결을 조금 나누어주마."*
- **누적 사망 횟수 3회 이상 후 재조우**:
  > **마키나**: *"또다시 옷자락을 붉게 물들이고 돌아왔구나. 기억은... 아직 온전하니?"*  
  > **답변 버튼**: `[방랑자 / 망설임] ...조금씩 흐려지는 것 같습니다.`  
  > **마키나**: *"괜찮단다. 네가 잊은 파편들은 내가 이 꽃잎 사이에 고이 모아두고 있을 테니."*

## 5. 데이터 구조 및 C# ScriptableObject 템플릿 설계

### 5.1 대화 단계 및 조건부 시퀀스 (`BlessingDialogueData.cs`)

```csharp
using System;
using System.Collections.Generic;
using UnityEngine;

// 1회 핑퐁 대사 (NPC 말 + 플레이어 답변 버튼)
[Serializable]
public class BlessingDialogueStep
{
    [Tooltip("화자 표기 (비어있으면 기본 NPC)")]
    public string speakerName;

    [Tooltip("NPC의 말풍선 대사")]
    [TextArea(2, 4)]
    public string npcDialogue;

    [Tooltip("플레이어 답변 캡슐 버튼 텍스트 (예: '[치하라 쇼 / 침묵] ...')")]
    public string playerAnswerText = "[방랑자] ...";
}

// 조건부 대화 묶음
[Serializable]
public class BlessingDialogueSequence
{
    public string sequenceId;

    [Header("발동 조건")]
    [Tooltip("우선순위 (동료 반응이나 특수 플래그는 10 이상)")]
    public int priority = 0;

    [Tooltip("최소 요구 친밀도")]
    public float minAffinity = 0f;

    [Tooltip("특정 동료가 파티에 있어야 발동 (예: 'Cp_01')")]
    public string requiredCompanionCharId = "";

    [Tooltip("특정 이벤트 플래그 필요 시 (예: 'low_hp', 'death_streak')")]
    public string requiredEventFlag = "";

    [Header("대화 핑퐁 단계")]
    public List<BlessingDialogueStep> steps = new();
}
```
