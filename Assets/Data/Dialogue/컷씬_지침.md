# 컷씬 / 다이얼로그 시스템 가이드

## 1. 전체 구조

세 컴포넌트가 역할을 나눠 가짐. 서로 존재를 몰라도 되게 `Play(json, onComplete)` 형태로만 연결됨.

```
CutscenePlayer  ← CutsceneSequenceSO(에셋: 순서 데이터)
   │
   ├─ 세그먼트가 Cutscene 타입이면 → CutsceneView.Play(json, 다음거 재생)
   └─ 세그먼트가 Dialogue 타입이면 → DialogueView.Play(json, 다음거 재생)
```

- **`DialogueView`** — 캐릭터 초상화 슬롯(최대 4명) + 하단 대사창. "누가 무슨 말을 하는지" 담당
- **`CutsceneView`** — 풀스크린 CG + 검정 페이드 전환 + 자막. "장면을 보여주는" 담당
- **`CutscenePlayer` + `CutsceneSequenceSO`** — 컷씬↔다이얼로그를 여러 번 번갈아 재생하는 순서를 관리. 프롤로그 하나에 종속되지 않고 챕터 인트로/엔딩 등 아무 시퀀스에나 재사용 가능

각자 독립적으로도 쓸 수 있음 — 예를 들어 이벤트 노드는 `EventView`가 `DialogueView`만 직접 호출(`dialogueView.Play(_data.dialogueJson, ShowDescriptionAndChoices)`), 컷씬은 안 거침.

## 2. 다이얼로그 JSON 작성법

**상세 포맷은 `Assets/Data/Dialogue/지침.md` 참고.** 여기서는 핵심만.

```json
{
  "characters": [
    { "id": "koyuki", "name": "코유키", "slot": 0 }
  ],
  "startNode": "start",
  "nodes": [
    {
      "id": "start",
      "lines": [
        { "type": "line", "speaker": "koyuki", "emotion": "confident", "text": "대사 내용" },
        { "type": "choice", "options": [ { "text": "선택지1", "next": "다른노드id" } ] },
        { "type": "end" }
      ]
    }
  ]
}
```

- `emotion`: `idle`/`laugh`/`embarrassed`/`blush`/`annoyed`/`sad`/`confident`/`despise` 중 하나 (캐릭터별 감정 스프라이트 매핑은 아직 미구현 — `CharacterSlotView.SetEmotion`이 빈 함수)
- 분기(`choice`)와 노드 점프(`next`) 지원. 컷씬 JSON에는 이 개념이 없음(아래 참고)
- `JsonUtility` 제약(Dictionary/폴리모피즘 불가)으로 `type` 필드로 종류 구분하는 구조

## 3. 컷씬 JSON 작성법 (신규)

다이얼로그와 달리 **분기가 필요 없어서** `nodes`/`id`/`next` 구조 없이, 순서대로 재생되는 `beats` 배열 하나면 충분함.

```json
{
  "beats": [
    { "background": "ruins_wide",  "fade": "in",  "caption": "때로는 생명 없는 연철에도 무덤이 있는 법이다." },
    { "background": "ruins_close", "fade": "cut", "caption": "이미 스러져간 무수한 군인들과 용병..." },
    { "fade": "out" }
  ]
}
```

| 필드 | 설명 |
|---|---|
| `background` | `CutsceneView` 인스펙터의 `Backgrounds` 리스트에 등록된 **키 문자열**. 비워두면 이전 배경 그대로 유지 |
| `fade` | `"in"`(암전에서 밝아짐) / `"out"`(밝은 상태에서 암전) / 생략 시 `"cut"`(페이드 없이 즉시 전환) |
| `caption` | 자막. 비워두면 자막 없이 그림만(연출용 순수 컷) |

**진행 방식**: 다이얼로그처럼 화살표 버튼 / 스페이스 / 엔터로 한 비트씩 넘어감. 자막이 타이핑 중이면 한 번 눌러서 즉시 완성, 한 번 더 눌러야 다음 비트로 진행(다이얼로그와 동일 관례).

컷씬은 항상 **암전(검정 화면)에서 시작**함 — 첫 비트를 보통 `"fade": "in"`으로 열게 됨.

## 4. 배경(CG) 등록하는 법

`CutsceneView` 인스펙터의 `Backgrounds` 리스트에 `key`(문자열) + `sprite`(그림) 쌍을 등록.

```
key: "ruins_wide"   → sprite: (폐허 그림 A)
key: "ruins_close"  → sprite: (폐허 그림 B)
```

JSON의 `"background": "ruins_wide"`가 이 키를 참조해서 실제 그림을 찾아옴. `emotion` 문자열로 캐릭터 표정 스프라이트 찾는 것과 같은 방식. **지금은 이 리스트가 비어있어서 등록 전까진 배경이 안 나옴.**

## 5. 컷씬↔다이얼로그 연속 재생 시퀀스 만들기

1. `Assets` 우클릭 → `Create > Game Asset > Cutscene Sequence` 로 `CutsceneSequenceSO` 에셋 생성 (예: `Prologue.asset`, `Chapter2Intro.asset`)
2. 인스펙터에서 `Segments` 리스트에 순서대로 추가:
   - `Type`: `Cutscene` 또는 `Dialogue`
   - `Json`: 해당 타입에 맞는 JSON 파일(컷씬 JSON 또는 다이얼로그 JSON)
3. 코드에서 재생할 땐:
   ```csharp
   cutscenePlayer.Play(prologueSequence, OnPrologueFinished);
   ```
   `CutscenePlayer`가 `segments`를 순서대로 훑으면서 타입에 맞게 `CutsceneView`/`DialogueView`를 번갈아 호출하고, 전부 끝나면 넘겨준 콜백을 부름.

컷씬 3개, 대화 2개를 어떤 순서로 섞든 이 구조는 안 바뀜 — 새 시퀀스가 필요하면 SO만 하나 더 만들면 됨(컴포넌트/코드 추가 불필요).
